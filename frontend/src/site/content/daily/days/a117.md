## Understand

### What seaborn adds to matplotlib

Seaborn is a plotting library built on top of matplotlib. It does not replace matplotlib; it draws onto the same figures and axes, so everything from the last two days (titles, limits, annotations, `savefig`) still works on a seaborn chart. What seaborn adds is a **statistical** layer: you pass a whole DataFrame and the names of columns, and seaborn does the grouping and aggregating, picks sensible defaults and labels the axes with the column names. A seaborn call that takes one line (`sns.barplot(data=df, x="category", y="revenue")`) replaces a `groupby`, a `mean` and a `bar` call in matplotlib. The price is that you must know what seaborn computed, because a bar can mean a mean, a count or a sum depending on the function, and the chart will not tell you.

### Long-format data

Seaborn works best with **long-format** (also called tidy) data: one row per observation and one column per variable, such as one row per order with columns for category, revenue and shipping days. You tell seaborn which column goes on which axis with `x=`, `y=` and which column colours the marks with `hue=`. If your data is wide (one column per category) you reshape it first with `melt`. Because seaborn returns a matplotlib axes (for the axes-level functions used today), you can pass `ax=ax` to draw onto an axes you created, and you can read the result back with `ax.patches`, `ax.lines` and the label getters.

### Distribution plots

A distribution plot shows how the values of one numeric column are spread. `sns.histplot` cuts the range into **bins** (equal-width intervals) and draws a bar for the count in each. The number of bins matters: too few hides the shape (everything looks like one lump), too many produces a ragged picture where each bar holds a handful of rows. You control it with `bins=10` for a count or `binwidth=50` for a width. The heights of the bars always add up to the number of rows, which is a useful check. With `kde=True` seaborn adds a **kernel density estimate**, a smooth curve that estimates the shape of the distribution by placing a small bump at every value and adding them up; it is drawn as one line on the same axes. `sns.kdeplot` draws only that curve. A histogram is honest about counts; a density curve can imply data below zero or smooth over a gap, so look at the histogram when the data have a hard limit such as zero.

### Categorical plots

Categorical plots compare a numeric column across the values of a category column. `sns.countplot` counts rows per category and needs no y column. `sns.barplot` computes an **estimator**, by default the mean, of the y column per category and draws a bar for each, with an error bar for uncertainty; pass `errorbar=None` to hide it, and `estimator="sum"` or another function to change the statistic. `sns.boxplot` shows the distribution per category: a box from the first to the third quartile, a line at the median, and whiskers that extend to the most extreme values within 1.5 times the interquartile range, with points beyond that drawn as outliers. A bar of means hides spread; a box shows it, which is why a boxplot is the better comparison when the groups have very different variation. Seaborn draws categories in the order they first appear in the data unless you pass `order=[...]`, so sort them yourself when the chart should be ranked.

### Themes and context

`sns.set_theme(style="whitegrid", context="talk", palette="deep")` sets matplotlib defaults for the rest of the session: `style` is the look of the axes (`darkgrid`, `whitegrid`, `dark`, `white`, `ticks`), `context` scales the font and line sizes for a purpose (`paper`, `notebook`, `talk`, `poster`), and `palette` sets the default colours. Like `plt.style.use`, it is global; use `with sns.axes_style("darkgrid"):` for a temporary change. Themes are about consistency, not correctness.

### Misconceptions and why it matters

Two beliefs cause trouble. The first is "seaborn shows the data": `barplot` shows a summary, and two groups with identical means can have very different shapes. The second is "the default bins are right": check the bin count and compare two settings before you believe a shape such as bimodality. In analysis work the fastest way to avoid both is to compute the summary in pandas as well and compare it with what the chart plots. This day's examples do exactly that.

## Syntax and key functions

```python
sns.histplot(data=df, x="revenue", bins=10, kde=True, ax=ax)
sns.kdeplot(data=df, x="revenue", ax=ax)
sns.countplot(data=df, x="category", order=["Home", "Beauty"], ax=ax)
sns.barplot(data=df, x="category", y="revenue", estimator="mean", errorbar=None, ax=ax)
sns.boxplot(data=df, x="category", y="revenue", hue="channel", ax=ax)
sns.set_theme(style="whitegrid", context="talk")
with sns.axes_style("darkgrid"):
    ...
```

| Function | What it draws or returns |
|---|---|
| `sns.histplot` | Histogram of one column (count per bin); returns the axes |
| `sns.kdeplot` | Smooth density curve of one column |
| `sns.countplot` | One bar per category with the row count |
| `sns.barplot` | One bar per category with an estimator (mean by default) of y |
| `sns.boxplot` | Box and whiskers per category |
| `sns.set_theme` | Sets style, context and palette defaults globally |
| `sns.axes_style(name)` | Returns the dict of style settings; usable as a context manager |
| `order=`, `hue=`, `errorbar=None` | Category order, colour grouping, and hide the error bar |

All of these are axes-level functions: they draw on one axes and return it, so `ax = sns.barplot(...)` and `ax=ax` both work.

## Learn by example

### Example 1: The numbers behind the charts

This example computes with pandas and NumPy what a histogram, a bar of means and a count bar would plot, so that you can check the charts afterwards. It runs in the browser.

```python run
import numpy as np
import pandas as pd


def make_orders():
    rng = np.random.default_rng(7)
    n = 240
    category = rng.choice(["Home", "Electronics", "Beauty", "Sports"], size=n, p=[0.35, 0.2, 0.25, 0.2])
    base = pd.Series({"Home": 45, "Electronics": 160, "Beauty": 28, "Sports": 60})
    df = pd.DataFrame({
        "order_date": pd.Timestamp("2025-01-01") + pd.to_timedelta(rng.integers(0, 365, n), unit="D"),
        "category": category,
        "quantity": rng.integers(1, 6, n),
        "unit_price": (base[category].to_numpy() * (0.8 + 0.4 * rng.random(n))).round(2),
        "shipping_days": rng.integers(1, 9, n),
    })
    df["revenue"] = (df["quantity"] * df["unit_price"]).round(2)
    return df.sort_values("order_date").reset_index(drop=True)

orders = make_orders()
counts, edges = np.histogram(orders["revenue"], bins=10)
print("bin counts:", [int(c) for c in counts], "sum:", int(counts.sum()))
print("bin width:", round(float(edges[1] - edges[0]), 1))
print("means:", {k: round(float(v), 1) for k, v in orders.groupby("category")["revenue"].mean().items()})
print("counts:", orders["category"].value_counts().sort_index().to_dict())
```

```output
bin counts: [87, 84, 26, 12, 3, 10, 3, 9, 2, 4] sum: 240
bin width: 91.7
means: {'Beauty': 85.0, 'Electronics': 553.5, 'Home': 145.3, 'Sports': 165.2}
counts: {'Beauty': 62, 'Electronics': 41, 'Home': 82, 'Sports': 55}
```

### Example 2: A histogram with a density curve

`histplot` with `bins=10` and `kde=True`. The ten bars are rectangles on the axes, so `ax.patches` has ten entries whose heights equal the counts from Example 1, and the density curve is one line. Seaborn labels the axes automatically: the x label is the column name and the y label is `Count`.

```python local
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt
import seaborn as sns
import numpy as np
import pandas as pd


def make_orders():
    rng = np.random.default_rng(7)
    n = 240
    category = rng.choice(["Home", "Electronics", "Beauty", "Sports"], size=n, p=[0.35, 0.2, 0.25, 0.2])
    base = pd.Series({"Home": 45, "Electronics": 160, "Beauty": 28, "Sports": 60})
    df = pd.DataFrame({
        "order_date": pd.Timestamp("2025-01-01") + pd.to_timedelta(rng.integers(0, 365, n), unit="D"),
        "category": category,
        "quantity": rng.integers(1, 6, n),
        "unit_price": (base[category].to_numpy() * (0.8 + 0.4 * rng.random(n))).round(2),
        "shipping_days": rng.integers(1, 9, n),
    })
    df["revenue"] = (df["quantity"] * df["unit_price"]).round(2)
    return df.sort_values("order_date").reset_index(drop=True)

orders = make_orders()
fig, ax = plt.subplots()
sns.histplot(data=orders, x="revenue", bins=10, kde=True, ax=ax)
ax.set_title("Most orders are small, a few are large")

counts, edges = np.histogram(orders["revenue"], bins=10)
print("bars:", len(ax.patches), "| lines (density):", len(ax.lines))
print("heights match numpy:", [int(p.get_height()) for p in ax.patches] == [int(c) for c in counts])
print("labels:", ax.get_xlabel(), "/", ax.get_ylabel())
print("total rows in bars:", int(sum(p.get_height() for p in ax.patches)))
```

```output
bars: 10 | lines (density): 1
heights match numpy: True
labels: revenue / Count
total rows in bars: 240
```

### Example 3: Bar of means and count of rows

`barplot` computes the mean revenue per category, `countplot` counts rows. Each bar's height is compared with pandas. The categories appear in the order they first occur in the data, so the example passes `order=` to rank them. Seaborn's default error bar is a bootstrap confidence interval, which uses random numbers, so it is switched off to keep the output stable.

```python local
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt
import seaborn as sns
import numpy as np
import pandas as pd


def make_orders():
    rng = np.random.default_rng(7)
    n = 240
    category = rng.choice(["Home", "Electronics", "Beauty", "Sports"], size=n, p=[0.35, 0.2, 0.25, 0.2])
    base = pd.Series({"Home": 45, "Electronics": 160, "Beauty": 28, "Sports": 60})
    df = pd.DataFrame({
        "order_date": pd.Timestamp("2025-01-01") + pd.to_timedelta(rng.integers(0, 365, n), unit="D"),
        "category": category,
        "quantity": rng.integers(1, 6, n),
        "unit_price": (base[category].to_numpy() * (0.8 + 0.4 * rng.random(n))).round(2),
        "shipping_days": rng.integers(1, 9, n),
    })
    df["revenue"] = (df["quantity"] * df["unit_price"]).round(2)
    return df.sort_values("order_date").reset_index(drop=True)

orders = make_orders()
rank = orders.groupby("category")["revenue"].mean().sort_values(ascending=False)

fig, (left, right) = plt.subplots(1, 2, figsize=(9, 3.5))
sns.barplot(data=orders, x="category", y="revenue", order=list(rank.index), errorbar=None, ax=left)
sns.countplot(data=orders, x="category", order=list(rank.index), ax=right)

print("bar order:", [t.get_text() for t in left.get_xticklabels()])
print("bar heights:", [round(float(p.get_height()), 1) for p in left.patches])
print("pandas means:", [round(float(v), 1) for v in rank.values])
print("count heights:", [int(p.get_height()) for p in right.patches])
print("y labels:", left.get_ylabel(), "/", right.get_ylabel())
```

```output
bar order: ['Electronics', 'Sports', 'Home', 'Beauty']
bar heights: [553.5, 165.2, 145.3, 85.0]
pandas means: [553.5, 165.2, 145.3, 85.0]
count heights: [41, 55, 82, 62]
y labels: revenue / count
```

### Example 4: Box plots compare spread

A boxplot per category shows what the bar of means hides. The prints give the number of boxes and the median and interquartile range from pandas for each group, the numbers the boxes draw. This example silences a deprecation warning that some seaborn and matplotlib version pairs emit from inside `boxplot`; the warning is about the library's own code, not yours.

```python local
import warnings
warnings.filterwarnings("ignore", category=DeprecationWarning)
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt
import seaborn as sns
import numpy as np
import pandas as pd


def make_orders():
    rng = np.random.default_rng(7)
    n = 240
    category = rng.choice(["Home", "Electronics", "Beauty", "Sports"], size=n, p=[0.35, 0.2, 0.25, 0.2])
    base = pd.Series({"Home": 45, "Electronics": 160, "Beauty": 28, "Sports": 60})
    df = pd.DataFrame({
        "order_date": pd.Timestamp("2025-01-01") + pd.to_timedelta(rng.integers(0, 365, n), unit="D"),
        "category": category,
        "quantity": rng.integers(1, 6, n),
        "unit_price": (base[category].to_numpy() * (0.8 + 0.4 * rng.random(n))).round(2),
        "shipping_days": rng.integers(1, 9, n),
    })
    df["revenue"] = (df["quantity"] * df["unit_price"]).round(2)
    return df.sort_values("order_date").reset_index(drop=True)

orders = make_orders()
fig, ax = plt.subplots()
sns.boxplot(data=orders, x="category", y="revenue", ax=ax)
ax.set_title("Electronics orders vary the most")

print("boxes:", len(ax.patches))
print("x label:", ax.get_xlabel(), "| y label:", ax.get_ylabel())
stats = orders.groupby("category")["revenue"].describe()[["25%", "50%", "75%"]].round(0)
stats["iqr"] = stats["75%"] - stats["25%"]
print(stats.sort_values("iqr", ascending=False).to_string())
```

### Example 5: Themes

A theme is a dictionary of matplotlib settings. `sns.axes_style` returns it without changing anything, so you can inspect a style before using it, and as a context manager it changes the look for one block. `sns.set_theme` changes the defaults for the session.

```python local
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt
import seaborn as sns
print("darkgrid background:", sns.axes_style("darkgrid")["axes.facecolor"])
print("whitegrid has grid:", sns.axes_style("whitegrid")["axes.grid"])
print("white has grid:", sns.axes_style("white")["axes.grid"])

before = plt.rcParams["font.size"]
sns.set_theme(style="whitegrid", context="talk")
after = plt.rcParams["font.size"]
print("font size grew:", after > before, "| talk size:", after)
```

```output
darkgrid background: #EAEAF2
whitegrid has grid: True
white has grid: False
font size grew: True | talk size: 18.0
```

## Real-world applications

- **Checking a metric's shape.** Before reporting an average order value, an analyst draws `histplot` and sees a long right tail (Example 2), which tells them to report the median as well.
- **Category comparisons for a review.** A bar of means with a count bar beside it (Example 3) shows whether a high average comes from a few orders or many.
- **Spotting spread differences.** Box plots by category (Example 4) show which category is unpredictable, which affects inventory and forecasting.
- **House style.** A single `sns.set_theme` call at the top of a reporting script gives every chart the same context and palette.

## Daily review

### Key takeaways

- Seaborn draws on matplotlib axes, so matplotlib methods still apply.
- It works from long-format DataFrames with `x=`, `y=`, `hue=`.
- `histplot` heights sum to the row count; `barplot` shows a mean by default; `countplot` shows counts; `boxplot` shows spread.
- Categories appear in data order unless you give `order=`.
- Verify a chart by computing the same numbers with pandas.

### Common mistakes

- Reading a bar of means as a bar of totals. Symptom: a category with few big orders looks as important as one with many. Fix: use `estimator="sum"` or a count plot, and say which in the label.
- Using `barplot` for a question about spread. Symptom: two groups look identical while one varies tenfold. Fix: use `boxplot`.
- Too few or too many histogram bins. Symptom: one lump, or a spiky outline. Fix: try `bins=10`, `20` and `binwidth` and compare.
- Passing wide data and getting nonsense. Symptom: seaborn plots only some columns or raises an error. Fix: `melt` to long format.

### Revision notes

- `sns.histplot(data, x, bins, kde)`, `sns.countplot`, `sns.barplot(estimator, errorbar)`, `sns.boxplot`.
- `ax=` draws on your axes; the return value is the axes.
- `sns.set_theme(style, context, palette)` is global; `with sns.axes_style(...)` is temporary.
- Box: quartiles, median, whiskers at 1.5 x IQR.
