## Objectives

- Apply string methods to a whole column with the `.str` accessor, including `lower`, `upper`, `title`, `strip`, `len` and `replace`.
- Test text with `str.contains`, `str.startswith` and `str.endswith`, and use the result as a filter mask.
- Split text into parts with `str.split` (as lists or as separate columns) and pick pieces with `str.get` or `str[...]`.
- Pull a part out of text with `str.extract` and a regular expression group.
- Clean a messy text column in a reliable order and verify the result.

## Understand

### Strings in columns

On Day 4 you cleaned one string with methods such as `strip()` and `lower()`. A pandas column of text holds thousands of strings, and writing a loop over them would be slow and long. The **`.str` accessor** solves this: `s.str.lower()` applies `lower()` to every string in the Series `s` and returns a new Series. An **accessor** is a namespace attached to a Series that collects related methods; `.str` is for text, `.dt` is for dates (next week), and `.cat` is for categories (Day 75). Almost every Day 4 method has a `.str` version with the same name and meaning: `lower`, `upper`, `title`, `strip`, `replace`, `startswith`, `endswith`, `find`, `count`, `isdigit` and `len`. The new idea is that they work on a whole column at once, and, like every vectorised pandas operation, they return a new column and leave the original unchanged.

Missing values are handled gently. If a cell is missing (`None` or `NaN`), `str.lower()` returns a missing value for that cell instead of raising an error, and `str.len()` returns `NaN`. This is convenient, but it also means that the result of a `.str` method that gives a number or a boolean can contain `NaN`, and such a result is stored as a float column. The `.str` accessor works only on columns of text; on a numeric column it raises `AttributeError: Can only use .str accessor with string values`. If the column holds numbers stored as text, `.str` is correct; if it holds real numbers, convert to text with `astype(str)` first.

### Cleaning case and spaces

The usual first steps for a messy column are `strip()` to remove spaces from both ends, then `lower()` or `title()` to make the case consistent: `s.str.strip().str.lower()`. Chaining works as for single strings. These two steps alone fix many of the label problems you found with `value_counts` on Day 70, where `Oslo`, `oslo` and `Oslo ` counted as three cities. `str.replace(old, new, regex=False)` replaces a fixed piece of text everywhere in each string. Write `regex=False` when the text to find is literal, such as `"-"` or `"."`. A dot has a special meaning in a regular expression, so a replacement meant to be literal can give wrong results otherwise.

### Testing and filtering text

`s.str.contains("ana")` returns a boolean Series that is `True` where the text contains the piece. `case=False` ignores case, and `na=False` treats missing values as `False`, which is necessary when you use the result as a mask, because a mask containing missing values raises an error. `str.startswith("SKU")` and `str.endswith(".csv")` test the ends. These give masks exactly as Day 72: `df[df["name"].str.contains("ana", case=False, na=False)]` keeps the rows whose name contains `ana`. By default `contains` reads its argument as a **regular expression**, a pattern language that you met in the Python regex note; plain words work as expected, and `regex=False` makes it a literal search.

### Splitting and picking parts

`s.str.split(" ")` splits every string at the separator and returns a Series of lists. `.str[0]` or `.str.get(0)` picks an item of each list, so `s.str.split(" ").str[0]` is the first word of each value. The argument `expand=True` goes further and returns a **DataFrame** with one column per part, named 0, 1, 2, ...: `s.str.split(" ", expand=True)`. You can then assign the pieces to new columns. Strings with fewer parts than the others get a missing value in the last columns. Slicing also works on a column: `s.str[:3]` is the first three characters and `s.str[-4:]` the last four, as on Day 4. `s.str.len()` gives each length and `s.str.zfill(5)` pads numbers written as text with leading zeros.

### Extracting with a pattern

When the part you need has a pattern, not a fixed position, use `str.extract` with a regular expression that has a **capture group** in parentheses. `s.str.extract(r"SKU-(\d+)-(\w+)")` returns a DataFrame with one column per group: the digits after `SKU-` and the word after the next hyphen. `\d` means a digit and `\w` a letter, digit or underscore. Rows that do not match give `NaN`, which is useful: the pattern doubles as a validity test. Named groups, `(?P<num>\d+)`, name the output columns. The pattern is written in a raw string, `r"..."`, so that backslashes are kept as they are. Extracted text is still text, so convert it with `to_numeric` or `astype(float)` (Day 75) to calculate with it.

### A reliable cleaning order

For a text column with problems, a good order is: look first with `value_counts` (Day 70); `strip` and unify the case; replace known variants or punctuation; extract or split what you need; convert to numbers where required; check the result again with `value_counts` and `isna`. Strip before comparing, and unify case before looking for duplicates (Day 75), because `"Ana"` and `"ana "` would otherwise count as different.

### The common misconception

Learners write `df["name"].str.strip()` on a line by itself and expect the table to be cleaned. Like every string method the result is a new Series, so it must be stored: `df["name"] = df["name"].str.strip()` (or kept in a new column). Another is to expect `str.replace` to treat its first argument as plain text. In older pandas versions it is read as a regular expression by default, and the safe habit is to always say `regex=False` or `regex=True` explicitly. A third is using Python's `in` on a column: `"ana" in df["name"]` tests the **index**, not the text; use `str.contains`.

### Why it matters in data work

A large share of cleaning is text: names with stray spaces, inconsistent capitalisation, codes that contain several fields, phone numbers and prices written with symbols. The `.str` tools turn these into consistent labels and separate fields in a few lines, and they make joins and grouping reliable, because equal things finally look equal. As with all cleaning, apply the steps to a copy, count what changed, and keep the raw column.

### Limits to remember

String methods cover the common cases, but not everything. They do not understand meaning: `Saint` and `St.` are different strings, and misspellings such as `Oslo` and `Oslu` stay different. Those need a lookup table of corrections, which you apply with `replace` and a dictionary, or fuzzy matching tools outside this course. Always check the cleaned column with `value_counts` to see the labels that remain.

## Syntax and key functions

```python
s.str.strip().str.lower()
s.str.replace("-", " ", regex=False)
s.str.contains("ana", case=False, na=False)
s.str.startswith("SKU")
s.str.split(" ")
s.str.split(" ", expand=True)
s.str[0]
s.str.extract(r"SKU-(\d+)-(\w+)")
s.str.len()
```

| Expression | Returns |
|---|---|
| `s.str.lower()`, `.upper()`, `.title()` | New Series with changed case. |
| `s.str.strip()` | New Series without edge whitespace. |
| `s.str.replace(old, new, regex=False)` | New Series with literal text replaced. |
| `s.str.contains(text, case=False, na=False)` | Boolean mask. |
| `s.str.startswith(t)`, `.endswith(t)` | Boolean mask. |
| `s.str.split(sep)` | Series of lists. |
| `s.str.split(sep, expand=True)` | DataFrame with one column per part. |
| `s.str[0]`, `s.str[:3]`, `s.str.get(i)` | Item of each list, or slice of each string. |
| `s.str.extract(pattern)` | DataFrame of the capture groups (NaN where no match). |
| `s.str.len()`, `s.str.count(t)` | Lengths, number of occurrences. |
| `s.str.zfill(n)` | Padded with leading zeros to width n. |

## Learn by example

### Example 1: Cleaning case and spaces

`strip`, `lower` and `title` work on the whole column. The original is unchanged, a missing value stays missing, and `len` returns `NaN` for it, which makes that result a float column. Counting the distinct labels before and after shows the effect.

```python run
import pandas as pd

s = pd.Series(["  Ana Silva ", "bob KING", "ana silva", None, "Bob King"])
clean = s.str.strip().str.title()
print(clean.tolist())
print(s.str.len().tolist())
print(s.tolist()[0])
print(s.nunique(), clean.nunique())
print(s.str.lower().str.strip().value_counts().sort_index().to_dict())
```

```output
['Ana Silva', 'Bob King', 'Ana Silva', None, 'Bob King']
[12.0, 8.0, 9.0, nan, 8.0]
  Ana Silva 
4 2
{'ana silva': 2, 'bob king': 2}
```

### Example 2: Replacing and testing text

`replace` with `regex=False` swaps literal text. `contains` returns a mask, here with `case=False` and `na=False`, and the mask filters a DataFrame as on Day 72. `startswith` and `endswith` test the ends.

```python run
import pandas as pd

pd.set_option("display.width", 200)
pd.set_option("display.max_columns", 20)

df = pd.DataFrame({"file": ["sales-2024.csv", "Costs-2024.CSV", "notes.txt", None], "qty": [1, 2, 3, 4]})
print(df["file"].str.replace("-", "_", regex=False).tolist())
mask = df["file"].str.contains("2024", na=False)
print(mask.tolist())
print(df[df["file"].str.lower().str.endswith(".csv", na=False)])
print(df["file"].str.startswith("s", na=False).sum())
print(df["file"].str.contains("sales", case=False, na=False).tolist())
```

```output
['sales_2024.csv', 'Costs_2024.CSV', 'notes.txt', None]
[True, True, False, False]
             file  qty
0  sales-2024.csv    1
1  Costs-2024.CSV    2
1
[True, False, False, False]
```

### Example 3: Splitting into parts

`split` returns lists and `.str[0]` picks the first item of each. `expand=True` returns a DataFrame with one column per part, and the pieces can become new columns of the table.

```python run
import pandas as pd

pd.set_option("display.width", 200)
pd.set_option("display.max_columns", 20)

names = pd.Series(["Ana Silva", "Bob King", "Cy Lopez"])
print(names.str.split(" ").tolist())
print(names.str.split(" ").str[0].tolist(), names.str.split(" ").str[-1].tolist())
parts = names.str.split(" ", expand=True)
print(parts)
df = pd.DataFrame({"full": names})
df["first"] = parts[0]
df["last"] = parts[1]
print(df)
print(names.str[:3].tolist(), names.str.len().tolist())
```

```output
[['Ana', 'Silva'], ['Bob', 'King'], ['Cy', 'Lopez']]
['Ana', 'Bob', 'Cy'] ['Silva', 'King', 'Lopez']
     0      1
0  Ana  Silva
1  Bob   King
2   Cy  Lopez
        full first   last
0  Ana Silva   Ana  Silva
1   Bob King   Bob   King
2   Cy Lopez    Cy  Lopez
['Ana', 'Bob', 'Cy '] [9, 8, 8]
```

### Example 4: Extracting with a pattern

`extract` returns the capture groups as columns and `NaN` when the text does not match. Named groups name the columns. The extracted number is still text until it is converted.

```python run
import pandas as pd

pd.set_option("display.width", 200)
pd.set_option("display.max_columns", 20)

codes = pd.Series(["SKU-123-BLUE", "SKU-45-RED", "bad-code"])
out = codes.str.extract(r"SKU-(?P<num>\d+)-(?P<colour>\w+)")
print(out)
print(out["num"].tolist())
print(pd.to_numeric(out["num"]).tolist())
print(out["num"].isna().tolist())
print(codes.str.zfill(12).tolist())
```

```output
   num colour
0  123   BLUE
1   45    RED
2  NaN    NaN
['123', '45', nan]
[123.0, 45.0, nan]
[False, False, True]
['SKU-123-BLUE', '00SKU-45-RED', '0000bad-code']
```

### Example 5: Cleaning prices and labels in the right order

A text column of prices with currency symbols and separators is cleaned with regular-expression replacement and converted to numbers. Names are stripped and given a consistent case before counting. The raw column is kept and the result is checked.

```python run
import pandas as pd

pd.set_option("display.width", 200)
pd.set_option("display.max_columns", 20)

raw = pd.DataFrame({"city": [" Oslo", "oslo ", "ROME", "Rome", "Lima"],
                    "price": ["$1,200", "$35", "n/a", "$7.50", "$2,000"]})
clean = raw.assign(
    city=raw["city"].str.strip().str.title(),
    price=pd.to_numeric(raw["price"].str.replace(r"[$,]", "", regex=True), errors="coerce"),
)
print(clean)
print(raw["city"].nunique(), clean["city"].nunique())
print(clean["city"].value_counts().sort_index().to_dict())
print(clean["price"].sum(), int(clean["price"].isna().sum()))
print(raw["price"].tolist()[0])
```

```output
   city   price
0  Oslo  1200.0
1  Oslo    35.0
2  Rome     NaN
3  Rome     7.5
4  Lima  2000.0
5 3
{'Lima': 1, 'Oslo': 2, 'Rome': 2}
3242.5 1
$1,200
```

## Real-world applications

- **Unifying labels.** `strip` and `title` or `lower`, as in Examples 1 and 5, make `Oslo`, `oslo ` and ` Oslo` into one label, so groups and joins are correct.
- **Splitting combined fields.** Full names, addresses and codes that hold several fields are split into columns, as in Example 3.
- **Pulling identifiers out of text.** `extract` takes the number and colour from product codes and doubles as a validity check, as in Example 4.
- **Making prices numeric.** Removing symbols and separators and converting, as in Example 5, turns text prices into numbers that can be summed.

## Daily review

### Key takeaways

- `.str` applies string methods to a whole column and returns a new Series; missing values stay missing.
- `strip` plus `lower` or `title` fixes most label problems; write `regex=False` for literal `replace`.
- `contains(..., na=False)`, `startswith` and `endswith` give masks that filter rows.
- `split` returns lists, `expand=True` returns columns, `.str[i]` picks parts; `extract` pulls out capture groups.
- Store the cleaned result; convert extracted text to numbers; check with `value_counts`.

### Common mistakes

- Calling `df["name"].str.strip()` and not storing the result.
- Using `.str` on a numeric column and getting `AttributeError`.
- Using `contains` as a mask without `na=False`, which fails when the column has gaps.
- Using a dot or a bracket in `replace` without `regex=False`, which may be read as a pattern.
- Testing `"ana" in df["name"]`, which checks the index, not the text.
- Forgetting that `extract` returns text, so sums fail until you convert.

### Revision notes

- `s.str.strip().str.lower()`, `s.str.replace(a, b, regex=False)`.
- `s.str.contains(t, case=False, na=False)`, `s.str.startswith(t)`.
- `s.str.split(" ", expand=True)`, `s.str[0]`, `s.str.extract(r"(\d+)")`.
- Strip, unify case, replace, extract, convert, check.
