## Understand

### What a string is

A **string** (type `str`) is a sequence of characters: letters, digits, spaces, punctuation and symbols, in a fixed order. You write one by putting characters inside quotes. Single quotes and double quotes mean exactly the same thing, so `'data'` and `"data"` are identical. Choosing double quotes lets you include an apostrophe, as in `"it's"`, and choosing single quotes lets you include a double quote, as in `'say "hi"'`. For text over several lines you can use triple quotes, `"""like this"""`, which keep the line breaks you type.

The number of characters is given by `len()`, so `len("data")` is `4`. Spaces count as characters, and so does the empty string `""`, whose length is `0`. The `+` operator joins two strings and `*` repeats a string, so `"ab" + "cd"` is `"abcd"` and `"ab" * 3` is `"ababab"`. Joining a string to a number is an error: convert the number with `str()` first.

### Indexing: one character at a time

Every character has a position called its **index**, and Python counts from zero. In `"python"`, the `p` is at index 0, `y` at 1 and `n` at 5. You pick a character with square brackets: `word[0]` is `"p"`. A beginner's picture is a row of numbered boxes, where the first box is number 0, not 1. This is why the last valid index is always `len(text) - 1`. Asking for an index that does not exist, such as `word[6]`, raises an `IndexError`.

Negative indexes count from the end: `word[-1]` is the last character, `word[-2]` the one before it. This is more convenient than working out `len(word) - 1`.

Each index gives back a new string of length one. There is no separate "character" type in Python.

### Slicing: a part of the string

A **slice** takes several characters at once. The form is `text[start:stop]`. It includes the character at `start` and stops just before `stop`. A useful way to remember this is that the numbers point at the gaps between characters, so `"python"[1:4]` is the characters between gap 1 and gap 4, which is `"yth"`. The length of a slice is `stop - start`.

Either number can be left out. A missing `start` means "from the beginning" and a missing `stop` means "to the end", so `word[:2]` is the first two characters and `word[-3:]` is the last three. A third number is the **step**: `word[::2]` takes every second character, and `word[::-1]` walks backwards, which reverses the string. Unlike an index, a slice never raises an error when the numbers are too large; it just returns what exists.

### Strings are immutable

**Immutable** means that a value cannot be changed after it is created. You can read any character of a string, but you cannot assign to one: `word[0] = "P"` raises a `TypeError`. When you want a different string, you build a new one, for example `"P" + word[1:]`, and attach a name to it. The same rule explains the most common beginner bug with methods. A method such as `upper()` does not change the string it is called on; it returns a new string. Writing `name.upper()` on a line by itself therefore does nothing visible, because the new string is thrown away. You must store it: `name = name.upper()`.

### Methods

A **method** is a function that belongs to a value and is called with a dot: `text.upper()`. Because it belongs to the value, you do not pass the string in; it is already there. The methods you will use most are:

- `upper()`, `lower()` and `title()` change the case. Lowercasing is the usual first step before comparing text.
- `strip()` removes spaces and line breaks from both ends (`lstrip()` and `rstrip()` do one end). Messy data nearly always carries stray spaces.
- `replace(old, new)` replaces every occurrence of `old` with `new`.
- `find(part)` returns the index where `part` first appears, or `-1` when it is absent. `count(part)` returns how many times it appears without overlapping.
- `startswith(part)` and `endswith(part)` return `True` or `False`.
- `isdigit()` returns `True` when every character is a digit and the string is not empty.

Because each method returns a string, you can **chain** them: `raw.strip().lower()` strips first and then lowercases the result. Methods are case-sensitive about their arguments: `"Data".find("d")` is `-1` because `D` and `d` are different characters.

### The in operator

`part in text` is `True` when `part` appears anywhere inside `text` and `False` otherwise; `not in` is the reverse. It works on pieces, not only on single characters: `"base" in "database"` is `True`. It is case-sensitive, so `"Base" in "database"` is `False`.

### Escape sequences

Some characters cannot be typed directly inside a string, such as a line break or a quote that matches the surrounding quotes. An **escape sequence** is a backslash followed by a letter or symbol that stands for one special character. `\n` is a new line, `\t` is a tab, `\\` is one backslash, and `\"` and `\'` are quote characters. Each sequence is a single character, so `len("a\nb")` is `3`, not `4`. Backslashes need care in Windows file paths: `"C:\new"` contains a newline, while `"C:\\new"` is the path you meant.

### Common misconception

Learners often think `name.upper()` has changed `name`. It has not. Strings are immutable, so every method returns a fresh string and the original stays as it was.

### Why it matters

Real datasets are full of text: names, emails, product codes, cities, dates written as text. Almost all cleaning work, such as removing stray spaces, fixing case, pulling a code out of a longer identifier or checking a pattern, uses exactly the tools in this lesson.

## Syntax and key functions

Index and slice:

```python
text[index]
text[start:stop]
text[start:stop:step]
```

`index` is a position starting at 0, negative counts from the end. In a slice `start` is included and `stop` is excluded; any of the three numbers may be omitted.

Call a method:

```python
new_text = text.method(arguments)
```

The method is called on the value with a dot. It returns a new value; `text` itself never changes.

Test membership:

```python
part in text
part not in text
```

Both return `True` or `False`.

| Expression | Returns | Example result |
|---|---|---|
| `len(text)` | Number of characters. | `len("data")` is `4` |
| `text[0]`, `text[-1]` | First and last character. | `"python"[0]` is `"p"` |
| `text[1:4]` | Characters 1 up to 3. | `"python"[1:4]` is `"yth"` |
| `text[::-1]` | The text reversed. | `"abc"[::-1]` is `"cba"` |
| `a + b`, `a * 3` | Join, repeat. | `"ab" * 2` is `"abab"` |
| `text.upper()` / `.lower()` / `.title()` | New string with changed case. | `"ada".title()` is `"Ada"` |
| `text.strip()` | New string without edge whitespace. | `"  x ".strip()` is `"x"` |
| `text.replace(a, b)` | New string with every `a` replaced. | `"a-b".replace("-", "_")` is `"a_b"` |
| `text.find(part)` | Index of first match, or `-1`. | `"data".find("t")` is `2` |
| `text.count(part)` | Number of matches. | `"banana".count("an")` is `2` |
| `text.startswith(part)` | `True` or `False`. | `"report.csv".endswith(".csv")` is `True` |
| `text.isdigit()` | `True` if all digits. | `"2024".isdigit()` is `True` |

| Escape | Meaning |
|---|---|
| `\n` | New line |
| `\t` | Tab |
| `\\` | One backslash |
| `\"` and `\'` | A quote character |

## Learn by example

### Example 1: Length and indexes

The word `"analytics"` has nine characters, indexed 0 to 8. A positive index counts from the left and a negative index from the right. `len(word) - 1` is the last valid positive index, and it gives the same character as `-1`.

```python run
word = "analytics"
print(len(word))
print(word[0])
print(word[3])
print(word[-1])
print(word[len(word) - 1])
print(word[-3])
```

```output
9
a
l
s
s
i
```

### Example 2: Slicing

The start index is included and the stop index is not. Leaving out a number means "from the beginning" or "to the end". The slice `[::-1]` steps backwards and reverses the text. A stop index that is too large does not cause an error.

```python run
code = "DF-2024-0137"
print(code[0:2])
print(code[3:7])
print(code[:2])
print(code[-4:])
print(code[::2])
print(code[::-1])
print(code[8:100])
```

```output
DF
2024
DF
0137
D-0403
7310-4202-FD
0137
```

### Example 3: Strings cannot be changed, but you can build a new one

Assigning to `word[0]` would raise a `TypeError`, so that line is shown only as text. To get a changed string, join a new first character to a slice of the old one. Calling `upper()` without storing the result leaves `word` as it was, while assigning it gives the new value.

```text
word = "python"
word[0] = "P"
TypeError
```

```python run
word = "python"
changed = "P" + word[1:]
print(changed)
print(word)

word.upper()
print(word)
word = word.upper()
print(word)
```

```output
Python
python
python
PYTHON
```

### Example 4: Cleaning text with methods

Raw data often has stray spaces and mixed case. The first block strips and lowercases an email. The `find` and `count` calls then inspect the cleaned text, and `find` returns `-1` for something that is absent. `replace` swaps every dot in the local part, and methods can be chained in a single line.

```python run
raw = "  Ana.Silva@Example.COM  "
email = raw.strip().lower()
print(email)
print(len(raw), len(email))
print(email.find("@"))
print(email.find("#"))
print(email.count("a"))
print(email.startswith("ana"), email.endswith(".org"))
print(email.replace(".", "_"))
print("2024".isdigit(), "20.4".isdigit())
```

```output
ana.silva@example.com
25 21
9
-1
4
True False
ana_silva@example_com
True False
```

### Example 5: in and escape sequences

`in` is a case-sensitive substring test that returns `True` or `False`. The escape `\n` starts a new line inside one `print` call, `\t` inserts a tab, and `\\` prints a single backslash. A quote of the same kind as the surrounding quotes needs a backslash, or you can switch to the other kind. The escape sequence counts as one character.

```python run
email = "ana.silva@example.com"
print("@" in email)
print("example" in email, "Example" in email)
print("#" not in email)

print("first line\nsecond line")
print("name\tcity")
print("C:\\data\\sales.csv")
print("She said \"ok\" and 'done'")
print(len("a\nb"))
```

```output
True
True False
True
first line
second line
name	city
C:\data\sales.csv
She said "ok" and 'done'
3
```

### Example 6: Building a text report with + and *

A header line is built from the title and an underline of the same length, made with `*` and `len()`. Numbers must be converted with `str()` before being joined to text with `+`, which is why `str(rows)` appears. A comma in `print()` would avoid the conversion, but `+` builds a single string you can store or measure.

```python run
title = "Load report"
rows = 1250
print(title)
print("=" * len(title))
line = "Rows loaded: " + str(rows)
print(line)
print(len(line))
print("-" * 12 + ">")
```

```output
Load report
===========
Rows loaded: 1250
17
------------>
```

## Real-world applications

- **Cleaning identifiers and names.** Customer names arrive as `"  aNa  sILVA "` from different systems. `strip()`, `lower()` or `title()` and `replace()` make them consistent before they are compared or counted, so the same customer is not counted twice.
- **Pulling parts out of codes.** A product code such as `DF-2024-0137` encodes a year and a serial number. Slicing, as in Example 2, extracts each part, and `find()` locates a separator when the lengths vary.
- **Validating and screening text.** `in`, `startswith()`, `endswith()` and `isdigit()` flag rows that look wrong, for example an email without an `@`, a file name that does not end in `.csv` or a postcode that contains letters.
- **Formatting plain-text output.** Log lines, console reports and small exports are built from strings with `+`, `*` and escapes such as `\n` and `\t`, as in Example 6. Tab-separated text is a common export format.

## Daily review

### Key takeaways

- Strings are ordered characters with indexes from 0 (and from -1 at the end); `len()` counts them.
- In a slice `text[start:stop]` the start is included, the stop is excluded, and omitted numbers mean the ends.
- Strings are immutable: methods return new strings, so store the result to keep it.
- `strip()`, `lower()`, `replace()`, `find()`, `count()` and `startswith()` handle most cleaning and checking jobs, and they chain.
- `in` tests for a substring and is case-sensitive; escapes such as `\n`, `\t` and `\\` are single characters.

### Common mistakes

- Counting from 1 instead of 0, which picks the wrong character or raises an `IndexError`.
- Expecting `text[1:4]` to include index 4.
- Calling `text.strip()` or `text.lower()` and not storing the result.
- Trying to assign to a character, such as `text[0] = "X"`.
- Joining a string and a number with `+` without calling `str()`.
- Forgetting that `find()` returns `-1` when the text is missing, and then using `-1` as if it were a real position.
- Writing a Windows path with single backslashes, so that sequences such as `\n` or `\t` are read as escapes.

### Revision notes

- `"python"[0]` is `"p"`, `[-1]` is `"n"`, `[1:4]` is `"yth"`, `[::-1]` is `"nohtyp"`.
- `new = text.strip().lower()`: methods return new strings.
- `find` gives `-1` when absent; `count` counts non-overlapping matches.
- `part in text` is `True` or `False`, case-sensitive.
- `\n` new line, `\t` tab, `\\` backslash; each one is a single character.
