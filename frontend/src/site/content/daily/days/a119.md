## Objectives

- Draw line, bar, scatter and histogram charts with `plotly.express` from a long-format DataFrame and explain what each argument maps.
- Read a figure's data and layout (`fig.data`, `fig.layout.title.text`) to check a chart without opening it.
- Customise hover text with `hover_name`, `hover_data` and `labels`.
- Choose a continuous colour scale and build an animated chart with `animation_frame`.

## Understand

### What Plotly Express is

Plotly is a charting library whose charts are interactive: they are rendered by a JavaScript engine in a browser, so a viewer can hover to read values, zoom, pan, and click legend entries to hide series. **Plotly Express**, imported as `px`, is the short, high-level interface: one function call per chart type, taking a DataFrame and column names, much like seaborn. Because the output is HTML and JavaScript rather than an image, Plotly charts are used in notebooks, dashboards and web pages, and the figure is also a plain data structure that you can inspect from Python.

### Figures are data

A Plotly `Figure` has two parts. `fig.data` is a tuple of **traces**: one trace per series, such as one line, one set of bars or one set of markers, each holding its own `x` and `y` arrays, a `name`, and a `hovertemplate`. `fig.layout` holds everything that is not data: the title (`fig.layout.title.text`), the axis titles (`fig.layout.xaxis.title.text`), the legend, the size, the colour scales and the template (the theme). When you write `px.line(df, x="month", y="revenue", color="category")`, Express splits the table by `category` and creates one trace per value, which is why four categories give `len(fig.data) == 4`. This is the Plotly equivalent of reading `ax.lines` in matplotlib: it lets you test that a chart has the series you meant it to have.

### Mapping columns to the chart

The core idea of Express is that you map **columns to visual roles**, with keyword arguments, instead of drawing marks by hand. `x` and `y` give the positions; `color` splits the data into groups with different colours (or, for a numeric column, applies a colour scale); `size` scales marker area; `symbol` varies marker shape; `facet_col` and `facet_row` make small multiples; `text` or `text_auto=True` writes values on bars; and `title` sets the title. Data should be in the long format used by seaborn (one row per observation, one column per variable); wide data is reshaped with `melt` first. Names such as `revenue` become axis titles by default, so use `labels={"revenue": "Revenue (GBP)"}` to give them units.

### Hover

Interactivity is the main reason to choose Plotly. Hover text, the box that appears when the pointer is over a mark, is built from a `hovertemplate`. Express sets a sensible one, and you shape it with `hover_name` (the bold heading, such as a customer or category), `hover_data` (extra columns, or a dict like `{"revenue": ":,.0f"}` to format a value with thousands separators and no decimals), and `labels`. Put identifiers in hover (order id, name) and keep the visible chart uncluttered; hover is where the detail belongs. Remember that hover does not exist on paper, in a PDF, or on a phone without a pointer, so a chart must still carry its message without it.

### Colour scales

For a categorical column, `color` uses a discrete sequence (`px.colors.qualitative.Plotly` is the default list of hex colours). For a numeric column it uses a **continuous colour scale**: `color_continuous_scale="Viridis"` maps low to high along a perceptually even scale; adding `_r` (`"Viridis_r"`) reverses it. Use sequential scales (one hue getting darker, or Viridis) for values that run from low to high, and diverging scales (`"RdBu"`) only where there is a meaningful middle. A colour bar is created automatically and its title is the column name, which `labels=` changes. Choose scales that remain readable for readers with colour-vision differences; Viridis was designed for that, and Day 122 returns to this.

### Animation

`animation_frame="month"` creates one **frame** per distinct value of the column and adds a play button and a slider. The figure stores the frames in `fig.frames`, each with the data for that value. Animation is good for showing change over time in a presentation, but it asks the viewer to remember earlier frames, and it is poor for comparison across time; a line chart or small multiples usually serves analysis better. If you animate, fix the axis ranges with `range_y=[0, 3000]` so the axis does not rescale and jump between frames.

### Misconceptions and why it matters

Plotly figures are not images, so `print(fig)` shows a data structure and nothing is drawn until you display or export the figure. Many learners also assume interactive is better; it is better only if the viewer has a question the hover answers. In analyst work Plotly appears in dashboards and exploratory notebooks, where readers want to look up values themselves. As with every chart so far, compute the numbers in pandas, then check that `fig.data[i].y` contains them.

## Syntax and key functions

```python
fig = px.line(df, x="month", y="revenue", color="category", title="Monthly revenue",
              labels={"revenue": "Revenue (GBP)"})
fig = px.bar(df, x="category", y="revenue", text_auto=".0f",
             category_orders={"category": ["Electronics", "Home"]})
fig = px.scatter(df, x="unit_price", y="revenue", color="shipping_days",
                 color_continuous_scale="Viridis", hover_name="category", hover_data=["quantity"])
fig = px.histogram(df, x="revenue", nbins=10)
fig = px.bar(df, x="category", y="revenue", animation_frame="month", range_y=[0, 3000])
```

| Item | What it is or returns |
|---|---|
| `px.line`, `px.bar`, `px.scatter`, `px.histogram` | Return a `Figure` |
| `color=`, `size=`, `symbol=`, `facet_col=` | Map a column to colour, size, shape, panels |
| `labels={"col": "Text"}` | Rename axis and legend titles |
| `hover_name`, `hover_data` | Bold hover heading; extra hover columns or formats |
| `color_continuous_scale` | Name of a numeric colour scale; add `_r` to reverse |
| `animation_frame` | Column whose values become frames |
| `fig.data` | Tuple of traces; each has `x`, `y`, `name`, `hovertemplate` |
| `fig.layout.title.text` | The title text |
| `fig.frames` | Animation frames |
| `fig.show()`, `fig.write_html(path)` | Display or export (Day 120) |

## Learn by example

### Example 1: Long format for Plotly

Plotly Express wants one row per observation. This example builds the monthly revenue per category in long format, the table the line chart will consume, and checks its shape. It runs in the browser.

```python run
import numpy as np
import pandas as pd


def make_orders():
    rng = np.random.default_rng(7)
    n = 240
    category = rng.choice(["Home", "Electronics", "Beauty", "Sports"], size=n, p=[0.35, 0.2, 0.25, 0.2])
    base = pd.Series({"Home": 45, "Electronics": 160, "Beauty": 28, "Sports": 60})
    df = pd.DataFrame({
        "order_date": pd.Timestamp("2025-01-01") + pd.to_timedelta(rng.integers(0, 365, n), unit="D"),
        "category": category,
        "quantity": rng.integers(1, 6, n),
        "unit_price": (base[category].to_numpy() * (0.8 + 0.4 * rng.random(n))).round(2),
        "shipping_days": rng.integers(1, 9, n),
    })
    df["revenue"] = (df["quantity"] * df["unit_price"]).round(2)
    return df.sort_values("order_date").reset_index(drop=True)

orders = make_orders()
orders["month"] = orders["order_date"].dt.month
long = orders.groupby(["month", "category"], as_index=False)["revenue"].sum().round(0)
print(long.head(4).to_string(index=False))
print("rows:", len(long), "| categories:", long["category"].nunique(), "| months:", long["month"].nunique())
```

```output
 month    category  revenue
     1      Beauty    164.0
     1 Electronics   1620.0
     1        Home   1266.0
     1      Sports    449.0
rows: 47 | categories: 4 | months: 12
```

### Example 2: A line chart with one trace per category

`color="category"` splits the table, so there is one trace per category. The prints read the title, axis titles, trace names and the first values of one trace. Because Plotly is not available in the browser runner, this is a local example (`pip install plotly pandas numpy`).

        "category": category,
        "quantity": rng.integers(1, 6, n),

        "shipping_days": rng.integers(1, 9, n),
    })
    df["revenue"] = (df["quantity"] * df["unit_price"]).round(2)
    return df.sort_values("order_date").reset_index(drop=True)

### Example 3: Bars with values and a custom hover

A sorted bar chart. `text_auto=".0f"` prints values on bars and `hover_data` formats the value in the hover box with a thousands separator. The x and y of the single trace carry the data, and `hovertemplate` shows the hover format that Express built.

```python local
import plotly.express as px
import numpy as np
import pandas as pd


def make_orders():
    rng = np.random.default_rng(7)
    n = 240
    category = rng.choice(["Home", "Electronics", "Beauty", "Sports"], size=n, p=[0.35, 0.2, 0.25, 0.2])
    base = pd.Series({"Home": 45, "Electronics": 160, "Beauty": 28, "Sports": 60})
    df = pd.DataFrame({
        "order_date": pd.Timestamp("2025-01-01") + pd.to_timedelta(rng.integers(0, 365, n), unit="D"),
        "category": category,
        "quantity": rng.integers(1, 6, n),
        "unit_price": (base[category].to_numpy() * (0.8 + 0.4 * rng.random(n))).round(2),
        "shipping_days": rng.integers(1, 9, n),
    })
    df["revenue"] = (df["quantity"] * df["unit_price"]).round(2)
    return df.sort_values("order_date").reset_index(drop=True)

orders = make_orders()
by_cat = orders.groupby("category", as_index=False)["revenue"].sum().round(0).sort_values("revenue", ascending=False)

fig = px.bar(by_cat, x="category", y="revenue", text_auto=".0f", hover_data={"revenue": ":,.0f"},
             title="Electronics earns the most", labels={"revenue": "Revenue (GBP)"})
bar = fig.data[0]
print("type:", bar.type, "| bars:", len(bar.x))
print("x:", list(bar.x))
print("y:", [float(v) for v in bar.y])
print("hover:", bar.hovertemplate)
```

```output

x: ['Electronics', 'Home', 'Sports', 'Beauty']
y: [22694.0, 11917.0, 9087.0, 5267.0]
hover: category=%{x}<br>Revenue (GBP)=%{y:,.0f}<extra></extra>
```

A scatter of unit price against revenue, coloured by shipping days (a numeric column) with the Viridis scale. Hover shows the category as the heading and the quantity as an extra. The colour axis sits in `fig.layout.coloraxis`, and its title comes from the column or from `labels`.

### Example 5: Animation frames

One frame per month, each showing revenue by category. Fixing `range_y` keeps the axis steady. The figure stores one frame per month and one slider step for each; the check shows that the number of frames equals the number of distinct months in the data.

import pandas as pd


def make_orders():

        "category": category,
        "quantity": rng.integers(1, 6, n),
        "unit_price": (base[category].to_numpy() * (0.8 + 0.4 * rng.random(n))).round(2),
        "shipping_days": rng.integers(1, 9, n),
    })
    df["revenue"] = (df["quantity"] * df["unit_price"]).round(2)
    return df.sort_values("order_date").reset_index(drop=True)

orders = make_orders()

## Real-world applications

- **Exploratory notebooks.** An analyst draws a scatter with hover names (Example 4) and points the pointer at outliers to identify the customer or order behind them.
- **Dashboards and web reports.** Plotly figures embed in web pages, and the hover formatting from Example 3 gives readers exact numbers without crowding the chart.
- **Presentations of change over time.** An animated bar (Example 5) steps through months in a live walkthrough, with the axis fixed so heights are comparable across frames.
- **Chart tests.** Reading `fig.data` and `fig.layout` in a unit test (Examples 2 and 3) checks that an automated report has the right series and titles before it is published.

## Daily review

### Key takeaways

- Plotly Express maps columns to roles (`x`, `y`, `color`, `size`, `facet_col`, `animation_frame`) from a long-format DataFrame.
- A figure is data: `fig.data` holds the traces and `fig.layout` holds titles, axes and colour scales.
- `color` on a category creates one trace per value; on a number it applies a continuous scale.
- `hover_name`, `hover_data` and `labels` shape the hover box, but the chart must work without hover.
- Animation needs fixed axis ranges and is rarely the best way to compare.

### Common mistakes

- Passing wide data and getting one trace for the whole table. Symptom: a single colour and a confusing legend. Fix: `melt` or `groupby` to long format and use `color=`.
- Using a diverging scale for values with no middle. Symptom: reds and blues that imply "good" and "bad". Fix: a sequential scale such as `Viridis`.
- Leaving the animation axis free. Symptom: bars jumping in height between frames. Fix: `range_y=[0, max]`.
- Printing the figure and expecting a picture. Symptom: a long data dump. Fix: `fig.show()` in a notebook or `fig.write_html`, or read `fig.data` for checks.

### Revision notes

- `px.line/bar/scatter/histogram(df, x, y, color, title, labels)`.
- `fig.data[i].x/.y/.name/.hovertemplate`; `fig.layout.title.text`.
- `hover_name`, `hover_data={"col": ":,.0f"}`; `color_continuous_scale="Viridis"`.
- `animation_frame="month", range_y=[...]`; `len(fig.frames)`.
