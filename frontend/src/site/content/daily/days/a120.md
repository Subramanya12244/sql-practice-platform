## Understand

### graph_objects: the layer under Express

Yesterday's `px` functions are shortcuts. Underneath, every Plotly figure is built from `plotly.graph_objects`, usually imported as `go`: a `go.Figure` holds a list of **traces** (objects such as `go.Scatter`, `go.Bar`, `go.Histogram`) and a **layout**. Express builds the figure for you from a DataFrame; with `graph_objects` you build it yourself, trace by trace. You do that when Express cannot express what you want: mixing a bar and a line in one chart, drawing series that come from different tables, or controlling every property of a mark. The two are not rivals. An Express figure is a `go.Figure`, so you can create it with `px` and then adjust it with the methods below.

The core calls are `fig = go.Figure()`, `fig.add_trace(go.Scatter(x=..., y=..., mode="lines+markers", name="Home"))` for each series, and `fig.update_layout(title=..., xaxis_title=..., yaxis_title=...)` for everything else. `mode` chooses what a scatter trace draws: `"lines"`, `"markers"` or `"lines+markers"`. Two helper methods apply a change to many objects at once: `fig.update_traces(...)` edits every trace and `fig.update_xaxes(...)` / `update_yaxes(...)` edits the axes. As on previous days, read `fig.data` and `fig.layout` back to check what you built.

### Interactivity

Interactivity is a set of layout options that the JavaScript engine acts on in the viewer's browser. Three are useful from the start. **Hover mode** controls what appears when the pointer moves: `hovermode="x unified"` shows one box listing every series at the pointer's x position, which is the best choice for time series because it compares the series at the same month. A **range slider** (`fig.update_xaxes(rangeslider_visible=True)`) adds a small overview strip below the chart that the viewer drags to zoom into a time window. A **dropdown** is an `updatemenus` entry with buttons; each button holds a `method` and `args` describing the change to apply. With `method="update"`, the first argument changes trace properties, for instance `{"visible": [True, False, False, False]}` shows only the first of four traces, and the second changes layout properties, such as a new title. Because the buttons hold fixed instructions, the dropdown works in a static HTML file with no Python running.

The practical limit of this approach is that all the data is stored in the figure. A dropdown switches between traces that already exist; it does not query a database. For a few thousand points that is perfect, and for millions of points it makes the HTML file huge and slow.

### Combining charts: a small dashboard

A **dashboard** is a single page that shows several charts or numbers about one subject so that a reader can answer a set of related questions at a glance. The simplest dashboard in Plotly is one figure with several panels, built with `make_subplots(rows=1, cols=2, subplot_titles=("Line", "Bar"))`, then `fig.add_trace(trace, row=1, col=1)` to place each trace. The panels share the figure's layout, hover and export. When a dashboard needs to react to the viewer's choices by running Python (filtering a database, recalculating a number), the standard step beyond this is Dash, Plotly's separate web-application framework, which is outside today's lesson. Good dashboard design uses what Day 114 taught: one question per panel, a title that states the finding, consistent colours for the same category in every panel, and few panels.

### Exporting

A figure can leave Python in several forms. `fig.write_html("chart.html")` writes a standalone web page: the interactive chart, which anyone can open in a browser. By default the file embeds the Plotly JavaScript library, which makes it large (a few megabytes); `include_plotlyjs="cdn"` links to a copy on the internet instead, giving a small file that needs a connection to display. `fig.to_json()` returns the figure as a JSON string with two keys, `data` and `layout`, which is the format for saving a figure, sending it to a web front end, or testing it. Static images (`fig.write_image("chart.png")`) need an extra export package installed (Kaleido) and are for reports and slides where interactivity is not possible. Choose the format by where the chart will be read.

### Misconceptions and why it matters

One misconception is that an HTML export is a "screenshot": it is a live chart carrying all its data, which also means that anyone who receives the file receives the data behind it. Check this before sending a chart that contains sensitive rows. A second is that interactivity replaces design: a chart that depends on a hover to be understood fails in print and on slides. Interactivity matters for analysts because stakeholders ask follow-up questions in the meeting, and a dropdown or hover often answers them without a second chart; building it with `go` gives you control that Express does not.

## Syntax and key functions

```python
fig = go.Figure()
fig.add_trace(go.Scatter(x=months, y=values, mode="lines+markers", name="Home"))
fig.update_layout(title="Monthly revenue", xaxis_title="Month", yaxis_title="Revenue (GBP)",
                  hovermode="x unified")
fig.update_xaxes(rangeslider_visible=True)
fig.update_traces(hovertemplate="%{y:,.0f} GBP<extra>%{fullData.name}</extra>")
fig.add_hline(y=3000, line_dash="dash", annotation_text="Target")

button = dict(label="Home", method="update",
              args=[{"visible": [True, False]}, {"title": {"text": "Home revenue"}}])
fig.update_layout(updatemenus=[dict(buttons=[button], direction="down")])

sub = make_subplots(rows=1, cols=2, subplot_titles=("Line", "Bar"))
sub.add_trace(go.Bar(x=names, y=totals), row=1, col=2)
fig.write_html("chart.html", include_plotlyjs="cdn")
fig.to_json()
```

| Item | What it does or returns |
|---|---|
| `go.Figure()` | Empty figure; `fig.data` is `()` and `fig.layout` is empty |
| `go.Scatter`, `go.Bar` | Trace classes; take `x`, `y`, `name`, `mode` |
| `fig.add_trace(trace, row=, col=)` | Adds a trace, optionally to a subplot panel |
| `fig.update_layout(...)` | Sets title, axis titles, hover mode, menus |
| `fig.update_traces(...)`, `update_xaxes(...)` | Edit all traces or axes |
| `fig.add_hline(y=)` | Horizontal reference line (adds a shape) |
| `updatemenus` buttons | Dropdown/buttons with `label`, `method`, `args` |
| `make_subplots(rows, cols, subplot_titles)` | Figure with a grid of panels |
| `fig.write_html(path, include_plotlyjs="cdn")` | Standalone interactive page |
| `fig.to_json()` | JSON string with `data` and `layout` |

## Learn by example

### Example 1: Visibility masks on paper

A dropdown button shows one series by giving each trace `True` or `False` for `visible`. This pure-Python example builds those lists for four traces, which is the logic behind Example 3. It runs in the browser.

```python run
import numpy as np
import pandas as pd


def make_orders():
    rng = np.random.default_rng(7)
    n = 240
    category = rng.choice(["Home", "Electronics", "Beauty", "Sports"], size=n, p=[0.35, 0.2, 0.25, 0.2])
    base = pd.Series({"Home": 45, "Electronics": 160, "Beauty": 28, "Sports": 60})
    df = pd.DataFrame({
        "order_date": pd.Timestamp("2025-01-01") + pd.to_timedelta(rng.integers(0, 365, n), unit="D"),
        "category": category,
        "quantity": rng.integers(1, 6, n),
        "unit_price": (base[category].to_numpy() * (0.8 + 0.4 * rng.random(n))).round(2),
        "shipping_days": rng.integers(1, 9, n),
    })
    df["revenue"] = (df["quantity"] * df["unit_price"]).round(2)
    return df.sort_values("order_date").reset_index(drop=True)

orders = make_orders()
orders["month"] = orders["order_date"].dt.month
table = orders.pivot_table(index="month", columns="category", values="revenue", aggfunc="sum", fill_value=0).round(0)
names = list(table.columns)
masks = {name: [other == name for other in names] for name in names}
for name, mask in masks.items():
    print(name, mask)
print("series:", len(names), "| months:", len(table))
```

```output
Beauty [True, False, False, False]
Electronics [False, True, False, False]
Home [False, False, True, False]
Sports [False, False, False, True]
series: 4 | months: 12
```

### Example 2: Build a figure trace by trace

One `go.Scatter` per category with lines and markers, then the layout. The checks read the number of traces, their names and modes, the title and the axis titles, and one trace's first values. Plotly is not available in the browser, so this is a local example.

```python local

import numpy as np

    n = 240

    df = pd.DataFrame({
        "order_date": pd.Timestamp("2025-01-01") + pd.to_timedelta(rng.integers(0, 365, n), unit="D"),
        "category": category,
        "quantity": rng.integers(1, 6, n),
        "unit_price": (base[category].to_numpy() * (0.8 + 0.4 * rng.random(n))).round(2),
        "shipping_days": rng.integers(1, 9, n),
    })
    df["revenue"] = (df["quantity"] * df["unit_price"]).round(2)
    return df.sort_values("order_date").reset_index(drop=True)

orders = make_orders()

table = orders.pivot_table(index="month", columns="category", values="revenue", aggfunc="sum", fill_value=0).round(0)
fig = go.Figure()
for name in table.columns:
    fig.add_trace(go.Scatter(x=list(table.index), y=list(table[name]), mode="lines+markers", name=name))
```

### Example 3: Hover, range slider and a dropdown

Three interactive features on the same figure. The dropdown has one button per category, each with a visibility mask like Example 1 and a new title. Everything is stored in the layout, so the checks read it back: the hover mode, the slider flag, the number of buttons and the first button's mask.

```python local
import plotly.graph_objects as go
import numpy as np
import pandas as pd


def make_orders():
    rng = np.random.default_rng(7)
    n = 240
    category = rng.choice(["Home", "Electronics", "Beauty", "Sports"], size=n, p=[0.35, 0.2, 0.25, 0.2])
    base = pd.Series({"Home": 45, "Electronics": 160, "Beauty": 28, "Sports": 60})
    df = pd.DataFrame({
        "order_date": pd.Timestamp("2025-01-01") + pd.to_timedelta(rng.integers(0, 365, n), unit="D"),
        "category": category,
        "quantity": rng.integers(1, 6, n),
        "unit_price": (base[category].to_numpy() * (0.8 + 0.4 * rng.random(n))).round(2),
        "shipping_days": rng.integers(1, 9, n),
    })
    df["revenue"] = (df["quantity"] * df["unit_price"]).round(2)
    return df.sort_values("order_date").reset_index(drop=True)

orders = make_orders()
orders["month"] = orders["order_date"].dt.month
table = orders.pivot_table(index="month", columns="category", values="revenue", aggfunc="sum", fill_value=0).round(0)
names = list(table.columns)
fig = go.Figure()
for name in names:
    fig.add_trace(go.Scatter(x=list(table.index), y=list(table[name]), mode="lines+markers", name=name))
buttons = [dict(label=name, method="update",
                args=[{"visible": [other == name for other in names]}, {"title": {"text": name + " revenue"}}])
           for name in names]
fig.update_layout(title="Monthly revenue", hovermode="x unified", updatemenus=[dict(buttons=buttons, direction="down")])
fig.update_xaxes(rangeslider_visible=True)

menu = fig.layout.updatemenus[0]
print("hover mode:", fig.layout.hovermode)
print("range slider:", fig.layout.xaxis.rangeslider.visible)
print("buttons:", [b.label for b in menu.buttons])
print("first mask:", menu.buttons[0].args[0]["visible"])
print("second title:", menu.buttons[1].args[1]["title"]["text"])
```

```output

range slider: True
buttons: ['Beauty', 'Electronics', 'Home', 'Sports']
first mask: [True, False, False, False]
second title: Electronics revenue
```

### Example 4: A two-panel dashboard

`make_subplots` creates a figure with a line panel for one category and a bar panel for the totals of all of them, plus a target line. Every trace knows which panel it belongs to through its axis names (`x`, `y` for the first panel and `x2`, `y2` for the second).

```python local
import plotly.graph_objects as go
from plotly.subplots import make_subplots
import numpy as np
import pandas as pd


def make_orders():
    rng = np.random.default_rng(7)
    n = 240
    category = rng.choice(["Home", "Electronics", "Beauty", "Sports"], size=n, p=[0.35, 0.2, 0.25, 0.2])
    base = pd.Series({"Home": 45, "Electronics": 160, "Beauty": 28, "Sports": 60})
    df = pd.DataFrame({
        "order_date": pd.Timestamp("2025-01-01") + pd.to_timedelta(rng.integers(0, 365, n), unit="D"),
        "category": category,
        "quantity": rng.integers(1, 6, n),
        "unit_price": (base[category].to_numpy() * (0.8 + 0.4 * rng.random(n))).round(2),
        "shipping_days": rng.integers(1, 9, n),
    })
    df["revenue"] = (df["quantity"] * df["unit_price"]).round(2)
    return df.sort_values("order_date").reset_index(drop=True)

orders = make_orders()
orders["month"] = orders["order_date"].dt.month
table = orders.pivot_table(index="month", columns="category", values="revenue", aggfunc="sum", fill_value=0).round(0)
totals = table.sum()
fig = make_subplots(rows=1, cols=2, subplot_titles=("Home by month", "Total by category"))
fig.add_trace(go.Scatter(x=list(table.index), y=list(table["Home"]), name="Home"), row=1, col=1)
fig.add_trace(go.Bar(x=list(totals.index), y=list(totals.values), name="Total"), row=1, col=2)
fig.add_hline(y=1000, line_dash="dash", annotation_text="Target", row=1, col=1)
fig.update_layout(title="Home trades steadily; Electronics earns the most", showlegend=False)

print("traces:", len(fig.data), [type(t).__name__ for t in fig.data])
print("panel titles:", [a.text for a in fig.layout.annotations if a.text != "Target"])
print("axes of traces:", [(t.xaxis, t.yaxis) for t in fig.data])
print("reference lines:", len(fig.layout.shapes), "at", fig.layout.shapes[0].y0)
```

```output
traces: 2 ['Scatter', 'Bar']
panel titles: ['Home by month', 'Total by category']
axes of traces: [('x', 'y'), ('x2', 'y2')]
reference lines: 1 at 1000
```

### Example 5: Export to HTML and JSON

A figure is written to a temporary folder as a standalone HTML page with the library loaded from a CDN, and converted to JSON. The checks do not print file sizes (they vary); they confirm the file exists, contains the chart title, and that the JSON has the two top-level keys.

```python local
import json
import os
import tempfile
import plotly.graph_objects as go

fig = go.Figure(go.Bar(x=["A", "B", "C"], y=[3, 5, 2]))
fig.update_layout(title="Demo export")

with tempfile.TemporaryDirectory() as folder:
    path = os.path.join(folder, "chart.html")
    fig.write_html(path, include_plotlyjs="cdn")
    with open(path) as handle:
        page = handle.read()
    print("html written:", os.path.getsize(path) > 0)
    print("contains title:", "Demo export" in page)
    print("uses cdn:", "cdn.plot.ly" in page)

parsed = json.loads(fig.to_json())
print("json keys:", sorted(parsed))
print("json y values:", parsed["data"][0]["y"])
```

```output
html written: True
contains title: True
uses cdn: True
json keys: ['data', 'layout']
json y values: [3, 5, 2]
```

## Real-world applications

- **Stakeholder meetings.** A dropdown by category (Example 3) lets a manager switch between series live, answering follow-up questions without a second chart.
- **Self-contained reports.** `write_html` (Example 5) produces a file that can be emailed and opened in any browser, with hover and zoom intact.
- **Mixed charts.** A bar and a line in one figure, or a panel layout (Example 4), cover cases that a single Express call cannot, such as totals next to a trend.
- **Automated tests and archives.** Storing `fig.to_json()` records exactly what was published, and a test can reload and check it.

## Daily review

### Key takeaways

- `graph_objects` builds figures trace by trace; Express figures are `go.Figure` objects too.
- Interactivity lives in the layout: `hovermode`, a range slider, and `updatemenus` buttons with `method` and `args`.
- A dropdown switches between traces that already exist; all the data travels with the figure.
- `make_subplots` is the simplest dashboard; Dash is the framework for dashboards that run Python on demand.
- `write_html` is for readers, `to_json` is for storage and tests, and image export needs an extra package.

### Common mistakes

- A `visible` list with the wrong length. Symptom: a button hides or shows the wrong series. Fix: one entry per trace, in trace order.
- Sending an HTML export without thinking about the data inside. Symptom: sensitive rows readable by anyone who views the page source. Fix: aggregate before plotting.
- Putting every chart on one page. Symptom: a dashboard no one can read. Fix: one question per panel, a few panels, consistent colours.
- Relying on hover for the main message. Symptom: a chart useless on a slide or in print. Fix: put the finding in the title and direct labels.

### Revision notes

- `go.Figure()`, `add_trace(go.Scatter(..., mode="lines+markers", name=...))`, `update_layout(...)`.
- `hovermode="x unified"`; `update_xaxes(rangeslider_visible=True)`.
- Button: `dict(label=, method="update", args=[{"visible": [...]}, {"title": {"text": ...}}])`.
- `make_subplots(rows, cols)`, `add_trace(row=, col=)`; `write_html(include_plotlyjs="cdn")`; `to_json()`.
