## Objectives

- Build a boolean mask from a condition on a column and use it to keep only the matching rows.
- Combine conditions with `&`, `|` and `~`, with parentheses around each condition.
- Test for membership with `isin()` and for ranges with `between()`.
- Write the same filter with `df.query("...")` and explain when `query` is clearer.
- Count and sum the matching rows with `mask.sum()` and select columns in the same step with `loc`.

## Understand

### Filtering is the WHERE clause of pandas

Most questions about data begin with a subset: the orders over 100, the customers in Oslo or Rome, the readings in March. In SQL you wrote a `WHERE` clause. In pandas you use a **boolean mask**, the same idea as on Day 64 for NumPy arrays. A comparison on a column such as `df["qty"] > 5` does not return one answer. It returns a Series of `True` and `False` values, one per row, with the same index as the table. Putting that mask inside the brackets of the DataFrame, `df[df["qty"] > 5]`, keeps only the rows where it is `True`. Read it as "the rows of `df` where `qty` is greater than 5". The result is a smaller DataFrame with all the columns and the original row labels kept, so a row that used to be number 4 is still labelled 4.

It helps to separate the two steps, especially at the start: first `mask = df["qty"] > 5`, then `df[mask]`. Printing the mask lets you see which rows are selected before you apply it. The comparison operators are `==`, `!=`, `<`, `<=`, `>` and `>=`. Note the double equals for "is equal to": a single `=` assigns, and `df["city"] = "Oslo"` would overwrite the column instead of testing it.

### Combining conditions

Real filters have several conditions. The operators for combining masks are `&` (and), `|` (or) and `~` (not), exactly as for NumPy. The Python words `and`, `or` and `not` do not work on whole Series, because a Series of many booleans has no single truth value, and they raise a `ValueError: The truth value of a Series is ambiguous`. Each condition must be wrapped in parentheses, because `&` and `|` are applied before the comparison operators: `df[(df["qty"] > 5) & (df["city"] == "Oslo")]`. Without parentheses you get a confusing error about comparing a Series with a string.

`~` flips a mask: `~(df["city"] == "Oslo")` is true for every row that is not in Oslo, and it is the clear way to say "everything except".

### isin and between

Writing `(df["city"] == "Oslo") | (df["city"] == "Rome") | (df["city"] == "Lima")` is long and error-prone. `df["city"].isin(["Oslo", "Rome", "Lima"])` says it in one step. It returns a mask that is true where the value is in the list, the pandas form of SQL's `IN`. With `~` in front it becomes `NOT IN`.

For ranges, `df["price"].between(5, 10)` is true where the value is from 5 to 10 **including both ends**, which is the same as SQL's `BETWEEN` and shorter than `(df["price"] >= 5) & (df["price"] <= 10)`. A parameter `inclusive="neither"` or `"left"` or `"right"` changes which ends are included.

### The query method

`df.query("qty > 5 and city == 'Oslo'")` expresses the same filter as a string. Inside the string, column names are used directly, `and`, `or` and `not` are allowed (they work here because `query` translates the expression for you), `in` works with lists as in `city in ['Oslo', 'Rome']`, and you can refer to a Python variable with an at sign: `df.query("qty > @limit")`. The query is often easier to read for filters with several conditions. Its limits: it only filters rows (it returns a DataFrame of the matching rows), and column names with spaces need backticks, as in `` `unit price` > 3 ``. Mistyped column names fail with `UndefinedVariableError`, which means a name inside the string was not found among the columns or variables.

### Using the mask for more than filtering

A mask is a normal Series of booleans, so you can use it in other ways. `mask.sum()` counts the rows that match, because `True` counts as 1. `mask.mean()` gives the share of rows that match. `df.loc[mask, "price"]` selects the rows where the mask is true and only the `price` column, in one step, as a Series. The same form can be used to set values: `df.loc[mask, "city"] = "Big"` changes only the matching rows. This replaces the loops you would otherwise write, and it is the same mask-assignment idea as `a[a > 45] = 45` on arrays from Day 64. Because it is an assignment, work on a copy when the original must stay unchanged.

### Missing values and masks

A comparison with a missing value (`NaN`) is always `False`, so `df["price"] > 5` does not select rows with a missing price, and `~(df["price"] > 5)` does select them, together with the rows that are 5 or less. That second effect surprises beginners: the opposite of "greater than 5" is not "5 or less" when values are missing. Missing values get proper treatment on Day 74; for now note that a missing value never satisfies a comparison.

### The common misconception

Two mistakes dominate. First, using `and` or `or` instead of `&` and `|`, which raises the "truth value is ambiguous" error. Second, forgetting the parentheses, so that `df["a"] > 1 & df["b"] < 5` is evaluated as `df["a"] > (1 & df["b"]) < 5`, which fails with a `TypeError` or a `ValueError`. The error message does not mention parentheses, so remember the rule: every condition in its own parentheses.

### Why it matters in data work

Filtering is the most frequent operation in analysis. Every report, quality check and sample selection starts with it, and the mask is also the tool for counting problems (how many rows are negative?) and for fixing them (set those rows to missing). Knowing that the mask is just a Series of booleans makes the rest of pandas easier, because the same idea returns when you group, replace and clean data. Always check the number of rows after a filter, with `len` or `shape`: a filter that returns zero rows, or all of them, usually means a typo in the condition or a text value with a stray space.

## Syntax and key functions

Mask and filter:

```python
mask = df["qty"] > 5
df[mask]
df[(df["qty"] > 5) & (df["city"] == "Oslo")]
df[df["city"].isin(["Oslo", "Rome"])]
df[df["price"].between(5, 10)]
df.query("qty > 5 and city == 'Oslo'")
df.loc[mask, ["city", "qty"]]
```

| Expression | Returns |
|---|---|
| `df["x"] > 5` | A boolean Series, one value per row. |
| `df[mask]` | The rows where the mask is true, all columns. |
| `m1 & m2`, `m1 | m2`, `~m` | Element-wise and, or, not of masks. |
| `s.isin(list)` | True where the value is in the list. |
| `s.between(a, b)` | True where `a <= value <= b` (both ends included). |
| `df.query("expr")` | The rows that satisfy the expression string. |
| `df.query("x > @limit")` | A query using a Python variable. |
| `mask.sum()`, `mask.mean()` | Number and share of matching rows. |
| `df.loc[mask, cols]` | Matching rows and chosen columns. |

## Learn by example

### Example 1: A mask and the filtered table

The comparison gives one boolean per row. Indexing the table with it keeps the matching rows, and the original row labels stay. The mask can be counted, and `==` tests text.

```python run
import pandas as pd

pd.set_option("display.width", 200)
pd.set_option("display.max_columns", 20)

df = pd.DataFrame({"city": ["Oslo", "Rome", "Oslo", "Lima", "Rome", "Oslo"],
                   "qty": [3, 8, 6, 2, 9, 4], "price": [9.5, 4.0, 12.25, 7.0, 3.5, 8.0]})
mask = df["qty"] > 5
print(mask.tolist())
print(df[mask])
print(mask.sum(), round(mask.mean(), 2))
print(df[df["city"] == "Oslo"]["qty"].tolist())
print(len(df[df["price"] > 100]))
```

```output

   city  qty  price
1  Rome    8   4.00
2  Oslo    6  12.25
4  Rome    9   3.50
3 0.5
[3, 6, 4]
0
```

### Example 2: Combining conditions

`&` means both conditions, `|` means either, and `~` negates. Each condition is in parentheses. The last lines show that the Python word `and` fails on whole columns.

```python run
import pandas as pd

pd.set_option("display.width", 200)
pd.set_option("display.max_columns", 20)

df = pd.DataFrame({"city": ["Oslo", "Rome", "Oslo", "Lima", "Rome", "Oslo"],
                   "qty": [3, 8, 6, 2, 9, 4], "price": [9.5, 4.0, 12.25, 7.0, 3.5, 8.0]})
print(df[(df["city"] == "Oslo") & (df["qty"] > 3)])
print(df[(df["qty"] < 3) | (df["price"] > 10)]["qty"].tolist())
print(df[~(df["city"] == "Oslo")]["city"].tolist())
try:
    df[(df["qty"] > 3) and (df["price"] > 5)]
except ValueError as e:
    print("ValueError:", str(e)[:36])
```

```output
   city  qty  price
2  Oslo    6  12.25
5  Oslo    4   8.00
[6, 2]
['Rome', 'Lima', 'Rome']
ValueError: The truth value of a Series is ambig
```

### Example 3: isin and between

`isin` replaces a chain of `or` conditions and `~` gives "not in". `between` includes both ends, so a price of exactly 4.0 or 8.0 is kept.

```python run
import pandas as pd

pd.set_option("display.width", 200)
pd.set_option("display.max_columns", 20)

df = pd.DataFrame({"city": ["Oslo", "Rome", "Oslo", "Lima", "Rome", "Oslo"],
                   "qty": [3, 8, 6, 2, 9, 4], "price": [9.5, 4.0, 12.25, 7.0, 3.5, 8.0]})
print(df[df["city"].isin(["Rome", "Lima"])])
print(df[~df["city"].isin(["Rome", "Lima"])]["city"].tolist())
print(df[df["price"].between(4, 8)]["price"].tolist())
print(df[df["price"].between(4, 8, inclusive="neither")]["price"].tolist())
print(df["city"].isin(["Oslo"]).sum())
```

```output
   city  qty  price
1  Rome    8    4.0
3  Lima    2    7.0
4  Rome    9    3.5
['Oslo', 'Oslo', 'Oslo']
[4.0, 7.0, 8.0]
[7.0]
3
```

### Example 4: The same filters with query

`query` writes the condition as one string. It allows `and`, `or`, `in`, and the at sign for Python variables. The results equal the mask versions, which `equals` confirms.

```python run
import pandas as pd

pd.set_option("display.width", 200)
pd.set_option("display.max_columns", 20)

df = pd.DataFrame({"city": ["Oslo", "Rome", "Oslo", "Lima", "Rome", "Oslo"],
                   "qty": [3, 8, 6, 2, 9, 4], "price": [9.5, 4.0, 12.25, 7.0, 3.5, 8.0]})
a = df.query("city == 'Oslo' and qty > 3")
b = df[(df["city"] == "Oslo") & (df["qty"] > 3)]
print(a)
print(a.equals(b))
limit = 7
print(df.query("qty > @limit")["qty"].tolist())
print(df.query("city in ['Rome', 'Lima'] or price > 12")["city"].tolist())
print(df.query("price >= 4 and price <= 8")["price"].tolist())
```

```output
   city  qty  price
2  Oslo    6  12.25
5  Oslo    4   8.00
True
[8, 9]
['Rome', 'Oslo', 'Lima', 'Rome']
[4.0, 7.0, 8.0]
```

### Example 5: Counting and fixing with a mask, and missing values

`loc` with a mask and a column name selects or sets just those cells. A copy is edited so the original stays. A missing price never passes a comparison, so `~` of a mask also picks up the missing row.

```python run
import pandas as pd

pd.set_option("display.width", 200)
pd.set_option("display.max_columns", 20)

df = pd.DataFrame({"item": ["a", "b", "c", "d", "e"], "price": [5.0, -1.0, 12.0, None, 7.5]})
bad = df["price"] < 0
print(bad.sum(), df.loc[bad, "item"].tolist())
fixed = df.copy()
fixed.loc[bad, "price"] = 0.0
print(fixed["price"].tolist())
print(df["price"].tolist())
print((df["price"] > 6).sum(), (~(df["price"] > 6)).sum())
print(df.loc[df["price"] > 6, ["item", "price"]].to_dict("list"))
```

```output
1 ['b']
[5.0, 0.0, 12.0, nan, 7.5]
[5.0, -1.0, 12.0, nan, 7.5]
2 3
{'item': ['c', 'e'], 'price': [12.0, 7.5]}
```

### Example 6: A realistic report

Orders are filtered to those from two cities with a value (quantity times price) over 20, the total value and the share of orders that qualified are reported, and the matching ids are listed. Everything uses masks and column arithmetic.

```python run
import io
import pandas as pd

pd.set_option("display.width", 200)
pd.set_option("display.max_columns", 20)

text = """id,city,qty,price
1,Oslo,3,9.5
2,Rome,8,4.0
3,Oslo,6,12.25
4,Lima,2,7.0
5,Rome,9,3.5
6,Oslo,4,8.0
7,Lima,5,6.5
"""
orders = pd.read_csv(io.StringIO(text))
value = orders["qty"] * orders["price"]
big = orders[orders["city"].isin(["Oslo", "Rome"]) & (value > 20)]
print(big)
print(round(value[big.index].sum(), 2), round(len(big) / len(orders), 3))
print(orders.query("qty * price > 20")["id"].tolist())
```

```output

0   1  Oslo    3   9.50
1   2  Rome    8   4.00
2   3  Oslo    6  12.25
4   5  Rome    9   3.50
5   6  Oslo    4   8.00
197.5 0.714
[1, 2, 3, 5, 6, 7]
```

## Real-world applications

- **Selecting subsets for a report.** Orders from certain regions over a threshold, as in Example 6, are `isin` plus a comparison combined with `&`.
- **Counting problems.** `mask.sum()` counts negative or impossible values, as in Example 5, and the share `mask.mean()` shows how widespread the problem is.
- **Fixing selected rows.** `df.loc[mask, "col"] = value` corrects exactly the rows that break a rule, while a copy keeps the raw table.
- **Readable business rules.** A long rule becomes one clear `query` string, as in Example 4, which analysts can read, review and paste into documentation.

## Daily review

### Key takeaways

- A comparison on a column gives a boolean Series; `df[mask]` keeps the rows where it is `True` and keeps the original labels.
- Combine with `&`, `|` and `~`, each condition in parentheses; `and`, `or` and `not` fail on Series.
- `isin` is `IN`; `between` is `BETWEEN` with both ends included.
- `query("...")` writes the same filter as a string, with `@name` for variables.
- `mask.sum()` counts rows; `df.loc[mask, col]` selects or sets matching cells; missing values never satisfy a comparison.

### Common mistakes

- Using `and` or `or` between Series, which raises `ValueError: The truth value of a Series is ambiguous`. Use `&` and `|`.
- Forgetting parentheses around each condition, which gives a `TypeError` or `ValueError`.
- Writing `df["city"] = "Oslo"` (assignment) instead of `df["city"] == "Oslo"` (test).
- Expecting `~(x > 5)` to mean `x <= 5` when there are missing values.
- Filtering text with a stray space or a different case, and getting zero rows. Check with `value_counts`.
- Using a name in `query` that is not a column and not marked with `@`, which raises `UndefinedVariableError`.

### Revision notes

- `df[df["a"] > 5]`, `df[(m1) & (m2)]`, `df[(m1) | (m2)]`, `df[~m]`.
- `s.isin([...])`, `s.between(a, b)`, `df.query("a > 5 and b == 'x'")`, `@var`.
- `mask.sum()`, `mask.mean()`, `df.loc[mask, "col"] = v`.
