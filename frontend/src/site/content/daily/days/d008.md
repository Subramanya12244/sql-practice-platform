## Understand

### What a list is

A **list** (type `list`) is an ordered collection of values written in square brackets, with commas between the items: `prices = [12.5, 8, 30]`. You have used single values so far, one name for one number or string. A list lets one name hold many values, which is how you hold a column of data, such as every order total in a day. The items can be of any type and the types can be mixed, though in data work a list usually holds items of one kind. The empty list is `[]`, and `len(prices)` is the number of items.

A list is **mutable**: unlike the strings you met on Day 4, you can change a list in place. Replacing an item with `prices[0] = 15` changes the list itself, and no new list is made.

### Indexing

Items have positions called **indexes**, counted from zero, exactly as in strings. In `names = ["Ada", "Grace", "Linus"]`, `names[0]` is `"Ada"` and `names[2]` is `"Linus"`. Negative indexes count from the end: `names[-1]` is the last item. An index that does not exist, such as `names[3]`, raises `IndexError: list index out of range`. The last valid index is always `len(names) - 1`.

### Changing a list

Four methods cover most changes. A **method** is a function that belongs to a value and is called with a dot.

- `append(x)` adds `x` at the end.
- `insert(i, x)` puts `x` at index `i` and shifts the later items one place to the right.
- `remove(x)` deletes the first item equal to `x`, and raises `ValueError` if there is none.
- `pop(i)` removes the item at index `i` and returns it; without an index it removes the last item. `del names[i]` removes the item at `i` without returning it.

The key habit: these methods change the list and return `None` (except `pop`, which returns the removed item). So `names = names.append("Zoe")` is a bug: the list is changed, then the name is overwritten with `None`. Call the method on its own line.

Removing items shifts the positions of later ones. The mental model is a queue of people: when someone leaves from the middle, everyone behind steps forward, and their numbers drop by one.

### Slicing

A **slice** `items[start:stop:step]` returns a **new list** containing the items from `start` up to but not including `stop`, moving by `step`. As with strings, a missing start means the beginning, a missing stop means the end, and a negative step walks backwards. `items[:3]` is the first three items, `items[-2:]` the last two, and `items[::-1]` a reversed copy. A slice never raises an error for going past the end; it just gives fewer items.

### Sorting

`items.sort()` sorts the list **in place** and returns `None`. `sorted(items)` leaves the original alone and **returns a new sorted list**. Both take `reverse=True` for descending order. Numbers sort by value and strings sort by character codes, so capital letters come before lowercase letters. A list that mixes numbers and strings cannot be sorted and raises `TypeError`. Beginners often write `ranked = scores.sort()` and find that `ranked` is `None`; use `sorted()` when you want a result to assign.

### Copying, and the misconception about assignment

Writing `backup = scores` does **not** copy the list. It gives the same list a second name, so a change through either name is visible through both. A picture helps: two name tags tied to one box. To get a separate list, use `scores.copy()` or the slice `scores[:]`. These make a **shallow copy**: a new outer list holding the same items. That is enough for lists of numbers and strings. If the items are themselves lists, the inner lists are still shared.

### Why it matters

Most data arrives as sequences: rows, values in a column, names in a file. Lists are the first tool for holding such sequences, and the next days build on them.

### A worked trace

Follow the list through these lines, writing the list after each step. Start with `tasks = ["a", "b", "c"]`. After `tasks.insert(1, "x")` it is `["a", "x", "b", "c"]`, because "x" took position 1 and "b" and "c" moved right. After `tasks.pop()` it is `["a", "x", "b"]`, and the value `"c"` was returned. After `tasks.remove("a")` it is `["x", "b"]`, and `"x"` is now at index 0. Notice that the index of "b" changed from 1 to 2 and then to 1 again. Code that stores an index and later changes the list can end up pointing at a different item, so recompute positions after you add or remove items.

Two more habits help. Check that a list is not empty before reading `items[0]` or `items[-1]`, because an empty list has no first or last item and both raise `IndexError: list index out of range`. And remember that a list can hold other lists: `grid = [[1, 2], [3, 4]]` has `grid[1][0]` equal to `3`, the first item of the second inner list.

## Syntax and key functions

```text
items = [a, b, c]            # create
items[i]                      # read the item at index i (negative counts from the end)
items[i] = value              # replace an item
items.append(x)               # add at the end
items.insert(i, x)            # add at position i
items.remove(x)               # delete first item equal to x
items.pop()  /  items.pop(i)  # remove and return an item
items[start:stop:step]        # slice: a new list
items.sort(reverse=False)     # sort in place
sorted(items)                 # new sorted list
items.copy()  /  items[:]     # shallow copy
```

| Function or method | What it returns |
|---|---|
| `len(items)` | the number of items |
| `items.append(x)`, `insert`, `remove`, `sort` | `None` (the list is changed) |
| `items.pop(i)` | the removed item |
| `sorted(items)` | a new sorted list |
| `items.index(x)` | the index of the first item equal to `x` |
| `items.count(x)` | how many items equal `x` |
| `sum(items)`, `min(items)`, `max(items)` | total, smallest, largest of numbers |
| `x in items` | `True` if some item equals `x` |

## Learn by example

### Example 1: Create, index and change

```python run
names = ["Ada", "Grace", "Linus"]
print(names[0], names[-1], len(names))
names[1] = "Margaret"
names.append("Guido")
names.insert(1, "Alan")
print(names)
print(len(names))
```

```output
Ada Linus 3
['Ada', 'Alan', 'Margaret', 'Linus', 'Guido']
5
```

`insert(1, "Alan")` pushed `"Margaret"` and the later names one place to the right.

### Example 2: Removing items

```python run
tasks = ["email", "report", "call", "report", "lunch"]
tasks.remove("report")
print(tasks)
last = tasks.pop()
print(last, tasks)
second = tasks.pop(1)
print(second, tasks)
del tasks[0]
print(tasks)
print("lunch" in tasks)
```

```output
['email', 'call', 'report', 'lunch']
lunch ['email', 'call', 'report']
call ['email', 'report']
['report']
False
```

`remove` took out only the first `"report"`. Each `pop` shortened the list and returned what it removed.

### Example 3: Slicing

```python run
scores = [55, 70, 82, 91, 64, 78]
print(scores[:3])
print(scores[-2:])
print(scores[1:5:2])
print(scores[::-1])
print(scores[4:100])
print(scores)
```

```output
[55, 70, 82]
[64, 78]
[70, 91]
[78, 64, 91, 82, 70, 55]
[64, 78]
[55, 70, 82, 91, 64, 78]
```

Every slice is a new list. The original `scores` is unchanged in the last line.

### Example 4: Sorting, in place and not

```python run
scores = [55, 70, 82, 91, 64, 78]
ranked = sorted(scores, reverse=True)
print(ranked)
print(scores)
result = scores.sort()
print(result)
print(scores)
words = ["banana", "Cherry", "apple"]
words.sort()
print(words)
```

```output
[91, 82, 78, 70, 64, 55]
[55, 70, 82, 91, 64, 78]
None
[55, 64, 70, 78, 82, 91]
['Cherry', 'apple', 'banana']
```

`sorted()` returned a new list and left `scores` alone. `sort()` changed `scores` and returned `None`. `"Cherry"` comes before `"apple"` because capital letters sort first.

### Example 5: Assignment is not a copy

```python run
a = [1, 2, 3]
b = a
b.append(4)
print(a, b, a is b)
c = a.copy()
c.append(5)
print(a, c, a is c)
d = a[:]
d[0] = 99
print(a, d)
```

```output
[1, 2, 3, 4] [1, 2, 3, 4] True
[1, 2, 3, 4] [1, 2, 3, 4, 5] False
[1, 2, 3, 4] [99, 2, 3, 4]
```

`b` and `a` are one list, so appending through `b` changed `a`. `c` and `d` are separate lists.

### Example 6: A small report

The program removes an invalid value, sorts the rest and reports the top three and the average, using `sum()` and `len()`.

```python run
daily_sales = [120, 340, -1, 95, 410, 275, 180]
daily_sales.remove(-1)
top3 = sorted(daily_sales, reverse=True)[:3]
average = sum(daily_sales) / len(daily_sales)
print("Top 3:", top3)
print("Average:", round(average, 1))
print("Best day index:", daily_sales.index(max(daily_sales)))
```

```output
Top 3: [410, 340, 275]
Average: 236.7
Best day index: 3
```

## Real-world applications

- **Holding a column of values.** A list of order totals can be summed, averaged, sorted or sliced for a "top 5" report.
- **Queues of work.** `append()` and `pop(0)` model a list of records waiting to be processed.
- **Leaderboards and rankings.** `sorted(..., reverse=True)[:n]` gives the best n items without disturbing the source data.
- **Safe experiments.** `copy()` lets you clean or reorder a working version of a list while keeping the raw data intact.

## Daily review

### Key takeaways

- A list is an ordered, mutable collection; indexes start at 0 and negative indexes count from the end.
- `append`, `insert`, `remove` and `sort` change the list and return `None`; `pop` returns the removed item.
- A slice is a new list, and slices never raise `IndexError`.
- `sort()` works in place; `sorted()` returns a new list.
- `b = a` shares one list; `copy()` or `[:]` makes a separate one.

### Common mistakes

- **Assigning the result of `append` or `sort`.** `names = names.append("x")` leaves `names` as `None`, and the next use fails with `TypeError: 'NoneType' object is not iterable` or similar. Call the method on its own line.
- **Index out of range.** `names[len(names)]` raises `IndexError: list index out of range`. The last index is `len(names) - 1`, or `-1`.
- **Thinking `b = a` copies.** Changes through `b` appear in `a`. Use `a.copy()`.
- **`remove` of a missing value.** `ValueError: list.remove(x): x not in list`. Check `x in items` first.
- **Sorting mixed types.** `[3, "a"].sort()` raises `TypeError: '<' not supported between instances of 'str' and 'int'`. Convert to one type first.

### Revision notes

- `[ ]`, index from 0, negative from the end, `len()`.
- Change: `append`, `insert`, `remove`, `pop`, `del`.
- Slice `[start:stop:step]` makes a new list.
- `sort()` in place returns `None`; `sorted()` returns a list.
- Copy with `.copy()` or `[:]`.
