## Objectives

- Choose a chart type for each analytical question and justify it by what the data contains.
- Build the capstone charts with matplotlib and an interactive chart with plotly, and verify them by printing figure properties.
- Check a chart specification against design rules (title, labels, baseline, sorting, category count) with code.
- Write the Power BI page as steps with DAX measures, and verify every number the cards would show with pandas.

## Understand

### What this stage produces

Day 176 produced the numbers. This stage produces three charts in Python, one interactive chart, and the specification for a Power BI page that presents the same results. Charts answer the questions from Day 172: the trend of monthly net revenue, which channel returns the most per unit of spend, and which category is returned most. A chart that does not answer a question does not belong in the deliverable, however attractive it is.

### Choosing the chart from the question

The question decides the chart. A trend over time is a line chart, because the order of months matters and the eye follows the slope. A comparison of a number across categories is a bar chart, sorted by value, so the ranking is visible without reading labels. Parts of a whole across many categories are better shown as a sorted bar than a pie. Every chart needs a title that states what is measured, axis labels with units, and a baseline: bar lengths encode values, so a bar chart axis must start at zero, or a small difference looks enormous. These rules can be checked by code, which is what Example 2 does with a chart specification.

### Verifying a chart without looking at it

The browser tests cannot look at an image, so you verify a chart by its properties: the title and labels, the number of bars or points, the data behind the marks and the axis baseline. This is also good practice in real projects, where a chart is generated by a script and a regression is caught by a test that the data behind the chart did not change. In matplotlib, `ax.get_title()`, `ax.lines[0].get_ydata()` and `ax.patches` expose those properties. In plotly, `fig.data` holds the traces, each with its `x` and `y`, and `fig.layout` holds the title and the menus.

### Interactivity

An interactive chart lets the viewer filter or switch the measure without a new chart for each. In plotly, hover text is set with `hovertemplate`, and a dropdown is a list of buttons in `updatemenus` that switch which data is visible. In Power BI the equivalent is cross-filtering between visuals and slicers. Interactivity is a tool for exploration, not decoration: add it when the viewer has a real choice to make, such as country or measure.

### The Power BI page

Power BI Desktop is not available in the browser, so this day gives the page as steps with a model answer. The brief's sample model has a `Sales` fact table related to `Customers`, `Products` and a `Calendar` table. The capstone export adds `discount_pct` and `returned` columns to `Sales`, because net revenue needs them. The measures are written in DAX (Data Analysis Expressions), and each number they should show is computed here with pandas, so the page can be checked against a verified result.

### Common misconception

Learners often start from the chart tool and ask what it can draw. Start from the question and the table behind the chart: if you cannot state in one sentence what the chart shows and what decision it supports, redo the question.

## Syntax and key functions

```python
fig, ax = plt.subplots()
ax.plot(x, y, marker="o")
ax.bar(labels, values)
ax.set_title("..."); ax.set_xlabel("..."); ax.set_ylabel("...")
```

```python
fig = go.Figure(go.Bar(x=labels, y=values, hovertemplate="%{x}: %{y}<extra></extra>"))
fig.update_layout(title_text="...", updatemenus=[...])
```

| Call | Returns |
|---|---|
| `ax.get_title()` | The axes title text |
| `ax.lines[0].get_ydata()` | The y values of the first line |
| `ax.patches` | The bars (rectangles); `len` is the number of bars |
| `[p.get_height() for p in ax.patches]` | Bar heights |
| `fig.data` | Tuple of plotly traces |
| `fig.layout.title.text` | The plotly title |
| `fig.layout.updatemenus[0].buttons` | The dropdown or button options |

## Learn by example

### Example 1: The three capstone charts in matplotlib

A line chart for the monthly trend and two sorted bar charts. The script prints each chart's title, labels, number of marks and data, since an image cannot be compared in a test.

```python local
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt
import numpy as np
import pandas as pd


def generate(seed=7):
    """Seeded online-store data with planted defects: 500 orders, 120 customers, 20 products."""
    rng = np.random.default_rng(seed)
    customers = pd.DataFrame({
        "customer_id": np.arange(1, 121),
        "country": rng.choice(["DE", "FR", "UK", "US"], 120, p=[0.3, 0.2, 0.2, 0.3]),
        "signup_date": pd.Timestamp("2024-07-01") + pd.to_timedelta(rng.integers(0, 180, 120), unit="D"),
    })
    customers.loc[rng.choice(120, 8, replace=False), "country"] = "us "
    products = pd.DataFrame({
        "product_id": np.arange(1, 21),
        "category": np.repeat(["home", "beauty", "sports", "electronics"], 5),
        "unit_price": (10 + rng.random(20) * 90).round(2),
    })
    campaigns = pd.DataFrame({
        "campaign_id": [0, 1, 2, 3],
        "channel": ["organic", "email", "paid_search", "social"],
        "spend": [0.0, 800.0, 2500.0, 1200.0],
    })
    n = 500
    orders = pd.DataFrame({
        "order_id": np.arange(1001, 1001 + n),
        "customer_id": rng.integers(1, 121, n),
        "product_id": rng.integers(1, 21, n),
        "order_date": pd.Timestamp("2025-01-01") + pd.to_timedelta(rng.integers(0, 180, n), unit="D"),
        "quantity": rng.integers(1, 5, n),
        "discount_pct": rng.choice([0, 10, 20], n, p=[0.6, 0.25, 0.15]),
        "campaign_id": rng.choice([0, 1, 2, 3], n, p=[0.4, 0.2, 0.25, 0.15]),
    })
    orders.loc[rng.choice(n, 5, replace=False), "quantity"] = -1
    orders.loc[rng.choice(n, 6, replace=False), "customer_id"] = 999
    orders = pd.concat([orders, orders.sample(10, random_state=1)], ignore_index=True)
    returned = rng.choice(np.arange(1001, 1001 + n), 60, replace=False)
    returns = pd.DataFrame({
        "order_id": np.concatenate([returned, [9001, 9002, 9003]]),
        "reason": rng.choice(["damaged", "wrong_item", "changed_mind"], 63, p=[0.3, 0.2, 0.5]),
    })
    return {"orders": orders, "customers": customers, "products": products, "campaigns": campaigns, "returns": returns}



def clean(t):
    """Apply the quality rules; return cleaned tables and a row-accounting log."""
    log = {}
    o = t["orders"]
    log["raw_orders"] = len(o)
    o = o.drop_duplicates()
    log["after_duplicates"] = len(o)
    o = o[o["quantity"] > 0]
    log["after_quantity"] = len(o)
    c = t["customers"].copy()
    c["country"] = c["country"].str.strip().str.upper()
    o = o[o["customer_id"].isin(c["customer_id"])]
    log["after_customers"] = len(o)
    r = t["returns"]
    log["raw_returns"] = len(r)
    r = r[r["order_id"].isin(o["order_id"])].drop_duplicates("order_id")
    log["clean_returns"] = len(r)
    p = t["products"]
    o = o.merge(p[["product_id", "unit_price"]], on="product_id", how="left")
    o["revenue"] = (o["quantity"] * o["unit_price"] * (1 - o["discount_pct"] / 100)).round(2)
    o["returned"] = o["order_id"].isin(r["order_id"])
    return {"orders": o.reset_index(drop=True), "customers": c, "products": p, "campaigns": t["campaigns"], "returns": r.reset_index(drop=True)}, log



def prepare(ct):
    """Analysis tables from the clean data: orders with category, channel and month, plus the three chart series."""
    o = ct["orders"].merge(ct["products"][["product_id", "category"]], on="product_id")
    o = o.merge(ct["campaigns"][["campaign_id", "channel"]], on="campaign_id")
    o["month"] = o["order_date"].dt.month
    net = o[~o["returned"]]
    net_month = net.groupby("month")["revenue"].sum().round(2)
    spend = ct["campaigns"].set_index("channel")["spend"]
    roas = (net.groupby("channel")["revenue"].sum() / spend[spend > 0]).dropna().round(2)
    rate = (o.groupby("category")["returned"].mean() * 100).round(1)
    return o, net_month, roas, rate


ct, log = clean(generate())
o, net_month, roas, rate = prepare(ct)
fig, axes = plt.subplots(1, 3, figsize=(15, 4))
axes[0].plot(net_month.index, net_month.values, marker="o")
axes[0].set_title("Net revenue by month, 2025")
axes[0].set_xlabel("Month")
axes[0].set_ylabel("Net revenue")
r = roas.sort_values(ascending=False)
axes[1].bar(r.index, r.values)
axes[1].set_title("Return on spend by channel")
axes[1].set_xlabel("Channel")
axes[1].set_ylabel("Net revenue per unit of spend")
c = rate.sort_values(ascending=False)
axes[2].bar(c.index, c.values)
axes[2].set_title("Return rate by category")
axes[2].set_xlabel("Category")
axes[2].set_ylabel("Returned orders (%)")
for ax in axes:
    print(ax.get_title(), "|", ax.get_xlabel(), "|", ax.get_ylabel())
print("line points:", [round(float(v), 2) for v in axes[0].lines[0].get_ydata()])
print("roas bars:", [round(float(p.get_height()), 2) for p in axes[1].patches])
print("rate bars:", [round(float(p.get_height()), 1) for p in axes[2].patches])
print("bar baselines at zero:", axes[1].get_ylim()[0] == 0.0 and axes[2].get_ylim()[0] == 0.0)
plt.close(fig)
```

```output
Net revenue by month, 2025 | Month | Net revenue
Return on spend by channel | Channel | Net revenue per unit of spend
Return rate by category | Category | Returned orders (%)
line points: [8082.83, 8665.04, 8725.74, 7255.76, 10677.92, 9223.7]
roas bars: [13.68, 5.58, 5.37]
rate bars: [14.5, 12.8, 11.8, 8.7]
bar baselines at zero: True
```

### Example 2: Check chart specifications with code

A chart specification is a small dictionary. The checker returns the design problems it finds, so a weak chart is caught before anyone sees it. The same pandas results provide the figures a Power BI card page would show.

def check_spec(spec):
    problems = []
    if not spec.get("title"):
        problems.append("no title")
    if not spec.get("xlabel") or not spec.get("ylabel"):
        problems.append("missing axis label")
    if spec["kind"] == "bar" and spec.get("ymin", 0) != 0:
        problems.append("bar baseline not zero")
    if spec["kind"] == "bar" and spec["values"] != sorted(spec["values"], reverse=True):
        problems.append("bars not sorted")
    if spec["kind"] == "pie":
        problems.append("use a sorted bar instead of a pie")
    if len(spec["values"]) > 7 and spec["kind"] != "line":
        problems.append("too many categories")
    return problems


ct, log = clean(generate())
o, net_month, roas, rate = prepare(ct)
good = {"kind": "bar", "title": "Return rate by category", "xlabel": "Category", "ylabel": "Returned orders (%)", "values": sorted(rate.tolist(), reverse=True)}
weak = {"kind": "bar", "title": "", "xlabel": "Category", "ylabel": "", "ymin": 8, "values": rate.sort_index().tolist()}
print("good:", check_spec(good))
print("weak:", check_spec(weak))
net_total = o.loc[~o["returned"], "revenue"].sum()
print("cards -> net revenue:", round(float(net_total), 2), "| orders:", len(o), "| return rate:", round(float(o["returned"].mean() * 100), 1), "%")
print("best channel by return on spend:", roas.idxmax(), roas.max())

### Example 4: The Power BI page, verified in pandas

The Power BI steps are written below. They cannot run here, so every number the page shows is computed with pandas first. These are the DAX measures, shown but not run:

```dax
Gross Revenue = SUMX ( Sales, Sales[quantity] * Sales[unit_price] * ( 1 - Sales[discount_pct] / 100 ) )
Net Revenue = CALCULATE ( [Gross Revenue], Sales[returned] = FALSE () )
Return Rate = DIVIDE ( CALCULATE ( COUNTROWS ( Sales ), Sales[returned] = TRUE () ), COUNTROWS ( Sales ) )
```

The page: three cards (Net Revenue, Orders, Return Rate), a line chart of Net Revenue by `Calendar[month_name]`, a bar chart of Return Rate by `Products[category]` sorted descending, and a slicer on `Customers[country]`. Selecting a country in the slicer cross-filters all visuals through the relationships. The block computes what each card shows with the slicer on every country and on one country.

    })
    orders.loc[rng.choice(n, 5, replace=False), "quantity"] = -1
    orders.loc[rng.choice(n, 6, replace=False), "customer_id"] = 999
    orders = pd.concat([orders, orders.sample(10, random_state=1)], ignore_index=True)
    returned = rng.choice(np.arange(1001, 1001 + n), 60, replace=False)
    returns = pd.DataFrame({
        "order_id": np.concatenate([returned, [9001, 9002, 9003]]),
        "reason": rng.choice(["damaged", "wrong_item", "changed_mind"], 63, p=[0.3, 0.2, 0.5]),
    })
    return {"orders": orders, "customers": customers, "products": products, "campaigns": campaigns, "returns": returns}



def clean(t):
    """Apply the quality rules; return cleaned tables and a row-accounting log."""
    log = {}
    o = t["orders"]
    log["raw_orders"] = len(o)
    o = o.drop_duplicates()
    log["after_duplicates"] = len(o)
    o = o[o["quantity"] > 0]
    log["after_quantity"] = len(o)
    c = t["customers"].copy()
    c["country"] = c["country"].str.strip().str.upper()
    o = o[o["customer_id"].isin(c["customer_id"])]
    log["after_customers"] = len(o)
    r = t["returns"]
    log["raw_returns"] = len(r)
    r = r[r["order_id"].isin(o["order_id"])].drop_duplicates("order_id")
    log["clean_returns"] = len(r)
    p = t["products"]
    o = o.merge(p[["product_id", "unit_price"]], on="product_id", how="left")
    o["revenue"] = (o["quantity"] * o["unit_price"] * (1 - o["discount_pct"] / 100)).round(2)
    o["returned"] = o["order_id"].isin(r["order_id"])
    return {"orders": o.reset_index(drop=True), "customers": c, "products": p, "campaigns": t["campaigns"], "returns": r.reset_index(drop=True)}, log



def prepare(ct):
    """Analysis tables from the clean data: orders with category, channel and month, plus the three chart series."""
    o = ct["orders"].merge(ct["products"][["product_id", "category"]], on="product_id")
    o = o.merge(ct["campaigns"][["campaign_id", "channel"]], on="campaign_id")
    o["month"] = o["order_date"].dt.month
    net = o[~o["returned"]]
    net_month = net.groupby("month")["revenue"].sum().round(2)
    spend = ct["campaigns"].set_index("channel")["spend"]
    roas = (net.groupby("channel")["revenue"].sum() / spend[spend > 0]).dropna().round(2)
    rate = (o.groupby("category")["returned"].mean() * 100).round(1)
    return o, net_month, roas, rate

## Daily review

### Key takeaways

- The question picks the chart: line for trend, sorted bar for comparison.
- Every chart has a title, axis labels and, for bars, a zero baseline.
- Verify charts by printing their properties and the data behind the marks.
- Check every number on a Power BI page against an independent computation.

### Common mistakes

- Starting a bar axis above zero: small differences look large. Keep the baseline at zero, or use a different chart.
- Leaving bars in alphabetical order: the ranking is hidden. Sort by value.
- Using the dropdown or hover to hide a poor chart design instead of fixing the base chart.
- Showing a ratio for a channel with no spend (organic): the value is undefined. Exclude it and say so in a note.
