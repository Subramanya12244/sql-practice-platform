## Understand

### Variables: names for values

Yesterday every value in your programs was typed straight into `print()`. That works for one use, but a real program needs to remember a value and use it again later. A **variable** is a name that refers to a value stored in the computer's memory. You create one with **assignment**, written with a single equals sign:

```text
price = 19.99
```

Read this from right to left: "work out the value on the right, then give it the name on the left." After this line, writing `price` anywhere in the program means 19.99. A helpful picture is a sticky label attached to an object: the object is the value, and the label is the name. A value can have several labels, and you can peel a label off and stick it on a different value at any time.

### Assignment is not an equation

In mathematics, `x = x + 1` is impossible. In Python it is perfectly normal, because `=` does not mean "is equal to"; it means "store the result on the right under the name on the left". Python first calculates `x + 1` using the current value of `x`, and only then attaches the name `x` to the result. This is how a program keeps a running count or a running total. Whether two things are equal is a different question that uses `==`, which you will meet on day 6.

### Variables hold values, not formulas

Another common misconception is that a variable remembers how it was calculated. If you write `b = a * 2` and later change `a`, then `b` does not change. The right-hand side was calculated once, at the moment of assignment, and `b` points to that result. Likewise `y = x` copies the current value of `x`; later changes to `x` do not alter `y`.

### Naming rules and conventions

Python enforces a few rules. A name may contain letters, digits and underscores, it cannot start with a digit, and it cannot contain spaces or hyphens. It must not be one of Python's **keywords**, words that already have a meaning in the language, such as `class`, `if` or `for`. Names are case-sensitive: `Price`, `price` and `PRICE` are three different names. Beyond the rules there is a convention that every Python programmer follows: use lowercase words joined by underscores, called **snake_case**, such as `order_total`. Choose names that say what the value is. `order_total` tells the reader more than `x` or `ot`, and reading code is most of what you will do with it.

### Data types

Every value has a **type** that decides what you can do with it. Five matter from the start:

- `int` is a whole number, such as `42` or `-7`. There is no practical upper limit on its size.
- `float` is a number with a decimal point, such as `3.14` or `2.0`. The name comes from "floating-point". Note that `2.0` is a float even though it looks whole.
- `str` is a string: text in quotes, such as `"Pune"`. The text `"42"` is a string, not a number, because of the quotes.
- `bool` has exactly two values, `True` and `False`, written with a capital first letter. It records yes-or-no facts.
- `None` is the single value of its own type, `NoneType`. It means "there is no value here", for example a customer who has no discount yet. It is not zero and it is not an empty string.

The built-in function `type()` tells you the type of any value or variable. Its answer looks like `<class 'int'>`; the word "class" is simply how Python describes a type.

### Why the type matters

Python decides what an operation means by looking at the types involved. `5 + 5` adds two integers and gives `10`. `"5" + "5"` joins two strings and gives `"55"`. Python will not guess when you mix a number and a text: `"5" + 5` stops with a `TypeError`, because it is unclear whether you want addition or joining. A great many bugs in data work come from a number that is secretly text, because data read from files and forms arrives as text.

### Type conversion

**Type conversion** turns a value of one type into another. Each type has a function with the same name for this purpose:

- `int(x)` makes a whole number. From a float it cuts off the decimal part without rounding, so `int(3.9)` is `3` and `int(-3.9)` is `-3`. From a string it reads the digits, so `int("42")` is `42`. A string that is not a whole number, such as `"3.5"` or `"abc"`, raises a `ValueError`.
- `float(x)` makes a decimal number; `float("3.50")` is `3.5` and `float(7)` is `7.0`.
- `str(x)` makes text from any value, so `str(10)` is `"10"`. It is how you attach a number to a sentence with `+`.
- `bool(x)` makes `True` or `False`. For the numbers 0 and 0.0 it gives `False`, and for any other number it gives `True`.

A conversion produces a new value; it does not change the original variable. If you want to keep the converted value, assign it to a name.

### Why it matters

Data work is mostly receiving values in one form and needing them in another: a price that arrives as the text `"19.99"`, an id stored as a number but needed as text, a missing field that must stay distinct from zero. Knowing the five types and how to convert between them is what makes those jobs predictable.

## Syntax and key functions

Assign a value to a name:

```python
name = value
```

The name is on the left, the value or expression on the right. Running the line creates the name or, if it exists, points it to the new value.

Check a type:

```python
type(value)
```

It returns the type of the value, shown as `<class 'int'>`, `<class 'float'>`, `<class 'str'>`, `<class 'bool'>` or `<class 'NoneType'>`.

Convert a type:

```python
int(value)
float(value)
str(value)
bool(value)
```

Each call returns a new value of the named type and leaves the original unchanged.

| Expression | Returns | Notes |
|---|---|---|
| `type(5)` | `<class 'int'>` | Whole number. |
| `type(5.0)` | `<class 'float'>` | A decimal point makes a float. |
| `type("5")` | `<class 'str'>` | Quotes make it text. |
| `type(True)` | `<class 'bool'>` | `True` and `False` only. |
| `type(None)` | `<class 'NoneType'>` | The "no value" value. |
| `int("42")` | `42` | `int("4.2")` raises `ValueError`. |
| `int(3.9)` | `3` | Cuts the decimals, does not round. |
| `float("3.50")` | `3.5` | Trailing zeros are not kept. |
| `str(10)` | `"10"` | Printed as `10`. |
| `bool(0)` | `False` | `bool(7)` is `True`. |

## Learn by example

### Example 1: Creating and using variables

Each assignment attaches a name to a value. The print call then uses the names instead of the values. Notice that the variable `city` is written without quotes in the call, because quotes would print the word "city" instead of its value.

```python run
city = "Pune"
orders = 120
average_basket = 18.5
print(city)
print(city, orders, average_basket)
print("city")
```

```output
Pune
Pune 120 18.5
city
```

### Example 2: Changing a variable and the running-total pattern

The line `stock = stock - 8` is not an equation. Python takes the current value of `stock` (50), subtracts 8, and attaches the name to the result (42). The second part shows that `copy = stock` copies the current value, so changing `stock` later does not change `copy`.

```python run
stock = 50
print("Start:", stock)
stock = stock - 8
print("After sale:", stock)
stock = stock + 20
print("After delivery:", stock)

copy = stock
stock = 0
print("Copy:", copy, "Stock:", stock)
```

```output
Start: 50
After sale: 42
After delivery: 62
Copy: 62 Stock: 0
```

### Example 3: The five types

`type()` reports the type of each value. `None` is printed as the word `None`. The value `2.0` is a float even though it equals a whole number, and `"42"` is a string because of its quotes.

```python run
count = 42
ratio = 2.0
label = "42"
is_active = True
discount = None

print(type(count))
print(type(ratio))
print(type(label))
print(type(is_active))
print(type(discount))
print(discount)
```

```output
<class 'int'>
<class 'float'>
<class 'str'>
<class 'bool'>
<class 'NoneType'>
None
```

### Example 4: Converting between types

Each line shows one conversion and then its type. `int(3.9)` cuts off the decimals instead of rounding. `str(7)` gives text, which can be joined to another string with `+`. `bool(0)` is `False` and any other number gives `True`. The original variable `amount` is never changed by the conversions.

```python run
amount = 3.9
print(int(amount))
print(float("3.50"))
print(float(7))
print(str(7) + " days")
print(bool(0), bool(12))
print(type(int("42")))
print(amount)
```

```output
3
3.5
7.0
7 days
False True
<class 'int'>
3.9
```

### Example 5: Numbers that arrive as text

Data from files and forms usually arrives as text. Adding two strings joins them, which is rarely what you want. Converting first gives real arithmetic. The values are text in the variables `units_text` and `price_text`; the converted numbers are stored in new names so the originals stay available.

```python run
units_text = "3"
price_text = "20.50"

print(units_text + units_text)

units = int(units_text)
price = float(price_text)
total = units * price

print(units + units)
print("Total:", total)
print(type(units_text), type(units), type(total))
```

```output
33
6
Total: 61.5
<class 'str'> <class 'int'> <class 'float'>
```

## Real-world applications

- **Cleaning a spreadsheet export.** Every cell in a CSV file arrives as text, including the numbers. An analyst converts `"19.99"` with `float()` and `"12"` with `int()` before calculating a total, which is exactly Example 5.
- **Naming intermediate results.** A pipeline that computes `gross = 1200`, `tax_rate = 0.2` and `net = gross - gross * tax_rate` is self-explanatory when names carry the meaning. Change one value and everything derived from it is recomputed when the program runs again.
- **Representing missing data.** A record for a customer with no phone number stores `None`, not `0` and not an empty string, so later steps can tell "unknown" apart from "zero" or "blank". The same idea appears as NULL in SQL later in this programme.
- **Switches and flags.** A `bool` variable such as `is_active = True` records a yes-or-no fact about each row, which you will use for filtering once you learn comparisons and conditions.

## Daily review

### Key takeaways

- A variable is a name attached to a value; `name = value` creates it or moves it to a new value.
- `=` stores the right-hand result under the left-hand name; it is not a statement of equality, and the value is calculated once.
- The five basic types are `int`, `float`, `str`, `bool` and `None`; `type()` reports which one a value has.
- `"5"` and `5` are different values: `+` joins strings and adds numbers, and Python refuses to mix them.
- `int()`, `float()`, `str()` and `bool()` return converted values; `int()` cuts decimals instead of rounding.

### Common mistakes

- Putting quotes around a variable name in `print()`, which prints the name instead of the value.
- Using a name that starts with a digit, contains a space or hyphen, or is a keyword (`2nd`, `total price`, `total-price`, `class`).
- Mixing capitals inconsistently: `Total` and `total` are different variables.
- Expecting `b = a * 2` to update `b` when `a` changes later.
- Calling `int("3.5")`; a string with a decimal point must go through `float()` first.
- Adding a number to a string with `+` instead of converting one side first.

### Revision notes

- Assignment: `name = value`, right side first. Use snake_case names that describe the value.
- Types: `int` whole, `float` decimal, `str` text in quotes, `bool` `True`/`False`, `None` no value.
- `type(x)` shows the type; `int(x)`, `float(x)`, `str(x)`, `bool(x)` convert.
- `int(3.9)` is `3`; `float("3.50")` is `3.5`; `str(7)` is `"7"`; `bool(0)` is `False`.
- `"5" + "5"` is `"55"`; `5 + 5` is `10`.
