## Objectives

- Stack tables with `pd.concat` along rows and combine them side by side, and explain what happens to the index and to columns that do not match.
- Summarise a table into a grid of rows and columns with `pivot_table`, choosing the aggregation function and filling empty cells.
- Count combinations of two categories with `crosstab`, including shares per row.
- Turn a wide table (one column per month) into a long table with `melt`, and say when each shape is useful.

## Understand

### Shape is a choice

The same facts can be laid out in more than one shape. A **long** table has one row per observation: one row for each product in each month, with columns `product`, `month` and `sales`. A **wide** table has one row per product and one column per month. Neither is right in general. Long tables are what `groupby`, plotting libraries and databases expect, because adding a new month adds rows rather than a new column. Wide tables are what people like to read, because the grid shows comparisons at a glance. Today's tools move data between the two shapes and glue tables together. Day 81 joined tables side by side on a key; `concat` is the simpler operation of stacking tables that already have the same kind of columns.

### concat: stacking tables

`pd.concat([a, b, c])` puts the tables one under another, which is the pandas version of SQL `UNION ALL`. It is the tool for combining files that arrive in pieces, such as one export per month. Pandas matches columns by name, not by position. If a column exists in one table but not another, the missing cells are filled with `NaN`, and `join="inner"` keeps only the columns that all tables share. The result keeps each table's original row labels, so two tables numbered 0, 1, 2 produce a result with duplicated labels 0, 1, 2, 0, 1, 2, which later causes surprises with `loc`. Pass `ignore_index=True` to renumber the rows from 0, or `keys=["jan", "feb"]` to record which table each row came from in an extra index level.

With `axis=1`, `concat` places tables side by side and matches rows by index label. Rows without a partner in the other table get `NaN`. This is easy to misuse as a join: it matches the index, not a key column, so use `merge` when you have a key column.

### pivot_table: summarising into a grid

`df.pivot_table(index="region", columns="product", values="amount", aggfunc="sum")` is a groupby by two keys with the second key spread across the top as columns. The `index` values become rows, the `columns` values become column headings, and each cell holds the aggregate of `values` for that pair. A pair that never occurs gives `NaN`, and `fill_value=0` replaces it. `aggfunc` can be a name such as `"mean"` or `"count"`, a list of names, or a dictionary. With `margins=True`, pandas adds an `All` row and column with totals. A pivot table is a groupby in disguise: `df.groupby(["region", "product"])["amount"].sum().unstack()` gives the same grid, where `unstack` moves the inner key into the columns.

There is a plain `pivot` method too, which only reshapes and fails if a pair of keys appears twice. `pivot_table` is the safe choice because it always aggregates the duplicates.

### crosstab: counting combinations

`pd.crosstab(df["region"], df["product"])` counts how often each pair of values occurs. It is a pivot table with the aggregate fixed to a count. The option `normalize="index"` divides every cell by its row total, so each row shows shares that add up to 1, and `normalize="all"` divides by the grand total. Crosstabs are the quickest way to see how two categorical columns relate, for example status by country, and to check a cleaning step: after you standardise country names, the crosstab should show no stray spellings.

### melt: wide to long

`pd.melt(wide, id_vars="product", var_name="month", value_name="sales")` is the opposite of a pivot. The columns named in `id_vars` stay as they are. All other columns are stacked into two new columns: one holds the old column name (`var_name`) and one holds the value (`value_name`). A table with 3 products and 4 month columns becomes 12 rows. Use `value_vars` to melt only some of the columns. After melting, the data can be grouped, filtered by month, or plotted with the month as a variable.

### Common misconception

Learners often think a pivot table changes the data. It only reorganises a summary. If two rows have the same row and column key, they are combined by `aggfunc`, which is `mean` by default, not `sum`. A pivot table of money without `aggfunc="sum"` shows averages, and the grid looks plausible. Another trap is believing `concat` removes duplicates. It never does; stacking the same file twice gives every row twice, so check with `duplicated` from Day 75.

### Why it matters

Monthly files, regional exports and survey waves arrive as separate tables that must be stacked before analysis. Reports are read as grids, while analysis code wants long tables. Moving between the two correctly, and checking row counts before and after, is a routine part of preparing data.

## Syntax and key functions

```python nocheck
pd.concat([a, b], ignore_index=True)           # stack rows
pd.concat([a, b], axis=1)                      # side by side, by index
df.pivot_table(index="r", columns="c", values="v", aggfunc="sum", fill_value=0)
pd.crosstab(df["r"], df["c"], normalize="index")
pd.melt(wide, id_vars="id", var_name="month", value_name="sales")
```

| Call | Returns |
|---|---|
| `pd.concat(list, ignore_index=True)` | one table, rows stacked, columns matched by name |
| `pd.concat(list, join="inner")` | only the columns shared by all tables |
| `pd.concat(list, keys=[...])` | adds an index level naming each source |
| `df.pivot_table(...)` | grid of aggregates; `NaN` for missing pairs |
| `margins=True` | adds an `All` row and column |
| `pd.crosstab(a, b)` | counts for each pair of values |
| `normalize="index"` | shares per row |
| `pd.melt(...)` | long table: id columns, a variable column, a value column |

## Learn by example

### Example 1: Stack monthly files

Two monthly tables share two columns, but February has an extra `coupon` column.

```python run
import pandas as pd
jan = pd.DataFrame({"order_id": [1, 2], "amount": [10, 20]})
feb = pd.DataFrame({"order_id": [3, 4], "amount": [30, 40], "coupon": ["X", None]})
both = pd.concat([jan, feb], ignore_index=True)
print(both.to_string())
print(pd.concat([jan, feb], join="inner", ignore_index=True).columns.tolist())
print(pd.concat([jan, feb], keys=["jan", "feb"]).index.tolist())
```

```output
   order_id  amount coupon
0         1      10    NaN
1         2      20    NaN
2         3      30      X
3         4      40   None
['order_id', 'amount']
[('jan', 0), ('jan', 1), ('feb', 0), ('feb', 1)]
```

Without `ignore_index` the labels would repeat. The `keys` option records which table each row came from.

### Example 2: A pivot table

Sales per region and product become a grid. The pair (South, ink) never occurs, so `fill_value` supplies a 0.

```python run
import pandas as pd
sales = pd.DataFrame({
    "region": ["N", "N", "S", "N", "S"],
    "product": ["pen", "ink", "pen", "pen", "pen"],
    "amount": [10, 20, 5, 30, 15],
})
grid = sales.pivot_table(index="region", columns="product", values="amount", aggfunc="sum", fill_value=0, margins=True)
print(grid.to_string())
avg = sales.pivot_table(index="region", columns="product", values="amount")
print(avg.to_string())
```

```output
product  ink  pen  All
region                
N         20   40   60
S          0   20   20
All       20   60   80
product   ink   pen
region             
N        20.0  20.0
S         NaN  10.0
```

The second table has no `aggfunc`, so it shows means, and the empty pair is `NaN`.

### Example 3: Crosstab with shares

Counting how orders divide by status within each country.

```python run
import pandas as pd
o = pd.DataFrame({
    "country": ["UK", "UK", "UK", "US", "US"],
    "status": ["shipped", "shipped", "returned", "shipped", "returned"],
})
print(pd.crosstab(o["country"], o["status"]).to_string())
print(pd.crosstab(o["country"], o["status"], normalize="index").round(2).to_string())
```

```output
status   returned  shipped
country                   
UK              1        2
US              1        1
status   returned  shipped
country                   
UK           0.33     0.67
US           0.50     0.50
```

Each row of the second table adds to 1: two thirds of UK orders shipped and half of US orders did.

### Example 4: Melt wide to long, then group

A report with one column per month is melted, so it can be summed by month and the shape checked.

```python run
import pandas as pd
wide = pd.DataFrame({"product": ["pen", "ink", "pad"], "jan": [10, 20, 5], "feb": [12, 18, 9], "mar": [11, 25, 7]})
long = pd.melt(wide, id_vars="product", var_name="month", value_name="sales")
print(long.shape)
print(long.head(4).to_string(index=False))
print(long.groupby("month")["sales"].sum().to_string())
```

```output
(9, 3)
product month  sales
    pen   jan     10
    ink   jan     20
    pad   jan      5
    pen   feb     12
month
feb    39
jan    35
mar    43
```

Three products and three months give nine rows. The month totals are now an ordinary groupby.

## Real-world applications

- **Combining periodic extracts.** A data engineer stacks twelve monthly CSV tables with `concat(..., ignore_index=True)` and compares the row count with the sum of the file sizes in rows.
- **Management reports.** An analyst produces a region by product grid with `pivot_table(..., margins=True)` so totals appear without extra code.
- **Checking categories.** A crosstab of country by status after cleaning shows at a glance that no stray spellings remain.
- **Preparing data for charts.** Wide survey columns are melted so each question becomes a value of one `question` column that a plotting library can colour by.

## Daily review

### Key takeaways

- `concat` stacks tables by column name; use `ignore_index=True` and check for duplicates.
- `pivot_table` is a two-key groupby displayed as a grid; set `aggfunc` explicitly.
- `crosstab` counts pairs; `normalize` turns counts into shares.
- `melt` turns columns into rows; long tables suit grouping, wide tables suit reading.

### Common mistakes

- A pivot table of amounts showing averages: the default `aggfunc` is `mean`. Pass `aggfunc="sum"`.
- Duplicated row labels after `concat` make `df.loc[0]` return several rows. Use `ignore_index=True`.
- `concat(axis=1)` giving `NaN` rows because the indexes differ. It matches labels, not keys; use `merge`.
- Reading `NaN` in a pivot as "zero sales": it means the pair does not occur. Use `fill_value=0` only when zero is the correct meaning.

### Revision notes

- Stack: `concat`; reshape to grid: `pivot_table`; counts: `crosstab`; wide to long: `melt`.
- Default pivot aggregation is `mean`.
- Row counts: 3 products times 3 months is 9 rows after melt.
