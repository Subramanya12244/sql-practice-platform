## Understand

### Figure, axes and artists

Matplotlib is the foundation library for drawing charts in Python. It draws everything onto a canvas, and it organises that canvas as a hierarchy of objects. The **figure** is the whole canvas, like a sheet of paper. An **axes** (the word is singular here, which confuses almost every beginner) is one plot on that sheet: it owns an x axis, a y axis, a title and the data marks. One figure can hold many axes, which is how multi-panel charts work, and tomorrow's lesson uses that. Everything you can see on an axes (a line, a bar, a piece of text, a tick label) is an **artist**: an object with properties such as colour and visibility. Because charts are objects, you can inspect them, which is how this course checks charts without looking at images.

### Two interfaces, one to use

Matplotlib has two ways of driving it. The `pyplot` state-machine interface (`plt.plot(...)`, `plt.title(...)`) keeps a hidden "current" figure and axes, and each call modifies it. The object-oriented interface asks you to name the objects: `fig, ax = plt.subplots()` creates a figure and one axes, and you call methods on `ax`, such as `ax.plot(...)` and `ax.set_title(...)`. Quick experiments often use the first style, but real analysis code uses the second because it keeps working when you have several axes, inside functions, and in notebooks that re-run cells out of order. This course always uses `fig, ax = plt.subplots()`.

### The three charts and the data they need

A **line chart** (`ax.plot(x, y)`) joins points in order, and suits trends over time, where the x values are ordered. A **bar chart** (`ax.bar(categories, heights)` or `ax.barh` for horizontal bars) draws one rectangle per category, and suits comparing totals; as Day 114 said, its baseline must be zero. A **scatter chart** (`ax.scatter(x, y)`) draws one marker per row, with no joining line, and suits relationships between two numeric columns. Each method takes plain sequences or pandas columns, so the real work before drawing is shaping the data: a monthly total is a `groupby` or `resample`, a category total is a `groupby` followed by `sort_values`. Prepare that table in its own step and check it by printing it. A chart whose numbers are wrong is a more expensive mistake than one that looks plain.

### Labels are part of the chart

A chart without labels forces the reader to guess units. Four labels matter: the title (`ax.set_title`), the x label (`ax.set_xlabel`), the y label (`ax.set_ylabel`) with the unit, and a legend (`ax.legend()`) when more than one series is drawn. For a series to appear in a legend, give it a `label=` argument when you draw it. Tick labels, the text at each tick mark, come from the data for categorical bar charts and can be changed with `ax.set_xticks` and `ax.set_xticklabels` or rotated with `ax.tick_params(axis="x", rotation=45)`. Axis limits are set with `ax.set_ylim(bottom, top)`. Every setter has a matching getter (`ax.get_title()`, `ax.get_ylabel()`, `ax.get_ylim()`), and the getters are what the examples below print.

### Reading a figure back without looking

After drawing, the axes holds its marks in lists. `ax.lines` holds the line objects, and `line.get_ydata()` returns the numbers plotted. `ax.patches` holds the bar rectangles, and `bar.get_height()` gives each height. `ax.collections` holds scatter markers, and `collection.get_offsets()` returns the coordinates. Printing these turns a picture into facts: how many bars, in what order, with which heights. This is how professionals unit-test chart code, and it is the skill that tells you the chart really shows what you intended.

### Misconceptions

Beginners often think `plt.show()` is how a chart is made. It only displays the figure in a window or notebook; the figure exists after the drawing calls. In a script that runs without a screen (a server, an automated report, or the tests for this course) you select the non-interactive `Agg` backend with `matplotlib.use("Agg")` and save a file instead of showing a window. The other trap is plotting unsorted dates: `ax.plot` joins points in the order given, so if the table is not sorted by date the line zigzags back and forth. Sort first.

### Why it matters

Analysts spend more time shaping data for a chart than drawing it. Keeping the two steps apart (a function that returns the table, then a function that draws it) lets you test the numbers and change the style without touching the logic.

## Syntax and key functions

```python
fig, ax = plt.subplots(figsize=(8, 4))      # one figure, one axes
ax.plot(x, y, label="Revenue", marker="o")   # line chart
ax.bar(categories, heights, color="#4c78a8") # bar chart
ax.scatter(x, y, s=20, alpha=0.6)            # scatter chart
ax.set_title("Revenue rose in the second half")
ax.set_xlabel("Month"); ax.set_ylabel("Revenue (GBP)")
ax.set_ylim(bottom=0)
ax.legend()
```

`figsize` is width and height in inches. `marker` puts a dot on each point, `alpha` sets transparency (0 invisible to 1 solid), and `s` is the marker area.

| Call | What it does or returns |
|---|---|
| `plt.subplots()` | Returns `(fig, ax)`: a new figure and one axes |
| `ax.plot(x, y)` | Draws a line; returns a list of `Line2D` artists |
| `ax.bar(x, h)` / `ax.barh(y, w)` | Draws vertical or horizontal bars; returns a `BarContainer` |
| `ax.scatter(x, y)` | Draws markers; returns a `PathCollection` |
| `ax.set_title`, `set_xlabel`, `set_ylabel` | Set text; the `get_` versions return the text |
| `ax.set_xlim`, `ax.set_ylim` | Set limits; `get_ylim()` returns a `(low, high)` tuple |
| `ax.tick_params(axis="x", rotation=45)` | Rotates tick labels |
| `ax.legend()` | Builds a legend from the `label=` of each artist |
| `ax.lines`, `ax.patches`, `ax.collections` | The drawn marks, for inspection |
| `fig.savefig("name.png")` | Writes the figure to a file |

## Learn by example

### Example 1: Prepare the data behind the chart

Before any drawing, build the table. This example creates 240 orders and aggregates them by month with a period group, which is the data a line chart will plot. It runs in the browser because it only uses pandas.

```python run
import numpy as np
import pandas as pd


def make_orders():
    rng = np.random.default_rng(7)
    n = 240
    category = rng.choice(["Home", "Electronics", "Beauty", "Sports"], size=n, p=[0.35, 0.2, 0.25, 0.2])
    base = pd.Series({"Home": 45, "Electronics": 160, "Beauty": 28, "Sports": 60})
    df = pd.DataFrame({
        "order_date": pd.Timestamp("2025-01-01") + pd.to_timedelta(rng.integers(0, 365, n), unit="D"),
        "category": category,
        "quantity": rng.integers(1, 6, n),
        "unit_price": (base[category].to_numpy() * (0.8 + 0.4 * rng.random(n))).round(2),
        "shipping_days": rng.integers(1, 9, n),
    })
    df["revenue"] = (df["quantity"] * df["unit_price"]).round(2)
    return df.sort_values("order_date").reset_index(drop=True)

orders = make_orders()
monthly = orders.groupby(orders["order_date"].dt.to_period("M"))["revenue"].sum().round(0)
print(monthly.head(4).to_string())
print("months:", len(monthly), "| best month:", str(monthly.idxmax()), "| total:", int(monthly.sum()))
```

```output
order_date
2025-01    3499.0
2025-02    5287.0
2025-03    6418.0
2025-04    4485.0
Freq: M
months: 12 | best month: 2025-03 | total: 48967
```

### Example 2: A line chart and its properties

The figure is drawn with the object-oriented interface. Because `ax.plot` needs ordered x values, the monthly table is already ordered. The prints read the title, the labels, the number of lines and the plotted numbers back from the axes, which proves the chart holds the data from Example 1. This example needs matplotlib, so it is a local example.

```python local
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt
import numpy as np
import pandas as pd


def make_orders():
    rng = np.random.default_rng(7)
    n = 240
    category = rng.choice(["Home", "Electronics", "Beauty", "Sports"], size=n, p=[0.35, 0.2, 0.25, 0.2])
    base = pd.Series({"Home": 45, "Electronics": 160, "Beauty": 28, "Sports": 60})
    df = pd.DataFrame({
        "order_date": pd.Timestamp("2025-01-01") + pd.to_timedelta(rng.integers(0, 365, n), unit="D"),
        "category": category,
        "quantity": rng.integers(1, 6, n),
        "unit_price": (base[category].to_numpy() * (0.8 + 0.4 * rng.random(n))).round(2),
        "shipping_days": rng.integers(1, 9, n),
    })
    df["revenue"] = (df["quantity"] * df["unit_price"]).round(2)
    return df.sort_values("order_date").reset_index(drop=True)

orders = make_orders()
monthly = orders.groupby(orders["order_date"].dt.month)["revenue"].sum().round(0)

fig, ax = plt.subplots(figsize=(8, 4))
ax.plot(monthly.index, monthly.values, marker="o", label="Revenue")
ax.set_title("Monthly revenue, 2025")
ax.set_xlabel("Month number")
ax.set_ylabel("Revenue (GBP)")
ax.legend()

line = ax.lines[0]
print("title:", ax.get_title())
print("labels:", ax.get_xlabel(), "/", ax.get_ylabel())
print("lines:", len(ax.lines), "| points:", len(line.get_ydata()))
print("first three y:", [int(v) for v in line.get_ydata()[:3]])
print("legend entries:", [t.get_text() for t in ax.get_legend().get_texts()])
```

```output
title: Monthly revenue, 2025
labels: Month number / Revenue (GBP)
lines: 1 | points: 12
first three y: [3499, 5287, 6418]
legend entries: ['Revenue']
```

### Example 3: A sorted bar chart with values on the bars

A bar chart of revenue by category, sorted, with a zero baseline. `ax.bar_label` writes each bar's value above it. The code prints the bars in order with their heights, and the y-axis lower limit.

```python local
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt
import numpy as np
import pandas as pd


def make_orders():
    rng = np.random.default_rng(7)
    n = 240
    category = rng.choice(["Home", "Electronics", "Beauty", "Sports"], size=n, p=[0.35, 0.2, 0.25, 0.2])
    base = pd.Series({"Home": 45, "Electronics": 160, "Beauty": 28, "Sports": 60})
    df = pd.DataFrame({
        "order_date": pd.Timestamp("2025-01-01") + pd.to_timedelta(rng.integers(0, 365, n), unit="D"),
        "category": category,
        "quantity": rng.integers(1, 6, n),
        "unit_price": (base[category].to_numpy() * (0.8 + 0.4 * rng.random(n))).round(2),
        "shipping_days": rng.integers(1, 9, n),
    })
    df["revenue"] = (df["quantity"] * df["unit_price"]).round(2)
    return df.sort_values("order_date").reset_index(drop=True)

orders = make_orders()
by_cat = orders.groupby("category")["revenue"].sum().sort_values(ascending=False).round(0)

fig, ax = plt.subplots()
bars = ax.bar(by_cat.index, by_cat.values)
ax.bar_label(bars, fmt="%.0f")
ax.set_title("Electronics leads revenue")
ax.set_ylabel("Revenue (GBP)")
ax.set_ylim(bottom=0)

print("order:", [t.get_text() for t in ax.get_xticklabels()])
print("heights:", [int(p.get_height()) for p in ax.patches])
print("labels on bars:", [t.get_text() for t in ax.texts])
print("y starts at:", ax.get_ylim()[0])
```

```output
order: ['Electronics', 'Home', 'Sports', 'Beauty']
heights: [22694, 11917, 9087, 5267]
labels on bars: ['22694', '11917', '9087', '5267']
y starts at: 0.0
```

### Example 4: A scatter chart with a second encoding

A scatter chart of unit price against quantity with the marker colour showing shipping days. `c=` maps a numeric column to colour. The prints show the number of markers and their first coordinates, then the title and labels. Row counts are the first thing to check after drawing a scatter, because a filter that silently dropped rows would not show on the image.

```python local
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt
import numpy as np
import pandas as pd


def make_orders():
    rng = np.random.default_rng(7)
    n = 240
    category = rng.choice(["Home", "Electronics", "Beauty", "Sports"], size=n, p=[0.35, 0.2, 0.25, 0.2])
    base = pd.Series({"Home": 45, "Electronics": 160, "Beauty": 28, "Sports": 60})
    df = pd.DataFrame({
        "order_date": pd.Timestamp("2025-01-01") + pd.to_timedelta(rng.integers(0, 365, n), unit="D"),
        "category": category,
        "quantity": rng.integers(1, 6, n),
        "unit_price": (base[category].to_numpy() * (0.8 + 0.4 * rng.random(n))).round(2),
        "shipping_days": rng.integers(1, 9, n),
    })
    df["revenue"] = (df["quantity"] * df["unit_price"]).round(2)
    return df.sort_values("order_date").reset_index(drop=True)

orders = make_orders()
fig, ax = plt.subplots()
points = ax.scatter(orders["unit_price"], orders["revenue"], c=orders["shipping_days"], s=15, alpha=0.7)
ax.set_title("Revenue grows with unit price")
ax.set_xlabel("Unit price (GBP)")
ax.set_ylabel("Order revenue (GBP)")

offsets = points.get_offsets()
print("markers:", len(offsets), "| rows:", len(orders))
print("first marker:", [round(float(v), 2) for v in offsets[0]])
print("colour range:", points.get_array().min(), "to", points.get_array().max())
print("labels:", ax.get_xlabel(), "/", ax.get_ylabel())
```

```output
markers: 240 | rows: 240
first marker: [176.02, 704.08]
colour range: 1.0 to 8.0
labels: Unit price (GBP) / Order revenue (GBP)
```

## Real-world applications

- **Weekly trading report.** A script aggregates sales to months, draws the line with `ax.plot`, and saves it with `fig.savefig`. Because the data step is separate (Example 1), the same numbers feed a table and a chart.
- **Category review.** A sorted bar of revenue by category with values on the bars (Example 3) replaces a table of ten rows in a meeting slide.
- **Exploratory checks.** A scatter of price against order revenue (Example 4) shows quickly whether a few extreme orders drive a correlation, which a number such as the correlation coefficient alone would hide.
- **Chart tests in a pipeline.** Reading `ax.lines[0].get_ydata()` in a test confirms an automated report plots the numbers it should.

## Daily review

### Key takeaways

- A figure is the canvas, an axes is one plot, and everything drawn is an artist you can inspect.
- Use `fig, ax = plt.subplots()` and call methods on `ax`.
- Shape the data first (a groupby, a sort), then draw; print the table to check it.
- Set a title, both axis labels with units, and `label=` plus `ax.legend()` for multiple series.
- Read a chart back with `ax.lines`, `ax.patches` and `ax.collections` instead of trusting your eyes.

### Common mistakes

- Plotting unsorted dates. Symptom: a line that zigzags backwards. Fix: `sort_values("order_date")` or group so the index is ordered.
- Calling `plt.show()` in a script on a machine with no screen, or forgetting `matplotlib.use("Agg")`. Symptom: a hang or a backend error. Fix: select `Agg` and use `fig.savefig`.
- Treating `ax` as plural. Symptom: `AttributeError` when you index the result of `plt.subplots()` for one plot. Fix: one plot returns one axes object; several plots return an array.
- Forgetting `label=` and then calling `ax.legend()`. Symptom: a warning and an empty legend. Fix: pass `label=` when drawing.

### Revision notes

- `fig, ax = plt.subplots()`; `ax.plot`, `ax.bar`, `ax.scatter`.
- Setters: `set_title`, `set_xlabel`, `set_ylabel`, `set_ylim`; getters read them back.
- Inspect: `ax.lines`, `ax.patches`, `ax.collections`, `ax.texts`.
- Bars start at zero; sort dates; sort bars by value.
