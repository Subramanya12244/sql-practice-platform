## Objectives

- Draw a heatmap of a correlation matrix or a pivot table, with annotations and a colour scale centred on zero where it should be.
- Use `pairplot` to scan every pair of numeric columns at once, and read its grid of axes.
- Split one chart into panels by a category with `FacetGrid`, and name the panels.
- Fit and draw a regression line with `regplot`, and check the line against `np.polyfit`.

## Understand

### From one variable to many

Yesterday's charts looked at one numeric column, or one numeric column across categories. Real questions involve several variables at once: does price move with quantity, does shipping time relate to revenue, does the pattern differ by category? Today's tools scan relationships between columns. They share a weakness that you must carry in your head the whole day: a picture of relationships invites you to see patterns, and with enough pairs you will always see one by chance. Treat each chart as a lead to check, not as proof.

### Heatmaps

A **heatmap** draws a table as a grid of coloured cells, where the colour encodes the number in the cell. It suits two tables: a **correlation matrix** and a **pivot table** (for example orders by month and category). A correlation matrix holds the Pearson correlation coefficient for each pair of columns. The coefficient runs from -1 (a perfect downward straight-line relationship) through 0 (no straight-line relationship) to +1 (perfect upward), and measures only straight-line association. A heatmap of that matrix is symmetric, with ones on the diagonal, because every column correlates perfectly with itself. Because correlations have a natural middle, set `vmin=-1`, `vmax=1` and a **diverging** colour map (`cmap="vlag"` or `"coolwarm"`) so zero is a neutral colour; for counts and totals use a **sequential** map where darker means more. Turn on `annot=True` to print the number in every cell, since colour alone is imprecise (Day 114: colour is a weak channel for values). `sns.heatmap` returns the axes; the colours live in a `QuadMesh` in `ax.collections[0]`, and `get_array()` returns the values drawn.

### Pair plots

`sns.pairplot(df)` draws a grid with one row and one column per numeric column. Each off-diagonal panel is a scatter of one column against another, and each diagonal panel shows that column's own distribution. With `hue="category"`, points are coloured by group. It is the quickest way to scan a new table for relationships, outliers and groups that separate. Unlike the axes-level functions, `pairplot` is a **figure-level** function: it creates its own figure and returns a `PairGrid` object, not an axes. The grid of axes is `g.axes`, a two-dimensional array, and you cannot pass `ax=` to it. With many columns the grid becomes unreadable (ten columns means a hundred panels), so choose the columns first.

### Facets

A **facet** grid repeats one chart once per value of a category, in panels that share axes: the small multiples of Day 116, drawn without writing the loop. `sns.FacetGrid(df, col="category", col_wrap=2)` creates the empty grid, and `g.map_dataframe(sns.histplot, x="revenue")` draws one chart in each panel from that panel's rows. The panel titles come out as `category = Home` and so on, and `g.axes` is the array of axes. Facets are the answer to "does this pattern hold in every group?", which a single scatter coloured by group often hides under overplotting. `FacetGrid` is also figure-level. The higher-level functions `sns.displot` and `sns.relplot` build the same grids from one call with `col=` and `row=`.

### Regression plots

`sns.regplot(data=df, x="unit_price", y="revenue")` draws a scatter plot and adds a fitted straight line, the **least-squares line** that minimises the squared vertical distances to the points. It also draws a shaded **confidence band** around the line, estimated by resampling, which uses random numbers; pass `ci=None` to switch it off when you need reproducible output. The line is computed the same way as `np.polyfit(x, y, 1)`, which returns the slope and the intercept, so you can verify the chart. `sns.lmplot` does the same with facets and returns a grid. A regression line describes association, not cause, and a line fitted through data with a curve or a few extreme points can mislead; look at the scatter first.

### Misconceptions and why it matters

The most common mistake is reading a correlation of 0 as "no relationship": it means no straight-line relationship, and a clear curve can have a correlation near zero. A second is thinking the heatmap colour scale is absolute: seaborn scales colours to the data range unless you set `vmin` and `vmax`, so a matrix whose largest off-diagonal is 0.1 may look just as vivid as one at 0.9. In analyst work these charts open the exploration (the EDA phase of Days 106 to 113) and feed the choice of what to chart for stakeholders. Always keep the numbers: the heatmap and pair plot say where to look, the table says how big.

## Syntax and key functions

```python
sns.heatmap(corr, annot=True, vmin=-1, vmax=1, cmap="vlag", ax=ax)
g = sns.pairplot(df[cols + ["category"]], hue="category")
g = sns.FacetGrid(df, col="category", col_wrap=2, col_order=sorted(df["category"].unique()))
g.map_dataframe(sns.histplot, x="revenue", bins=8)
sns.regplot(data=df, x="unit_price", y="revenue", ci=None, ax=ax)
```

| Function | What it draws or returns |
|---|---|
| `df.corr()` | The Pearson correlation matrix of the numeric columns |
| `sns.heatmap(table)` | Coloured grid of a table; returns an axes |
| `annot=True`, `fmt=".2f"` | Print each cell's value, with a number format |
| `vmin`, `vmax`, `cmap`, `center` | Colour scale limits and map |
| `sns.pairplot(df, hue=)` | Grid of scatter and distribution panels; returns a `PairGrid` |
| `sns.FacetGrid(df, col=, row=, col_wrap=)` | Empty grid of panels; returns a `FacetGrid` |
| `g.map_dataframe(func, **kw)` | Draws `func` in every panel from that panel's rows |
| `g.axes` | Array of axes of a grid |
| `sns.regplot` | Scatter plus fitted line; returns an axes |
| `np.polyfit(x, y, 1)` | Slope and intercept of the least-squares line |

## Learn by example

### Example 1: The tables behind the charts

A correlation matrix of four numeric columns, and a month-by-category count table: the two inputs of a heatmap. Strong values are found with pandas first, so you know what the heatmap should show. This runs in the browser.

```python run
import numpy as np
import pandas as pd


def make_orders():
    rng = np.random.default_rng(7)
    n = 240
    category = rng.choice(["Home", "Electronics", "Beauty", "Sports"], size=n, p=[0.35, 0.2, 0.25, 0.2])
    base = pd.Series({"Home": 45, "Electronics": 160, "Beauty": 28, "Sports": 60})
    df = pd.DataFrame({
        "order_date": pd.Timestamp("2025-01-01") + pd.to_timedelta(rng.integers(0, 365, n), unit="D"),
        "category": category,
        "quantity": rng.integers(1, 6, n),
        "unit_price": (base[category].to_numpy() * (0.8 + 0.4 * rng.random(n))).round(2),
        "shipping_days": rng.integers(1, 9, n),
    })
    df["revenue"] = (df["quantity"] * df["unit_price"]).round(2)
    return df.sort_values("order_date").reset_index(drop=True)

orders = make_orders()
cols = ["quantity", "unit_price", "shipping_days", "revenue"]
corr = orders[cols].corr().round(2)
print(corr.to_string())
counts = orders.pivot_table(index=orders["order_date"].dt.quarter, columns="category", values="revenue", aggfunc="size", fill_value=0)
print(counts.to_string())
```

### Example 2: A correlation heatmap

The heatmap draws the correlation matrix with the colour scale fixed to -1 to 1. A 4-by-4 matrix gives 16 cells and, with `annot=True`, 16 text labels. The values the chart paints can be read back from the mesh and compared with the matrix.

```python local
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt
import seaborn as sns
import numpy as np
import pandas as pd


def make_orders():
    rng = np.random.default_rng(7)
    n = 240
    category = rng.choice(["Home", "Electronics", "Beauty", "Sports"], size=n, p=[0.35, 0.2, 0.25, 0.2])
    base = pd.Series({"Home": 45, "Electronics": 160, "Beauty": 28, "Sports": 60})
    df = pd.DataFrame({
        "order_date": pd.Timestamp("2025-01-01") + pd.to_timedelta(rng.integers(0, 365, n), unit="D"),
        "category": category,
        "quantity": rng.integers(1, 6, n),
        "unit_price": (base[category].to_numpy() * (0.8 + 0.4 * rng.random(n))).round(2),
        "shipping_days": rng.integers(1, 9, n),
    })
    df["revenue"] = (df["quantity"] * df["unit_price"]).round(2)
    return df.sort_values("order_date").reset_index(drop=True)

orders = make_orders()
cols = ["quantity", "unit_price", "shipping_days", "revenue"]
corr = orders[cols].corr()

fig, ax = plt.subplots()
sns.heatmap(corr, annot=True, fmt=".2f", vmin=-1, vmax=1, cmap="vlag", ax=ax)
ax.set_title("Revenue follows unit price and quantity")

mesh = ax.collections[0]
print("cells:", mesh.get_array().shape, "| labels:", len(ax.texts))
print("same as corr:", bool(np.allclose(mesh.get_array(), corr.to_numpy())))
print("colour limits:", mesh.get_clim())
print("axis labels:", [t.get_text() for t in ax.get_xticklabels()])
```

```output
cells: (4, 4) | labels: 16
same as corr: True
colour limits: (-1.0, 1.0)
axis labels: ['quantity', 'unit_price', 'shipping_days', 'revenue']
```

`pairplot` with `hue="category"` on four numeric columns makes a 4-by-4 grid. The return value is a `PairGrid`, not an axes, so the checks use `g.axes`. Histograms or density plots on the diagonal show each column alone, and scatter plots elsewhere show pairs.

### Example 5: A regression line, checked

`regplot` draws the scatter and the fitted line. The line has two ends, so its slope is rise over run. Comparing it with `np.polyfit` confirms that the chart shows the least-squares line and tells you what the slope means: the extra revenue per extra pound of unit price in this table.

```python local
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt
import seaborn as sns
import numpy as np
import pandas as pd


def make_orders():
    rng = np.random.default_rng(7)
    n = 240
    category = rng.choice(["Home", "Electronics", "Beauty", "Sports"], size=n, p=[0.35, 0.2, 0.25, 0.2])
    base = pd.Series({"Home": 45, "Electronics": 160, "Beauty": 28, "Sports": 60})
    df = pd.DataFrame({
        "order_date": pd.Timestamp("2025-01-01") + pd.to_timedelta(rng.integers(0, 365, n), unit="D"),
        "category": category,
        "quantity": rng.integers(1, 6, n),
        "unit_price": (base[category].to_numpy() * (0.8 + 0.4 * rng.random(n))).round(2),
        "shipping_days": rng.integers(1, 9, n),
    })
    df["revenue"] = (df["quantity"] * df["unit_price"]).round(2)
    return df.sort_values("order_date").reset_index(drop=True)

orders = make_orders()
fig, ax = plt.subplots()
sns.regplot(data=orders, x="unit_price", y="revenue", ci=None, ax=ax)

line = ax.lines[0]
x, y = line.get_xdata(), line.get_ydata()
chart_slope = (y[-1] - y[0]) / (x[-1] - x[0])
slope, intercept = np.polyfit(orders["unit_price"], orders["revenue"], 1)
print("lines:", len(ax.lines), "| scatter layers:", len(ax.collections))
print("chart slope:", round(float(chart_slope), 2), "| polyfit slope:", round(float(slope), 2))
print("intercept:", round(float(intercept), 2))
```

```output
lines: 1 | scatter layers: 1
chart slope: 3.41 | polyfit slope: 3.41
intercept: -13.57
```

## Real-world applications

- **First look at a new table.** A pair plot or correlation heatmap (Examples 2 and 3) is the opening move in EDA to find which columns relate before building a model.
- **Calendar-by-category views.** A heatmap of a pivot table (Example 1's table) shows seasonality by product line in one image, which is how many retail teams review weekly sales.
- **Checking that a pattern holds everywhere.** Facets (Example 4) show whether a trend is driven by one category or true across all, before a recommendation goes to the business.
- **Quantifying a relationship.** The regression line and its slope (Example 5) turn "revenue goes up with price" into "about 3.4 pounds of extra revenue per pound of price in this sample".

## Daily review

### Key takeaways

- A heatmap draws a table; use a diverging map and fixed limits for correlations, and annotate cells.
- `pairplot` and `FacetGrid` are figure-level: they return grid objects, and the axes are in `g.axes`.
- A correlation of zero means no straight-line relationship, not no relationship.
- `regplot` draws the least-squares line, the same as `np.polyfit(x, y, 1)`; switch off the random confidence band for reproducible checks with `ci=None`.
- Charts of many relationships find leads, not proof.

### Common mistakes

- Passing `ax=` to `pairplot` or `FacetGrid`. Symptom: `TypeError` for an unexpected keyword. Fix: these are figure-level; use the returned grid, or `sns.heatmap`/`regplot` for a single axes.
- Heatmap of a table with non-numeric columns. Symptom: `ValueError` about converting strings. Fix: select the numeric columns, or compute `corr(numeric_only=True)`.
- Forgetting `vmin` and `vmax`. Symptom: a weak correlation looks as strong as a strong one. Fix: fix the scale to -1 and 1.
- Reading a regression line as causation. Symptom: a claim that raising the price raises revenue. Fix: say "is associated with" and check the confounders.

### Revision notes

- `corr()`, `sns.heatmap(annot=True, vmin=-1, vmax=1, cmap="vlag")`.
- `PairGrid` and `FacetGrid`: `g.axes`; panel titles like `category = Home`.
- `np.polyfit(x, y, 1)` returns slope and intercept.
- `ci=None` for a stable chart.
