## Understand

### Operators and expressions

An **operator** is a symbol that combines values, and an **expression** is a piece of code that Python can work out to a single value, such as `7 + 3`. The values the operator acts on are its **operands**. Python's arithmetic operators are:

- `+` adds, `-` subtracts, `*` multiplies.
- `/` divides and always returns a `float`, even when the answer is whole: `10 / 2` is `5.0`.
- `//` is **floor division**: it divides and then rounds the answer down to the nearest whole number, so `7 // 2` is `3`.
- `%` is **modulo**: it gives the remainder after division, so `7 % 2` is `1`.
- `**` raises to a power, so `2 ** 10` is `1024`.

When both operands of `+`, `-`, `*`, `//`, `%` or `**` are integers, the result is an integer. If either operand is a float, the result is a float. The `/` operator is the exception: its result is a float whatever you give it.

### Floor division and modulo as a pair

Imagine sharing 17 sweets among 5 children. Each child receives 3 whole sweets, and 2 are left over. Floor division gives the 3 (`17 // 5`) and modulo gives the 2 (`17 % 5`). The two always fit together: `(a // b) * b + (a % b)` is always `a`. This pair is the standard tool for converting units. Splitting 135 minutes into hours and minutes is `135 // 60` hours and `135 % 60` minutes. It also answers "is this number even?": `n % 2` is `0` for even numbers and `1` for odd ones. Modulo also repeats a pattern, which is how you assign rows to a rotating set of groups.

With negative numbers, floor division rounds towards negative infinity, not towards zero. So `-7 // 2` is `-4`, not `-3`, and `-7 % 2` is `1`. The pairing rule above still holds: `-4 * 2 + 1` is `-7`. You will meet this only occasionally, but it surprises people who expect plain truncation.

### Operator precedence

When an expression has several operators, Python does not simply read left to right. It follows an order of **precedence**, the same idea as school mathematics. From highest to lowest, the order for today's operators is: parentheses `( )`, then `**`, then unary minus (the `-` in `-5`), then `*`, `/`, `//` and `%`, then `+` and `-`. Operators at the same level are worked out left to right, except `**`, which works right to left, so `2 ** 3 ** 2` is `2 ** 9`, which is `512`. A subtle effect of the table is that `-2 ** 2` is `-4`, because the power is worked out before the minus sign is applied.

Parentheses always win and are free. If an expression is not obvious at first glance, add parentheses. They cost nothing and tell the next reader what you meant. The classic mistake is an average written as `a + b + c / 3`: division goes first, so only `c` is divided. The correct form is `(a + b + c) / 3`.

### Floats are approximations

Computers store floats in binary, and many decimal fractions, such as 0.1, have no exact binary form. Python therefore stores the nearest value it can, and some results show a tiny error: `0.1 + 0.2` gives `0.30000000000000004`. This is not a Python bug; every language that uses standard floats does the same. For reports you almost never need that many digits, so you round the result. Whole numbers (`int`) are exact, which is why money is sometimes kept as whole cents.

### round()

`round(x)` returns the nearest whole number as an `int`. `round(x, n)` rounds to `n` digits after the decimal point and returns a float. Python rounds exact halves to the nearest even number, so `round(2.5)` is `2` and `round(3.5)` is `4`. A negative `n` rounds to tens, hundreds and so on: `round(1234.567, -2)` is `1200.0`. Because floats are approximations, a value that looks like an exact half, such as `2.675`, may be stored slightly below it and round down, giving `round(2.675, 2)` equal to `2.67`. Do not treat rounding for display as a precise decimal tool.

Rounding with `round()` is different from `int()`, which you met yesterday. `int(7.9)` cuts to 7, `round(7.9)` gives 8.

### The math module

Python keeps a lot of its functionality in **modules**, collections of extra tools that you load with an **import** statement. You write `import math` once, near the top of the file, and then use the tools as `math.name`. The `math` module is part of Python, so nothing needs installing. Four tools are enough for now:

- `math.sqrt(x)` returns the square root as a float.
- `math.ceil(x)` rounds up to the next whole number, and `math.floor(x)` rounds down to the previous one. Both return an `int`. They differ from `round()` because they always go in one direction.
- `math.pi` is the constant 3.14159..., a value, not a function, so it has no parentheses.

### Common misconception

Many beginners expect `10 / 2` to print `5`. It prints `5.0`, because `/` always produces a float. If you need a whole number, use `//` for integer division, or convert the result with `int()`.

### Why it matters

Almost every report contains a calculation: a total, a rate, a share, a percentage change, a unit conversion. The difference between `/` and `//`, the position of parentheses and the rounding step decide whether a number in a report is right. Errors here do not stop the program; they quietly produce a wrong figure, which is worse than a crash.

## Syntax and key functions

Arithmetic expression:

```python nocheck
result = left_operand operator right_operand
```

The operator sits between two operands. The expression is worked out first and the result stored under `result`.

Update a variable from its own value:

```python
total = total + 5
total += 5
```

Both lines do the same thing. `+=` is a shorthand, and `-=`, `*=` and `/=` work the same way.

Import and use a module:

```python
import math
math.sqrt(16)
```

`import math` makes the module available; `math.sqrt` means "the `sqrt` tool inside `math`".

| Operator or function | Meaning | Example and result |
|---|---|---|
| `+`, `-`, `*` | Add, subtract, multiply. | `6 * 7` is `42` |
| `/` | Division, always a float. | `7 / 2` is `3.5` |
| `//` | Floor division, rounds down. | `7 // 2` is `3` |
| `%` | Remainder. | `7 % 2` is `1` |
| `**` | Power. | `2 ** 5` is `32` |
| `abs(x)` | Distance from zero. | `abs(-4.5)` is `4.5` |
| `round(x)` | Nearest whole number (halves go to even). | `round(3.7)` is `4` |
| `round(x, n)` | Round to `n` decimals. | `round(3.14159, 2)` is `3.14` |
| `math.sqrt(x)` | Square root, as a float. | `math.sqrt(81)` is `9.0` |
| `math.ceil(x)` | Round up, as an int. | `math.ceil(2.1)` is `3` |
| `math.floor(x)` | Round down, as an int. | `math.floor(2.9)` is `2` |
| `math.pi` | The constant pi. | `3.141592653589793` |

## Learn by example

### Example 1: The arithmetic operators side by side

Seven operators applied to the same two integers. Note that `17 / 5` is a float while `17 // 5` is an integer, and that the quotient and the remainder together rebuild 17.

```python run
a = 17
b = 5
print("Add:", a + b)
print("Subtract:", a - b)
print("Multiply:", a * b)
print("Divide:", a / b)
print("Floor divide:", a // b)
print("Remainder:", a % b)
print("Power:", a ** 2)
print("Check:", (a // b) * b + a % b)
```

```output
Add: 22
Subtract: 12
Multiply: 85
Divide: 3.4
Floor divide: 3
Remainder: 2
Power: 289
Check: 17
```

### Example 2: Floor division and modulo for unit conversion

The total of 135 minutes becomes whole hours with `//` and the leftover minutes with `%`. The last two lines use `% 2` to test whether a number is even or odd.

```python run
total_minutes = 135
hours = total_minutes // 60
minutes = total_minutes % 60
print(hours, "hours and", minutes, "minutes")

print("12 % 2 =", 12 % 2)
print("13 % 2 =", 13 % 2)
print(-7 // 2, -7 % 2)
```

```output
2 hours and 15 minutes
12 % 2 = 0
13 % 2 = 1
-4 1
```

### Example 3: Precedence and parentheses

Multiplication happens before addition unless parentheses say otherwise. The average line shows the classic mistake and its fix. The power and unary-minus lines show two results that surprise newcomers.

```python run
print(2 + 3 * 4)
print((2 + 3) * 4)

a = 80
b = 90
c = 85
print(a + b + c / 3)
print((a + b + c) / 3)

print(2 ** 3 ** 2)
print(-2 ** 2)
print((-2) ** 2)
```

```output
14
20
198.33333333333334
85.0
512
-4
4
```

### Example 4: Float approximations and rounding

`0.1 + 0.2` is not exactly `0.3`, so you round before showing a result. `round(x)` returns an integer, `round(x, 2)` keeps two decimals, and a negative second argument rounds to tens or hundreds. Halves go to the nearest even number: 2.5 rounds to 2 and 3.5 to 4. The last line shows that `int()` cuts where `round()` goes to the nearest whole number.

```python run
total = 0.1 + 0.2
print(total)
print(round(total, 2))

print(round(7.9))
print(round(3.14159, 2))
print(round(1234.567, -2))
print(round(2.5), round(3.5))
print(int(7.9), round(7.9))
```

```output
0.30000000000000004
0.3
8
3.14
1200.0
2 4
7 8
```

### Example 5: The math module in a small calculation

A square tile floor and a circular table top. `math.sqrt` finds the side length of a square with a given area. `math.ceil` rounds up the number of boxes, because you cannot buy a fraction of a box. The circle uses `math.pi`.

```python run
import math

area = 144
side = math.sqrt(area)
print("Side:", side)

tiles = 47
per_box = 10
boxes = math.ceil(tiles / per_box)
print("Boxes needed:", boxes)

radius = 3
circle_area = math.pi * radius ** 2
print("Circle area:", round(circle_area, 2))
print(math.floor(2.9), math.ceil(2.1))
```

```output
Side: 12.0
Boxes needed: 5
Circle area: 28.27
2 3
```

## Real-world applications

- **Converting durations and sizes.** Pipelines log run times in seconds and reports show hours and minutes. `//` and `%` do the conversion, as in Example 2. The same pattern turns bytes into kilobytes with the remainder kept.
- **Percentages and growth rates.** A month-on-month change is `(new - old) / old * 100`. Parentheses and the always-float `/` matter here, and `round(result, 1)` makes it presentable for a dashboard.
- **Batching and pagination.** Loading 47,000 rows in batches of 10,000 needs `math.ceil(47000 / 10000)` batches, which is 5. Using plain division would give a fractional number of batches that cannot be run.
- **Taxes, discounts and money.** Applying a rate to a price produces long floats such as 53.9892. Rounding to 2 decimals at the end of the calculation gives a figure for an invoice, and knowing that floats are approximate explains why totals sometimes differ in the last digit.

## Daily review

### Key takeaways

- `/` always gives a float; `//` rounds down and, with integers, gives an integer; `%` gives the remainder.
- `(a // b) * b + (a % b)` always rebuilds `a`; this pair converts units and tests even or odd.
- Precedence: parentheses, `**`, unary minus, then `* / // %`, then `+ -`. Use parentheses when in doubt.
- Floats are approximations, so round results for display with `round(x, n)`.
- `round()` goes to the nearest value (halves to even), `math.ceil` always up, `math.floor` always down, `int()` cuts the decimals.

### Common mistakes

- Writing `a + b + c / 3` for an average instead of `(a + b + c) / 3`.
- Expecting `10 / 2` to be `5` rather than `5.0`.
- Expecting `round(2.5)` to be `3`; Python gives `2`.
- Forgetting `import math`, or writing `sqrt(16)` instead of `math.sqrt(16)`.
- Writing `math.pi()` with parentheses; `pi` is a value, not a function.
- Rounding intermediate results and then calculating further, which stacks rounding errors. Round once, at the end.

### Revision notes

- `-7 // 2` is `-4` because floor division rounds towards negative infinity.

- `round(x, 2)` for display; `math.ceil` for "how many whole boxes".
