## Objectives

- Use the `axis` argument to summarise down columns (`axis=0`) or across rows (`axis=1`), and predict the resulting shape.
- Build running totals with `cumsum` and `cumprod`, and differences with `np.diff`.
- Find positions with `argmax`, `argmin` and `argsort`, and use them to look up the matching labels.
- Handle missing values in aggregations with `np.nanmean` and `np.nansum`.

## Understand

### Aggregation: many numbers in, fewer numbers out

On Day 65 each operation returned an array of the same shape as its input. An **aggregation** (also called a reduction) does the opposite: it collapses many values into fewer, often a single number. `a.sum()` adds every value, `a.mean()` gives the average, `a.min()` and `a.max()` give the extremes, `a.std()` gives the standard deviation and `a.var()` the variance. The **standard deviation** measures how spread out the values are around their mean: a small value means readings cluster tightly, a large one means they vary widely. The **variance** is the standard deviation squared.

Each aggregation exists as a method (`a.mean()`) and as a function (`np.mean(a)`). They do the same thing, and the method form is more common. One detail matters when you compare results with other tools: NumPy's `std` divides by the number of values `n` by default (the population standard deviation). Many other tools, including pandas, divide by `n - 1` (the sample standard deviation). To get the `n - 1` version in NumPy, pass `ddof=1`. Forgetting this is the most common reason why a NumPy result disagrees slightly with a spreadsheet or pandas.

### The axis argument

For a one-dimensional array there is nothing to choose, but a table has two directions. The `axis` argument says which dimension disappears. This is the idea learners find hardest, so read it slowly.

Take a table with 3 rows (days) and 4 columns (sensors). `t.sum(axis=0)` collapses axis 0, the rows: for each column it adds together all the rows, so the result has one value per column and shape `(4,)`. `t.sum(axis=1)` collapses axis 1, the columns: for each row it adds across the columns, giving one value per row and shape `(3,)`. Without `axis`, all values are collapsed to one number.

A memory aid: **the axis you name is the one that vanishes**. In `axis=0` the first number in the shape, 3, vanishes and `(3, 4)` becomes `(4,)`. In `axis=1` the second number vanishes and the shape becomes `(3,)`. If you want to keep the collapsed axis with length 1, so that the result can broadcast against the original (Day 65), add `keepdims=True`: `t.mean(axis=1, keepdims=True)` has shape `(3, 1)` and `t - t.mean(axis=1, keepdims=True)` subtracts each row's mean from that row.

The misconception is to read `axis=0` as "work along the rows" and expect one value per row. The direction of the arrow is the opposite: `axis=0` means "walk down axis 0", which combines the rows, leaving one value per column. Whenever you are unsure, check the shape of the result: it tells you immediately which axis disappeared.

### Cumulative functions and differences

A cumulative function keeps the running result instead of collapsing it. `np.cumsum(a)` returns the running total: `[1, 2, 3, 4]` becomes `[1, 3, 6, 10]`. The result has the same length as the input. `np.cumprod` does the same with products, which is useful for compounding growth rates. These also accept `axis`. The inverse of `cumsum` is `np.diff(a)`, which returns the difference between each value and the one before it. It is one shorter than the input, because the first value has nothing before it.

### Finding positions: argmax, argmin and argsort

`a.max()` tells you the largest value but not where it is. `a.argmax()` returns the **index** of the largest value (the first one if there is a tie), and `a.argmin()` the smallest. This is how you answer "which sensor had the highest reading?" when you hold the sensor names in a separate list: `names[a.argmax()]`. `np.argsort(a)` returns the positions that would put the array in ascending order, so `a[np.argsort(a)]` is the sorted array and `names[np.argsort(a)]` is the names in that order. On a 2D array, `argmax(axis=1)` gives the winning column for each row.

### Missing values and aggregation

Real measurements contain gaps, stored as `np.nan`. The special value `nan` ("not a number") is a float that is contagious: any ordinary aggregation over an array with one `nan` returns `nan`. `np.array([1.0, np.nan, 3.0]).mean()` is `nan`, not 2.0. The functions `np.nanmean`, `np.nansum`, `np.nanmax`, `np.nanmin` and `np.nanstd` skip the missing values. `np.isnan(a)` gives the mask of missing positions, so `np.isnan(a).sum()` counts them. Before you trust a summary, decide whether missing values are rare enough to skip or whether they change the meaning of the result.

### Why it matters in data work

Summaries are the first thing anyone asks of a dataset: the total, the average, the spread, the best and worst. The `axis` argument turns one call into "average per sensor" or "total per day". These statistics also feed into later steps: normalising data needs a mean and a standard deviation, and spotting outliers needs a spread. Getting the axis right is the difference between a correct table of results and a plausible wrong one.

### A worked trace

Let `t = np.array([[2, 4, 6], [1, 3, 5]])`, shape `(2, 3)`. Then `t.sum()` is 21. `t.sum(axis=0)` adds the rows column by column: `2+1, 4+3, 6+5`, which is `[3, 7, 11]`, shape `(3,)`. `t.sum(axis=1)` adds across: `2+4+6` and `1+3+5`, which is `[12, 9]`, shape `(2,)`. `t.argmax(axis=1)` is `[2, 2]` because the largest value of each row is in its last column, and `t.cumsum(axis=1)` is `[[2, 6, 12], [1, 4, 9]]`. Work one of these out by hand each time you meet a new axis question; after a few it becomes automatic.

### Integer and float results

`mean`, `std` and `var` always return floats, because averages are rarely whole numbers. `sum` keeps integers for integer input. Comparing floats for equality is fragile: use `round` or `np.isclose` when you test an aggregation result. Printing with `round(x, 2)` keeps the output stable, and calling `float(x)` or `.tolist()` turns NumPy numbers into ordinary Python values when you need them for other code.

## Syntax and key functions

Aggregations:

```python
a.sum()
a.mean()
a.std(ddof=0)
a.max(axis=0)
t.sum(axis=1, keepdims=True)
```

`axis` names the axis that disappears. `ddof=1` gives the sample standard deviation. `keepdims=True` keeps the collapsed axis with length 1.

Cumulative and positional:

```python
np.cumsum(a)
np.diff(a)
a.argmax()
np.argsort(a)
np.nanmean(a)
```

| Expression | Returns |
|---|---|
| `a.sum()`, `a.mean()` | Total and average of all values. |
| `a.min()`, `a.max()` | Smallest and largest value. |
| `a.std()`, `a.var()` | Population standard deviation and variance. |
| `t.sum(axis=0)` | One value per column (rows collapse). |
| `t.sum(axis=1)` | One value per row (columns collapse). |
| `np.cumsum(a)`, `np.cumprod(a)` | Running total, running product. |
| `np.diff(a)` | Differences between neighbours, length n - 1. |
| `a.argmax()`, `a.argmin()` | Index of the largest and smallest value. |
| `np.argsort(a)` | Positions that sort the array ascending. |
| `np.nanmean(a)`, `np.nansum(a)` | Aggregations that ignore `nan`. |
| `np.isnan(a)` | Mask of missing values. |

## Learn by example

### Example 1: Basic aggregations

The same numbers are summarised with methods. The standard deviation is shown with `ddof=0` (the default) and `ddof=1`. Results are rounded so the output is stable.

```python run
import numpy as np

a = np.array([4, 8, 6, 5, 3, 2, 8, 9, 2, 5])
print(a.sum(), a.min(), a.max(), a.mean())
print(round(a.std(), 4), round(a.std(ddof=1), 4), round(a.var(), 2))
print(np.mean(a) == a.mean(), len(a), a.size)
print(round(a.sum() / len(a), 2))
```

```output
52 2 9 5.2
2.4 2.5298 5.76
True 10 10
5.2
```

### Example 2: The axis argument

A table has 3 days (rows) and 4 sensors (columns). `axis=0` collapses the rows and leaves one value per sensor, `axis=1` collapses the columns and leaves one value per day. The shapes confirm which axis vanished.

```python run
import numpy as np

t = np.array([[2, 4, 6, 8],
              [1, 3, 5, 7],
              [10, 20, 30, 40]])
print(t.sum())
print(t.sum(axis=0).tolist(), t.sum(axis=0).shape)
print(t.sum(axis=1).tolist(), t.sum(axis=1).shape)
print(t.mean(axis=0).round(2).tolist())
print(t.max(axis=1).tolist())
print(t.mean(axis=1, keepdims=True).shape)
print((t - t.mean(axis=1, keepdims=True)).round(1).tolist())
```

```output
136
[13, 27, 41, 55] (4,)
[20, 16, 100] (3,)
[4.33, 9.0, 13.67, 18.33]
[8, 7, 40]
(3, 1)
[[-3.0, -1.0, 1.0, 3.0], [-3.0, -1.0, 1.0, 3.0], [-15.0, -5.0, 5.0, 15.0]]
```

### Example 3: Cumulative functions and differences

`cumsum` keeps the running total, `cumprod` the running product. `np.diff` reverses a `cumsum`. On a table, `axis` chooses the direction of the running total.

```python run
import numpy as np

sales = np.array([5, 3, 8, 2])
run = np.cumsum(sales)
print(run.tolist())
print(np.diff(run).tolist())
print(np.cumprod(np.array([1.1, 1.1, 1.1])).round(3).tolist())
t = np.array([[1, 2, 3], [4, 5, 6]])
print(t.cumsum(axis=1).tolist())
print(t.cumsum(axis=0).tolist())
```

```output
[5, 8, 16, 18]
[3, 8, 2]
[1.1, 1.21, 1.331]
[[1, 3, 6], [4, 9, 15]]
[[1, 2, 3], [5, 7, 9]]
```

### Example 4: argmax, argmin and argsort

The extreme value does not say where it is. The `arg` functions give positions, and a list of names is looked up with them. The names are looked up with the positions.

```python run
import numpy as np

names = np.array(["north", "south", "east", "west"])
sales = np.array([120, 340, 95, 310])
print(sales.max(), sales.argmax(), names[sales.argmax()])
print(sales.argmin(), names[sales.argmin()])
order = np.argsort(sales)
print(order.tolist(), names[order].tolist())
print(names[np.argsort(-sales)][:2].tolist())

t = np.array([[3, 9, 2], [7, 1, 8]])
print(t.argmax(axis=1).tolist(), t.argmin(axis=0).tolist())
```

```output
340 1 south
2 east
[2, 0, 3, 1] ['east', 'north', 'west', 'south']
['south', 'west']
[1, 2] [0, 1, 0]
```

### Example 5: Missing values in aggregations

One `nan` makes an ordinary aggregation `nan`. The `nan` versions skip missing values. `isnan` finds and counts them, and the mask also lets you fill them with the mean.

```python run
import numpy as np

r = np.array([20.0, np.nan, 24.0, 22.0, np.nan, 30.0])
print(r.mean(), r.sum())
print(np.nanmean(r), np.nansum(r), np.nanmax(r))
print(np.isnan(r).sum(), np.isnan(r).tolist())
filled = np.where(np.isnan(r), np.nanmean(r), r)
print(filled.tolist())
print(round(float(filled.std()), 3), round(float(np.nanstd(r)), 3))
```

```output
nan nan
24.0 96.0 30.0
2 [False, True, False, False, True, False]
[20.0, 24.0, 24.0, 22.0, 24.0, 30.0]
3.055 3.742
```

### Example 6: A realistic summary of sensors by day

Readings for three sensors over five days are summarised per sensor (columns) and per day (rows). The hottest day, the most stable sensor (lowest standard deviation) and the day-to-day change of the first sensor are found with the tools above. The data come from a seeded generator and are rounded to one decimal, so every run gives the same table.

```python run
import numpy as np

rng = np.random.default_rng(7)
temps = np.round(rng.normal(loc=[20, 25, 22], scale=[1, 4, 2], size=(5, 3)), 1)
sensors = np.array(["A", "B", "C"])
print(temps.tolist())
print(np.round(temps.mean(axis=0), 2).tolist())
print(np.round(temps.mean(axis=1), 2).tolist())
print(int(temps.mean(axis=1).argmax()) + 1)
print(sensors[temps.std(axis=0).argmin()])
print(np.round(np.diff(temps[:, 0]), 1).tolist())
```

## Real-world applications

- **Per-group summaries.** `mean(axis=0)` gives one average per sensor or product, `mean(axis=1)` one per day or customer, as in Examples 2 and 6. The same idea becomes `GROUP BY` in SQL and `groupby` in pandas.
- **Running totals and growth.** `cumsum` produces cumulative sales and `cumprod` compounds a series of growth rates, as in Example 3, and `diff` recovers period-to-period changes.
- **Finding the best and worst.** `argmax`, `argmin` and `argsort` rank regions, products or sensors and look up their names, as in Example 4.
- **Quality checks on readings.** `np.isnan(a).sum()` counts missing readings and `nanmean` summarises what remains, as in Example 5. A large standard deviation flags a sensor that needs attention.

## Daily review

### Key takeaways

- Aggregations collapse many values; `sum`, `mean`, `min`, `max`, `std` and `var` exist as methods and functions.
- The axis you name is the axis that disappears: `axis=0` gives one value per column, `axis=1` one value per row.
- `std` uses `n` by default; use `ddof=1` for the sample standard deviation that pandas reports.
- `cumsum` and `cumprod` keep running results, `diff` gives neighbour differences, `argmax`, `argmin` and `argsort` give positions.
- A single `nan` poisons an ordinary aggregation; use the `nan` functions or filter first.

### Common mistakes

- Reading `axis=0` as "per row". The result then has the wrong length; compare the result's `shape` with what you expected.
- Comparing NumPy `std` with a spreadsheet or pandas value and seeing a small difference. The cause is `ddof`.
- Taking the mean of data containing `nan` and getting `nan`. Use `np.nanmean` or fill the gaps.
- Using `max()` when you need the position. Use `argmax()`.
- Using the Python built-in `sum()` on a 2D array and getting an array back instead of a number. Use `a.sum()`.
- Forgetting `keepdims=True` and getting a shape error when subtracting row means from a table.

### Revision notes

- `t.sum(axis=0)` collapses rows (per column); `t.sum(axis=1)` collapses columns (per row).
- `keepdims=True` keeps shape `(n, 1)` so the result broadcasts back.
- `cumsum` running total, `diff` one shorter; `argmax` first index of the maximum.
- `nanmean`, `nansum`, `isnan` for gaps; `ddof=1` for sample std.
