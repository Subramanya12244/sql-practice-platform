## Objectives

- Find missing values with `isna()` and `notna()`, and count them per column, per row and in total.
- Remove rows or columns with `dropna`, using `how`, `subset` and `thresh` to control what is removed.
- Fill gaps with `fillna` using a constant, a per-column dictionary, a statistic such as the mean or median, or the neighbouring values with `ffill` and `bfill`.
- Estimate a gap from its neighbours with `interpolate`.
- Choose a missing-value strategy for a column and justify it by the meaning of the data.

## Understand

### What missing means

A **missing value** is a cell for which no value is known. In pandas it is stored as `NaN` (not a number) in numeric columns, and as `None` or `NaN` in text columns; newer date columns use `NaT` (not a time). They arrive in data in many disguises: an empty cell in a CSV file, the text `n/a`, a sensor that failed to report, a customer who skipped a form field, or a join that found no partner. You already met `NaN` in NumPy on Day 66, where `np.nanmean` skipped it. pandas treats missing values more gently: most summaries, such as `sum`, `mean`, `min`, `max` and `count`, **skip** missing values by default. That is convenient, but it also hides the problem. A mean calculated from 3 of 10 rows looks just as confident as one calculated from all 10.

A missing value is also not equal to anything, including itself. `df["a"] == None` and `df["a"] == np.nan` give `False` everywhere, so you cannot find gaps with `==`. The dedicated tools are `isna()` and `notna()`.

### Finding missing values

`df.isna()` returns a table of booleans of the same shape: `True` where a value is missing. `df.notna()` is the opposite. Because `True` counts as 1, summing gives counts: `df.isna().sum()` is the number of missing values in each column, `df.isna().sum().sum()` the total, `df.isna().mean()` the share missing per column, and `df.isna().any(axis=1)` flags the rows that have at least one gap. Use `df["a"].isna()` as a mask to display the affected rows: `df[df["a"].isna()]`. Counting first is the correct start of any treatment: you need to know how many values are missing, in which columns, and whether the gaps cluster in particular rows.

Do not confuse missing with empty-looking text. A cell holding `""`, a single space or the word `unknown` is **not** missing for pandas. Such a value is a text, and you must convert it with `replace` or an `na_values` option in `read_csv` (Day 69) before `isna()` can find it. Likewise a sentinel such as `-999` is a number, which is why Day 70's inspection looked for odd minima.

### Removing: dropna

`df.dropna()` returns a new table without every row that has any missing value. That is usually too aggressive, so it has controls. `how="all"` removes a row only when all its values are missing. `subset=["price", "qty"]` looks only at those columns when deciding. `thresh=3` keeps a row only if it has at least 3 non-missing values. `axis=1` works on columns instead of rows, dropping every column that has a gap. Like other pandas methods, `dropna` returns a new table; store it.

Removal is simple and honest, but it loses data. If 5 per cent of rows have a gap in one unimportant column, dropping them throws away all the information in the other columns. Use `subset` to be selective: remove a row only if it is missing the field that your analysis needs.

### Filling: fillna

`df["a"].fillna(0)` replaces missing values in a column by 0. A dictionary fills several columns with different values: `df.fillna({"price": 0.0, "city": "unknown"})`. A statistic is a common choice for numeric data: `df["a"].fillna(df["a"].mean())` or the median, which resists outliers. For ordered data such as a time series, fill from the neighbours: `df["a"].ffill()` (forward fill) copies the last known value forward, and `df["a"].bfill()` (backward fill) copies the next known value backwards. A gap at the very start cannot be forward-filled and stays missing.

### Interpolation

`df["a"].interpolate()` estimates a missing value from the values on both sides. The default method is linear: between 10 and 20 with one gap, the estimate is 15, and with two gaps the estimates are 13.33 and 16.67. This suits smooth measurements such as temperature, but not categories or values that jump. Gaps at the very beginning stay missing, and gaps at the end are filled with the last value by default.

### Choosing a strategy

There is no single correct treatment. The choice depends on what the missing value means and on what you will do with the column.

- **Leave it missing** when summaries that skip gaps are fine and the missing count is small. State how many rows were skipped.
- **Drop** rows when the field is essential and you have plenty of data, using `subset`.
- **Fill with a constant** when missing really means zero (no sales that day) or a label such as `unknown`.
- **Fill with a statistic** (mean or median) when you need a complete numeric column and gaps are random and few. This shrinks the variation of the data, so use it with care.
- **Fill from neighbours or interpolate** for ordered measurements.

Whatever you choose, record it, keep the original table, and report how many values were affected. A silent fill changes results, and the reader cannot know unless you say so.

### The common misconception

Learners believe that filling or dropping makes the data "clean" and so ends the problem. A filled value is a guess, not an observation. Filling gaps with the mean leaves the mean unchanged but makes the spread smaller, and replacing every gap by 0 makes the average fall. A related belief is that `NaN` behaves like 0 in sums. It is skipped, which is different: the total ignores the gap, the mean is over fewer rows, and `count()` counts only non-missing values.

### Why it matters in data work

Real data always has gaps, and the way you handle them directly changes totals, averages and models. A good analyst counts them, understands why they occur, applies a documented rule and measures the effect, for example by comparing the mean before and after the fill. Wrong handling is a quiet source of errors: totals that omit rows, joins that fail on missing keys, and reports whose averages differ from the finance team's because they skipped different rows.

### Keeping types in mind

A numeric column with a missing value is stored as floating point, because `NaN` is a float. A column of whole numbers with one gap therefore turns into decimals such as `3.0`. The examples use floating-point columns for this reason, and fill them with decimal values, which keeps the type unchanged and avoids surprises.

## Syntax and key functions

Find, drop, fill:

```python
df.isna()
df.isna().sum()
df.dropna(how="any", subset=None, thresh=None)
df["a"].fillna(value)
df.fillna({"a": 0.0, "b": "unknown"})
df["a"].ffill()
df["a"].bfill()
df["a"].interpolate()
```

| Expression | Returns |
|---|---|
| `df.isna()`, `df.notna()` | Boolean table: missing, not missing. |
| `df.isna().sum()` | Missing count per column. |
| `df.isna().mean()` | Share missing per column. |
| `df.isna().any(axis=1)` | One boolean per row: has any gap. |
| `df.dropna()` | New table without rows that have any gap. |
| `dropna(how="all")`, `dropna(subset=[...])`, `dropna(thresh=n)` | Drop only fully empty rows; look only at some columns; keep rows with at least n values. |
| `s.fillna(value)` | New Series with gaps replaced. |
| `df.fillna({"a": 0})` | Different fill value per column. |
| `s.ffill()`, `s.bfill()` | Fill from the previous or the next value. |
| `s.interpolate()` | Linear estimate of gaps between known values. |

## Learn by example

### Example 1: Finding and counting

`isna` gives a table of booleans. Summing counts per column, and `any(axis=1)` flags rows with at least one gap. A comparison with `None` does not find gaps. A mask shows the affected rows.

```python run
import pandas as pd

pd.set_option("display.width", 200)
pd.set_option("display.max_columns", 20)

df = pd.DataFrame({"city": ["Oslo", None, "Rome", "Oslo", None],
                   "temp": [4.0, None, 18.0, None, 22.0], "qty": [3, 1, 4, 1, 5]})
print(df.isna())
print(df.isna().sum().to_dict(), int(df.isna().sum().sum()))
print(df.isna().mean().round(2).to_dict())
print(df.isna().any(axis=1).tolist())
print((df["temp"] == None).sum())
print(df[df["temp"].isna()])
print(df["temp"].sum(), round(df["temp"].mean(), 2), df["temp"].count(), len(df))
```


### Example 2: dropna with how, subset and thresh

Plain `dropna` removes any row with a gap. `how="all"` removes only rows that are completely empty, `subset` restricts the decision to chosen columns, and `thresh` keeps rows with enough values.

```python run
import pandas as pd

pd.set_option("display.width", 200)
pd.set_option("display.max_columns", 20)

df = pd.DataFrame({"a": [1.0, None, 3.0, None], "b": [10.0, None, None, None], "c": [5.0, 6.0, 7.0, None]})
print(df)
print(df.dropna().shape)
print(df.dropna(how="all").shape)
print(df.dropna(subset=["a"]).shape)
print(df.dropna(thresh=2).shape)
print(df.dropna(axis=1).columns.tolist())
```

```output
     a     b    c
0  1.0  10.0  5.0
1  NaN   NaN  6.0
2  3.0   NaN  7.0
3  NaN   NaN  NaN
(1, 3)
(3, 3)
(2, 3)
(2, 3)
[]
```

### Example 3: fillna with a constant, a dictionary and statistics

A constant or a dictionary fills gaps, and the mean or median fills a numeric column. Filling with the mean keeps the mean but shrinks the spread, which the standard deviations show.

```python run
import pandas as pd

pd.set_option("display.width", 200)
pd.set_option("display.max_columns", 20)

df = pd.DataFrame({"price": [10.0, None, 14.0, None, 30.0], "city": ["Oslo", None, "Rome", "Oslo", None]})
print(df["price"].fillna(0).tolist())
print(df.fillna({"price": -1.0, "city": "unknown"}))
mean = df["price"].mean()
median = df["price"].median()
print(mean, median)
filled = df["price"].fillna(mean)
print(filled.tolist(), filled.mean() == mean)
print(round(df["price"].std(), 2), round(filled.std(), 2))
print(df["price"].isna().sum(), filled.isna().sum())
```

```output

2   14.0     Rome
3   -1.0     Oslo
4   30.0  unknown
18.0 14.0
[10.0, 18.0, 14.0, 18.0, 30.0] True

```

### Example 4: ffill, bfill and interpolate

A time series of readings has gaps. Forward fill copies the previous value, backward fill the next one, and interpolation draws a straight line between the known points. A gap at the start cannot be forward-filled.

```python run
import pandas as pd

s = pd.Series([None, 10.0, None, None, 16.0, None, 20.0])
print(s.ffill().tolist())
print(s.bfill().tolist())
print(s.interpolate().round(2).tolist())
print(s.isna().sum(), s.ffill().isna().sum(), s.interpolate().isna().sum())
```

```output
[nan, 10.0, 10.0, 10.0, 16.0, 16.0, 20.0]
[10.0, 10.0, 16.0, 16.0, 16.0, 20.0, 20.0]
[nan, 10.0, 12.0, 14.0, 16.0, 18.0, 20.0]
4 1 1
```

### Example 5: A strategy per column

A small sensor and sales table gets a different rule for each column: rows without an id are dropped, missing temperatures are interpolated, missing sales are set to zero because no sale was recorded, and the missing labels become `unknown`. A before-and-after report states how much changed. The original is kept.

```python run
import pandas as pd

pd.set_option("display.width", 200)
pd.set_option("display.max_columns", 20)

raw = pd.DataFrame({"id": [1.0, 2.0, None, 4.0, 5.0], "temp": [20.0, None, 24.0, None, 28.0],
                    "sales": [100.0, None, 80.0, 120.0, None], "label": ["a", None, "c", "d", None]})
print(raw.isna().sum().to_dict())
clean = (raw.dropna(subset=["id"])
         .assign(temp=lambda t: t["temp"].interpolate(),
                 sales=lambda t: t["sales"].fillna(0.0),
                 label=lambda t: t["label"].fillna("unknown")))
print(clean)
print(clean.isna().sum().sum(), len(raw), len(clean))
print(raw["sales"].mean(), clean["sales"].mean())
```

```output
{'id': 1, 'temp': 2, 'sales': 2, 'label': 2}
    id       temp  sales    label
0  1.0  20.000000  100.0        a
1  2.0  22.666667    0.0  unknown
3  4.0  25.333333  120.0        d
4  5.0  28.000000    0.0  unknown
0 5 4
100.0 55.0
```

## Real-world applications

- **Auditing a data delivery.** Counting gaps per column, as in Example 1, tells you which fields are reliable before any report is built.
- **Keeping essential rows.** `dropna(subset=...)` removes only rows that lack the fields the analysis needs, as in Examples 2 and 5, instead of throwing away whole records.
- **Completing sensor series.** Forward fill and interpolation, as in Example 4, bridge short gaps in ordered measurements such as temperature or stock levels.
- **Documenting data decisions.** A before-and-after table of counts and means, as in Example 5, shows exactly what a filling rule changed.

## Daily review

### Key takeaways

- Missing values are `NaN`, `None` or `NaT`; find them with `isna()` and `notna()`, never with `==`.
- `isna().sum()` counts per column; summaries such as `sum` and `mean` skip gaps by default.
- `dropna` has `how`, `subset`, `thresh` and `axis`; prefer `subset` to avoid losing useful data.
- `fillna` takes a constant, a dictionary, a statistic, or use `ffill`, `bfill` and `interpolate` for ordered data.
- The right strategy depends on what the gap means; keep the original and report what changed.

### Common mistakes

- Testing `df["a"] == np.nan` and finding nothing. Use `isna()`.
- Assuming empty text or `n/a` is missing when pandas still holds it as text.
- Using `dropna()` with no arguments and losing most of the table.
- Filling gaps with 0 where 0 is a meaningful value, which pulls averages down.
- Filling with the mean and then reporting the standard deviation as if it were measured.
- Calling `df.fillna(0)` without storing the result, so the table keeps its gaps.

### Revision notes

- `df.isna().sum()`, `df.isna().mean()`, `df[df["a"].isna()]`.
- `df.dropna(subset=[...])`, `how="all"`, `thresh=n`.
- `s.fillna(0)`, `s.fillna(s.median())`, `s.ffill()`, `s.interpolate()`.
- State the rule and the number of values changed.
