- Predict how arithmetic between two Series lines values up by index label, not by position.

## Understand

### From arrays to labelled data

On Days 63 to 67 you worked with NumPy arrays: fast blocks of numbers of one type, addressed by position. Real tables are different in two ways. Their columns have names such as `price` or `city`, and different columns hold different kinds of data: numbers in one, text in another, dates in a third. Their rows often have meaningful identifiers too, such as an order number or a date. **pandas** (the package `pandas`, imported as `pd`) adds labels and mixed types on top of NumPy arrays. It is the main tool of Python data analysis, and the next days are about using it. Every pandas column is stored as a NumPy array underneath, which is why the vectorised arithmetic you learned on Day 65 works on columns too.

pandas has two main objects. A **Series** is one labelled column of values. A **DataFrame** is a table: a collection of Series that share the same row labels. The picture to keep in mind is a spreadsheet: the DataFrame is the whole sheet, and each column is a Series.

### The Series

A Series has three parts. The **values** are the data, held in a NumPy array and all of one dtype. The **index** is a list of labels, one per value. The **name** is an optional label for the whole Series (it becomes the column name inside a DataFrame). You create one from a list with `pd.Series([10, 20, 30])`. Because you gave no labels, the index is the default `0, 1, 2`, which is the same as positions. You can supply your own labels with `index=["a", "b", "c"]`, or create a Series from a dictionary, in which case the keys become the index: `pd.Series({"north": 120, "south": 85})`.

With labels you can look values up by name: `s["south"]` returns 85. This is the major difference from an array. The label is part of the data, not just a position.

### Index alignment

When you add or subtract two Series, pandas matches values by **index label**, not by position. If `a` has labels `x, y` and `b` has labels `y, z`, then `a + b` has labels `x, y, z`. The label `y` is present in both, so those values are added. Labels `x` and `z` appear in only one, so the result there is `NaN` (not a number, pandas' marker for a missing value). This is called **alignment** and it is a source of both power and surprise. It means that the order of rows in the two Series does not matter, but it also means that a typo in a label silently produces missing values.

### The DataFrame

A DataFrame has **columns** (a list of column labels), an **index** (row labels) and the values. The most readable way to build one is a dictionary where each key is a column name and each value is a list of that column's values: `pd.DataFrame({"city": ["Oslo", "Rome"], "temp": [4, 18]})`. All lists must have the same length. A second way is a list of dictionaries, one per row (records): `pd.DataFrame([{"city": "Oslo", "temp": 4}, {"city": "Rome", "temp": 18}])`. This is the shape that JSON data usually arrives in, and the next day uses it. A missing key in one record becomes `NaN`.

Each column has its own dtype. A column of whole numbers is `int64`, decimals are `float64`, and text columns have the dtype `object`, which means "a Python object per cell, here a string". The `dtypes` attribute lists them. A mixed table is therefore not a problem, unlike a NumPy array which forces one type.

### Basic attributes

The attributes you will use constantly are `shape` (a tuple of rows and columns, as in NumPy), `size` (number of cells), `ndim` (1 for a Series, 2 for a DataFrame), `len(df)` (number of rows), `df.index`, `df.columns`, `df.dtypes` and `df.values` (the data as a NumPy array). As in NumPy, these are attributes, so they have no parentheses. `df.shape()` raises `TypeError: 'tuple' object is not callable`.

### Selecting columns by name

`df["temp"]` returns one column as a Series, with the DataFrame's index. `df[["city", "temp"]]` (a list inside the brackets) returns a smaller DataFrame with those columns in that order. The double brackets confuse beginners: the outer pair is the selection and the inner pair is a Python list of names. A single name gives a Series, a list of names gives a DataFrame, even if the list has one name. Days 71 and 72 cover selecting rows and filtering; today only columns.

### The common misconception

Learners expect pandas to behave like a list of lists or like an array and think in positions only. Two misunderstandings follow. First, expecting `a + b` on Series to add by position; pandas adds by label, so Series with different labels give `NaN`. Second, assuming the index is a column of the table. The index is the row labels, outside the columns: `df.shape` for a table with three columns and four rows is `(4, 3)`, even if one of the columns looks like an identifier, until you deliberately make it the index.

### Why it matters in data work

Almost all analysis data is a table with named columns of different types, and you need to read, name and describe it before you can clean or summarise it. Knowing the three parts of a DataFrame, the index, the columns and the values, tells you what any pandas error is talking about, and knowing that columns are Series that align by label explains most of the surprising `NaN` values beginners meet. The attributes `shape` and `dtypes` are the first things to check on any new table, in the same way that `shape` and `dtype` were for arrays.

### Setting display options

pandas prints tables with some columns hidden if the table is wide. At the top of every example in these lessons we set `pd.set_option("display.width", 200)` and `pd.set_option("display.max_columns", 20)`, so that printed tables are complete and the same on every machine. It changes only how a table is shown, not the data.

## Syntax and key functions

Build and inspect:

```python
import pandas as pd

s = pd.Series(values, index=labels, name="name")
s = pd.Series({"a": 1, "b": 2})
df = pd.DataFrame({"col1": list1, "col2": list2})
df = pd.DataFrame([{"col1": 1, "col2": "x"}, {"col1": 2, "col2": "y"}])
df["col1"]
df[["col1", "col2"]]
```

| Expression | Returns |
|---|---|
| `pd.Series(list)` | A Series with the default index 0, 1, 2, ... |
| `pd.Series(dict)` | A Series whose index is the dictionary keys. |
| `pd.DataFrame(dict_of_lists)` | A table with one column per key. |
| `pd.DataFrame(list_of_dicts)` | A table with one row per dictionary. |
| `s.index`, `s.values`, `s.name` | Labels, the NumPy array of data, the name. |
| `df.columns`, `df.index`, `df.values` | Column labels, row labels, 2D NumPy array. |
| `df.shape`, `df.size`, `df.ndim`, `len(df)` | `(rows, columns)`, cell count, 2, row count. |
| `df.dtypes` | A Series of the dtype of each column. |
| `df["a"]` / `df[["a", "b"]]` | One column as a Series / several as a DataFrame. |
| `s.to_dict()`, `s.tolist()` | Plain Python dictionary or list. |

## Learn by example

### Example 1: Creating Series

A Series from a list gets the default index. Giving `index=` or using a dictionary adds labels, so lookups can use names. Series have the NumPy summaries of Day 66.

```python run
import pandas as pd

s = pd.Series([120, 85, 240])
print(s.tolist(), s.index.tolist(), s.dtype)

sales = pd.Series([120, 85, 240], index=["north", "south", "east"], name="sales")
print(sales["south"], sales.name, sales.index.tolist())
print(sales.values.tolist(), sales.shape, sales.ndim, len(sales))
print(sales.sum(), round(sales.mean(), 2), sales.max())

d = pd.Series({"a": 1.5, "b": 2.5})
print(d.to_dict(), d.dtype)
```

```output
[120, 85, 240] [0, 1, 2] int64
85 sales ['north', 'south', 'east']
[120, 85, 240] (3,) 1 3
445 148.33 240
{'a': 1.5, 'b': 2.5} float64
```

### Example 2: Index alignment

Addition lines up labels. Labels present in both Series are added, and labels in only one give `NaN`. The positions are irrelevant, as shown by listing the labels in a different order.

```python run
import pandas as pd

a = pd.Series([1, 2, 3], index=["x", "y", "z"])
b = pd.Series([10, 20, 30], index=["z", "y", "w"])
total = a + b
print(total.to_string())
print(total.isna().sum())
print((a + a).to_dict())
print((a * 2).tolist())
```

```output
w     NaN
x     NaN
y    22.0
z    13.0
2
{'x': 2, 'y': 4, 'z': 6}
[2, 4, 6]
```

### Example 3: Building a DataFrame

A dictionary of columns and a list of records give the same table. A record with a missing key gets `NaN`. The first print shows the table, and the attributes describe it.

```python run
import pandas as pd

pd.set_option("display.width", 200)
pd.set_option("display.max_columns", 20)

df = pd.DataFrame({"city": ["Oslo", "Rome", "Lima"], "temp": [4, 18, 22], "rain": [0.5, 0.1, 0.0]})
print(df)
rec = pd.DataFrame([{"city": "Oslo", "temp": 4}, {"city": "Rome"}, {"city": "Lima", "temp": 22}])
print(rec)
print(df.equals(pd.DataFrame([{"city": "Oslo", "temp": 4, "rain": 0.5}, {"city": "Rome", "temp": 18, "rain": 0.1}, {"city": "Lima", "temp": 22, "rain": 0.0}])))
```

```output
   city  temp  rain
0  Oslo     4   0.5
1  Rome    18   0.1
2  Lima    22   0.0
   city  temp
0  Oslo   4.0
1  Rome   NaN
2  Lima  22.0
True
```

### Example 4: Attributes and dtypes

Shape, size, index, columns and dtypes describe the table. The `dtypes` attribute is itself a Series of dtypes, and `values` is a NumPy array. The index can be replaced by assigning to `index`.

```python run
import pandas as pd

df = pd.DataFrame({"qty": [3, 1, 4, 1], "price": [9.5, 20.0, 3.25, 7.0], "item": ["pen", "ink", "cap", "pad"]})
print(df.shape, df.size, df.ndim, len(df))
print(df.columns.tolist(), df.index.tolist())
print(df[["qty", "price"]].dtypes.to_string())
print(df.values.shape)
df.index = ["a", "b", "c", "d"]
print(df.index.tolist())
print(df["qty"].tolist())
```

```output
(4, 3) 12 2 4
['qty', 'price', 'item'] [0, 1, 2, 3]
qty        int64
price    float64
(4, 3)
['a', 'b', 'c', 'd']
[3, 1, 4, 1]
```

### Example 5: Selecting columns and combining them

One name gives a Series, a list of names gives a DataFrame. Arithmetic between two columns of the same DataFrame lines up because they share the index, and summaries work column by column. The shapes show the difference between single and double brackets.

```python run
import pandas as pd

pd.set_option("display.width", 200)
pd.set_option("display.max_columns", 20)

df = pd.DataFrame({"item": ["pen", "ink", "cap"], "qty": [3, 1, 4], "price": [9.5, 20.0, 3.25]})
col = df["qty"]
sub = df[["qty"]]
print(type(col).__name__, col.shape, type(sub).__name__, sub.shape)
print(df[["price", "item"]])
total = df["qty"] * df["price"]
print(total.tolist())
print(round(total.sum(), 2))
print(df[["qty", "price"]].mean().round(2).to_dict())
```

```output
Series (3,) DataFrame (3, 1)
   price item
0   9.50  pen
1  20.00  ink
2   3.25  cap
[28.5, 20.0, 13.0]
61.5
{'qty': 2.67, 'price': 10.92}
```

## Real-world applications

- **Loading a table to look at it.** Whatever the source, a file, an API or a database, the data ends up as a DataFrame. Its `shape`, `columns` and `dtypes` are the first checks, as in Example 4.
- **Turning records into tables.** JSON from a web service is a list of dictionaries. `pd.DataFrame(list_of_dicts)`, as in Example 3, turns them into a table, with missing keys becoming `NaN`.
- **Combining columns.** Line totals (`qty * price`) and similar ratios are column arithmetic, as in Example 5, and need no loops.
- **Spotting alignment bugs.** An unexpected number of `NaN` values after adding two Series, as in Example 2, usually means that the labels of the two do not match exactly, for example a trailing space.

## Daily review

### Key takeaways

- A Series is one labelled column; a DataFrame is a table of Series sharing an index.
- The index holds row labels, the columns hold names; values are NumPy arrays and each column has its own dtype.
- `shape`, `size`, `ndim`, `dtypes`, `index` and `columns` are attributes without parentheses.
- `df["a"]` gives a Series and `df[["a"]]` gives a DataFrame.
- Arithmetic between Series aligns by index label; missing partners give `NaN`.

### Common mistakes

- Writing `df.shape()` and getting `TypeError: 'tuple' object is not callable`.
- Using `df["a", "b"]` for two columns, which raises a `KeyError`. Use a list: `df[["a", "b"]]`.
- Building a DataFrame from lists of different lengths, which raises `ValueError: All arrays must be of the same length`.
- Expecting Series to add by position and getting `NaN` where labels differ.
- Forgetting that a column of text has dtype `object` and so cannot be averaged.
- Treating the index as a column. `df["index"]` raises `KeyError` unless a column has that name.

### Revision notes

- `pd.Series(list, index=...)`, `pd.Series(dict)`, `pd.DataFrame(dict_of_lists)`, `pd.DataFrame(list_of_dicts)`.
- `df.shape` is `(rows, columns)`; `df.dtypes` per column; `df.values` is a NumPy array.
- `df["a"]` Series, `df[["a"]]` DataFrame.
- Alignment is by label.
