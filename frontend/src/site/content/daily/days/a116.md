## Objectives

- Create a grid of axes with `plt.subplots(nrows, ncols)`, index into it, and share axes so panels can be compared.
- Apply a built-in style and change defaults for one chart with a style context.
- Annotate a chart with a reference line and an arrow that points at a data point.
- Save a figure to PNG and SVG and explain the options that control resolution and cropping.

## Understand

### Why more than one panel

Yesterday every figure held one axes. A single chart can show several series, but beyond three or four lines it turns into a tangle, and a viewer cannot tell which line belongs to which category. **Small multiples** solve that: the same chart is repeated in a grid, once per group, with the same scale in every panel, so the eye can compare shapes. Each panel is a separate axes on one figure. In matplotlib you ask for the whole grid in one call, `fig, axes = plt.subplots(nrows, ncols)`, and you get back one figure and an array of axes.

### The shape of the axes array

The return value depends on the grid. `plt.subplots()` with no arguments returns a single axes object. `plt.subplots(1, 3)` returns a one-dimensional NumPy array of three axes, which you can loop over. `plt.subplots(2, 2)` returns a 2-by-2 array indexed as `axes[row, col]`. A common beginner failure is writing `axes[0, 1]` on a one-dimensional array, or calling `axes.plot` on an array. Two fixes help: print `axes.shape` to see what you have, and use `axes.flat` (or `axes.ravel()`) to loop over every panel regardless of the shape. The option `squeeze=False` always returns a two-dimensional array.

### Sharing axes and spacing

If two panels have different y ranges, a reader will compare the heights of lines or bars that mean different things. Passing `sharey=True` (or `sharex=True`) to `plt.subplots` forces all panels to use one scale, and the tick labels are shown only on the outer panels, which saves space. Use shared axes whenever the point is comparison and independent axes only when the groups have wildly different scales and you are interested in shape alone, and then say so in the title. Panels also need room for titles and labels. The option `layout="constrained"` (or the older `fig.tight_layout()`) adjusts margins automatically so labels do not overlap. A title for the whole figure goes through `fig.suptitle`, while each panel's own title goes through `axes[i].set_title`.

### Styles

A **style** is a bundle of default settings (colours, grid, fonts, background) applied to every chart drawn while it is active. Matplotlib ships with many: `plt.style.available` lists them. `plt.style.use("ggplot")` changes the defaults for the rest of the session, which can surprise you later; `with plt.style.context("ggplot"):` applies the style only inside the block, which is safer in scripts and notebooks. Styles are a quick way to get a consistent look across a report, and for exact control you can change individual defaults through `matplotlib.rcParams`, for example `rcParams["axes.grid"] = True`. Do not mistake a style for good design: it does not fix an axis that starts at the wrong place or a missing label.

### Annotations

Annotation puts a reader's attention where you want it. A **reference line** (`ax.axhline(y)` for a horizontal line, `ax.axvline(x)` for a vertical one) marks a target, an average or an event. **Text** (`ax.text(x, y, "label")`) writes at data coordinates. **`ax.annotate`** writes text and draws an arrow from the text to a data point: `ax.annotate("Peak", xy=(7, 2500), xytext=(8, 2800), arrowprops={"arrowstyle": "->"})`, where `xy` is the point being described and `xytext` is where the text sits. Annotate the one or two things that carry the message (the peak, the dip after a price change) rather than every point. Each annotation is stored as an artist, so `ax.texts` lists the texts and each has `get_text()`.

### Saving

`fig.savefig("report.png", dpi=150, bbox_inches="tight")` writes the figure to a file. The format comes from the extension: PNG is a raster image good for slides and web pages, SVG and PDF are vector formats that stay sharp when scaled, which suits print. `dpi` (dots per inch) sets the resolution of raster output, `bbox_inches="tight"` trims empty margins, and `transparent=True` removes the background. Save before you call `plt.show()` in an interactive session, and call `plt.close(fig)` once a figure is saved, because matplotlib keeps every open figure in memory, and a loop that makes hundreds of charts without closing them will warn and slow down.

### Misconceptions and why it matters

Beginners often assume subplots share a scale automatically; they do not, unless you ask. Another assumption is that `plt.style.use` affects only the next chart; it affects everything after it. Multi-panel layouts, styling, annotation and saving are the steps that turn a plot into something that can be sent to a manager, and they are the parts that are most often done by hand and then inconsistently, so scripting them is a real time saver.

## Syntax and key functions

```python
fig, axes = plt.subplots(1, 3, figsize=(12, 3.5), sharey=True, layout="constrained")
for ax, (name, part) in zip(axes, groups):
    ax.plot(part["x"], part["y"])
    ax.set_title(name)
fig.suptitle("Revenue by category")

with plt.style.context("ggplot"):
    fig, ax = plt.subplots()

ax.axhline(2000, linestyle="--", label="Target")
ax.annotate("Peak", xy=(7, 2500), xytext=(8, 2800), arrowprops={"arrowstyle": "->"})
fig.savefig("report.png", dpi=150, bbox_inches="tight")
plt.close(fig)
```

| Call | What it does or returns |
|---|---|
| `plt.subplots(r, c, sharex, sharey)` | Returns `(fig, axes)`; `axes` is one object, a 1-D array or a 2-D array |
| `axes.flat` | Iterates over every axes regardless of the grid shape |
| `fig.suptitle(text)` | Title for the whole figure |
| `layout="constrained"` | Automatic spacing so labels do not overlap |
| `plt.style.available` | List of style names |
| `plt.style.context(name)` | Context manager that applies a style temporarily |
| `ax.axhline(y)`, `ax.axvline(x)` | Draw a reference line |
| `ax.annotate(text, xy, xytext, arrowprops)` | Text with an arrow to a point |
| `fig.savefig(path, dpi, bbox_inches)` | Write PNG, SVG or PDF by extension |
| `plt.close(fig)` | Release the figure |

## Learn by example

### Example 1: The data behind each panel

This example builds a table of monthly revenue per category, which gives one line per panel, and finds the global maximum that every panel's y axis must accommodate. It runs in the browser.

```python run
import numpy as np
import pandas as pd


def make_orders():
    rng = np.random.default_rng(7)
    n = 240
    category = rng.choice(["Home", "Electronics", "Beauty", "Sports"], size=n, p=[0.35, 0.2, 0.25, 0.2])
    base = pd.Series({"Home": 45, "Electronics": 160, "Beauty": 28, "Sports": 60})
    df = pd.DataFrame({
        "order_date": pd.Timestamp("2025-01-01") + pd.to_timedelta(rng.integers(0, 365, n), unit="D"),
        "category": category,
        "quantity": rng.integers(1, 6, n),
        "unit_price": (base[category].to_numpy() * (0.8 + 0.4 * rng.random(n))).round(2),
        "shipping_days": rng.integers(1, 9, n),
    })
    df["revenue"] = (df["quantity"] * df["unit_price"]).round(2)
    return df.sort_values("order_date").reset_index(drop=True)

orders = make_orders()
table = orders.pivot_table(index=orders["order_date"].dt.month, columns="category", values="revenue", aggfunc="sum", fill_value=0).round(0)
print(table.shape, "months x categories")
print("peak per category:", {c: int(table[c].max()) for c in table.columns})
print("shared y top:", int(table.to_numpy().max()))
```

```output
(12, 4) months x categories
peak per category: {'Beauty': 915, 'Electronics': 4071, 'Home': 1573, 'Sports': 1224}
shared y top: 4071
```

### Example 2: Small multiples with a shared y axis

One panel per category in a single row. Because the call is `plt.subplots(1, 4, sharey=True)`, `axes` is a one-dimensional array of four axes, and the prints check the grid shape, that the y limits are identical, and each panel's title and line count.

```python local
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt
import numpy as np
import pandas as pd


def make_orders():
    rng = np.random.default_rng(7)
    n = 240
    category = rng.choice(["Home", "Electronics", "Beauty", "Sports"], size=n, p=[0.35, 0.2, 0.25, 0.2])
    base = pd.Series({"Home": 45, "Electronics": 160, "Beauty": 28, "Sports": 60})
    df = pd.DataFrame({
        "order_date": pd.Timestamp("2025-01-01") + pd.to_timedelta(rng.integers(0, 365, n), unit="D"),
        "category": category,
        "quantity": rng.integers(1, 6, n),
        "unit_price": (base[category].to_numpy() * (0.8 + 0.4 * rng.random(n))).round(2),
        "shipping_days": rng.integers(1, 9, n),
    })
    df["revenue"] = (df["quantity"] * df["unit_price"]).round(2)
    return df.sort_values("order_date").reset_index(drop=True)

orders = make_orders()
table = orders.pivot_table(index=orders["order_date"].dt.month, columns="category", values="revenue", aggfunc="sum", fill_value=0)

fig, axes = plt.subplots(1, 4, figsize=(12, 3), sharey=True, layout="constrained")
for ax, name in zip(axes, table.columns):
    ax.plot(table.index, table[name])
    ax.set_title(name)
    ax.set_xlabel("Month")
axes[0].set_ylabel("Revenue (GBP)")
fig.suptitle("Monthly revenue by category")

print("axes shape:", axes.shape)
print("titles:", [ax.get_title() for ax in axes])
print("same y limits:", len({ax.get_ylim() for ax in axes}) == 1)
print("lines per panel:", [len(ax.lines) for ax in axes])
print("figure title:", fig.get_suptitle())
```

```output
axes shape: (4,)
titles: ['Beauty', 'Electronics', 'Home', 'Sports']
same y limits: True
lines per panel: [1, 1, 1, 1]
figure title: Monthly revenue by category
```

### Example 3: A style inside a context

Styles change defaults. Inside `with plt.style.context("ggplot")` the plot background is grey, and after the block the default style returns. Printing the face colour in both cases proves the style did not leak.

```python local
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt
from matplotlib.colors import to_hex

print("ggplot available:", "ggplot" in plt.style.available)

fig, ax = plt.subplots()
print("default background:", to_hex(ax.get_facecolor()))
plt.close(fig)

with plt.style.context("ggplot"):
    fig, ax = plt.subplots()
    print("ggplot background:", to_hex(ax.get_facecolor()))
    plt.close(fig)

fig, ax = plt.subplots()
print("after the block:", to_hex(ax.get_facecolor()))
plt.close(fig)
```

```output
ggplot available: True
default background: #ffffff
ggplot background: #e5e5e5
after the block: #ffffff
```

### Example 4: Annotate the peak and a target

A line chart of monthly revenue gets a dashed target line and an arrow pointing at the best month. The prints show the annotation text, the target value and the number of text artists. The target of 4000 is an invented business goal for the example.

```python local
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt
import numpy as np
import pandas as pd


def make_orders():
    rng = np.random.default_rng(7)
    n = 240
    category = rng.choice(["Home", "Electronics", "Beauty", "Sports"], size=n, p=[0.35, 0.2, 0.25, 0.2])
    base = pd.Series({"Home": 45, "Electronics": 160, "Beauty": 28, "Sports": 60})
    df = pd.DataFrame({
        "order_date": pd.Timestamp("2025-01-01") + pd.to_timedelta(rng.integers(0, 365, n), unit="D"),
        "category": category,
        "quantity": rng.integers(1, 6, n),
        "unit_price": (base[category].to_numpy() * (0.8 + 0.4 * rng.random(n))).round(2),
        "shipping_days": rng.integers(1, 9, n),
    })
    df["revenue"] = (df["quantity"] * df["unit_price"]).round(2)
    return df.sort_values("order_date").reset_index(drop=True)

orders = make_orders()
monthly = orders.groupby(orders["order_date"].dt.month)["revenue"].sum().round(0)
peak_month = int(monthly.idxmax())
peak_value = int(monthly.max())

fig, ax = plt.subplots()
ax.plot(monthly.index, monthly.values, marker="o")
ax.axhline(4000, linestyle="--", color="grey")
ax.annotate(f"Peak: month {peak_month}", xy=(peak_month, peak_value),
            xytext=(peak_month - 3, peak_value + 300), arrowprops={"arrowstyle": "->"})
ax.set_title("Revenue peaked in month %d" % peak_month)
ax.set_ylim(bottom=0)

print("texts:", [t.get_text() for t in ax.texts])
print("reference lines:", len(ax.lines) - 1, "at", [float(l.get_ydata()[0]) for l in ax.lines[1:]])
print("peak:", peak_month, peak_value)
```

```output
texts: ['Peak: month 3']
reference lines: 1 at [4000.0]
peak: 3 6418
```

### Example 5: Save in two formats

The figure is saved into a temporary folder as PNG and SVG. The prints do not show file sizes (they vary by machine and version) but check that both files exist and are not empty, which is what a report pipeline needs to know.

```python local
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt
import os
import tempfile

fig, ax = plt.subplots(figsize=(4, 3))
ax.bar(["A", "B", "C"], [3, 5, 2])
ax.set_title("Demo")

with tempfile.TemporaryDirectory() as folder:
    for ext in ["png", "svg"]:
        path = os.path.join(folder, "chart." + ext)
        fig.savefig(path, dpi=100, bbox_inches="tight")
        print(ext, "saved:", os.path.getsize(path) > 0)
plt.close(fig)
print("open figures:", len(plt.get_fignums()))
```

```output
png saved: True
svg saved: True
open figures: 0
```

## Real-world applications

- **Regional comparison pages.** A sales report draws one panel per region with a shared y axis (Example 2), so managers compare regions without reading axis numbers.
- **Brand-consistent reports.** A style context applied to every figure in a monthly script keeps colours and gridlines consistent without editing each chart (Example 3).
- **Calling out the message.** A target line and a labelled peak (Example 4) tell the reader what to look at, and the same annotation code can be generated for any metric.
- **Automated report generation.** A nightly job saves PNG files for email and SVG for print, then closes each figure (Example 5) so memory does not grow across hundreds of charts.

## Daily review

### Key takeaways

- `plt.subplots(r, c)` returns one figure and an axes object, 1-D array or 2-D array depending on the grid.
- `sharey=True` makes panels comparable; `layout="constrained"` prevents overlapping labels.
- Use `with plt.style.context(...)` so a style does not leak.
- `axhline`, `annotate` and `text` put the message on the chart; annotate only what carries it.
- `fig.savefig` picks the format from the extension; close figures you no longer need.

### Common mistakes

- Indexing a 1-D axes array with two indices. Symptom: `IndexError: too many indices for array`. Fix: print `axes.shape`, or loop over `axes.flat`.
- Leaving panels on independent scales while comparing them. Symptom: two panels look similar but one axis runs to 100 and the other to 10000. Fix: `sharey=True`.
- Calling `plt.style.use(...)` in a notebook and wondering why later charts look different. Fix: use a style context, or reset with `plt.style.use("default")`.
- Making many figures in a loop without closing them. Symptom: `RuntimeWarning: More than 20 figures have been opened` and growing memory. Fix: `plt.close(fig)` after saving each one.

### Revision notes

- `fig, axes = plt.subplots(1, 3, sharey=True, layout="constrained")`; `axes.flat`.
