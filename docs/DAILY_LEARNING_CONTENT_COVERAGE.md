## Environment-dependent days

These days include examples or exercises that need software the browser cannot run. Each has an `environment` note in its lesson, and each has a graded alternative that runs in the browser (pure Python, pandas, `sqlite3` or PGlite SQL).

| Id | Title | Packages | Note |
|---|---|---|---|
| d022 | Modules, packages, venv and pip | pip | The two bash examples need a shell with python on the PATH and no network: they create a throwaway virtual environment with python -m venv and print only stable facts. Installing real packages from PyPI needs internet access and cannot run in the browser, so the lesson shows those commands as text. The graded exercises are pure-Python alternatives: parsing requirement lines, comparing them with installed versions, and building modules and packages from code. The written exercise covers the real shell session. |
| d023 | Dates and times | tzdata | Example 5 uses zoneinfo.ZoneInfo, which reads the operating system's time-zone database, so it is tagged python local and shown with its verified output. The browser runner may not have that database, so every graded exercise and the other examples use fixed offsets with datetime.timezone, which behave the same everywhere. On Windows, install the tzdata package (pip install tzdata) so ZoneInfo works. |

They use only portable options and avoid dates, users and absolute paths so the output is stable. The graded exercises are pure-Python simulations of grep, cut, sort, uniq, permission strings and ls -l parsing, which run in the browser. The written exercises cover real shell sessions that you check against the model answers. |
