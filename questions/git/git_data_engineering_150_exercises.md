# Git Practice Lab — Data Engineering

> 150 hands-on exercises covering the Git skills most useful for data engineering.
> Practice in order. Do not reveal solutions before the learner attempts the task.

## Recommended Practice Rules

- Attempt every command question before looking at a solution.
- For scenario questions, explain your reasoning before executing commands.
- Prefer safe history-preserving operations on shared branches.
- For destructive commands, practice only inside a disposable repository.
- Use realistic repositories containing Python, Airflow, dbt, SQL, notebooks, and configuration files.

## Exercise Schema

Each exercise contains: Title, Type, Difficulty, Concepts, Scenario, Task, Expected Outcome, and Explanation.
